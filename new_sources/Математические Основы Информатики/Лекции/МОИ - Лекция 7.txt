ЛЕКЦИЯ 7. НИЖНЯЯ ОЦЕНКА ДЛЯ ФУНКЦИИ ШЕННОНА L(n)

========================================
ТЕОРЕМА (НИЖНЯЯ ОЦЕНКА ФУНКЦИИ ШЕННОНА)
========================================

Теорема. L(n) ≳ 2^(n−1) / n.

Это означает, что при достаточно большом n почти все булевы функции
от n переменных имеют сложность реализации схемами из функциональных
элементов (СФЭ) не менее 2^(n−1)/n.

========================================
ИСПОЛЬЗУЕМЫЙ ИНСТРУМЕНТ: ОБЩАЯ ЛЕММА
========================================

Из предыдущей лекции (Лекция 6) была получена верхняя оценка числа
схем с заданными параметрами:

Количество СФЭ с n входами, 1 выходом и сложностью h:

    S(n, 1, h) < r^h · (n + h)^(hν + p),

где r — число элементов в базисе, ν — максимальное число входов
элемента, p — число выходов.

Для стандартного базиса {&, ∨, ¬} (или любого базиса с двухвходовыми
элементами): r = 3, ν = 2, p = 1.

Подставляя:

    S(n, 1, h) < 3^h · (n + h)^(2h + 1).

========================================
ДОКАЗАТЕЛЬСТВО ТЕОРЕМЫ
========================================

Положим h = 2^(n−1) / n.  Заметим, что при больших n: h > n (т.к. 2^(n−1)/n > n
при n ≥ 5).

Доказательство состоит из двух частей.

----------------------------------------
ЧАСТЬ I. Оценка S(n, 1, h) < (Ch)^(2h)
----------------------------------------

Докажем, что при n < h

    ∃C :  S(n, 1, h) < (Ch)^(2h).

Прологарифмируем оценку (*):

ln[3^h · (n + h)^(2h+1)] = h·ln 3 + (2h + 1)·ln(n + h).

Так как n < h, имеем n + h < 2h, поэтому:

    < h·ln 3 + 2h·ln(2h) + ln(2h) =
    = h·ln 3 + 2h·ln 2 + 2h·ln h + ln 2 + ln h =
    = h(ln 3 + 2·ln 2 + ln 2/h + ln h/h) + 2h·ln h.

Слагаемое в скобках (ln 3 + 2·ln 2 + ln 2/h + ln h/h) —
ограниченная величина при h → ∞.

Таким образом,

    ln[3^h · (n + h)^(2h+1)] < h(ln 3 + 2·ln 2 + ln 2/h + ln h/h) + 2h·ln h.

В то же время:

    ln[(Ch)^(2h)] = h(2·ln C) + 2h·ln h.

Выбрав C так, что:

    2·ln C > ln 3 + 2·ln 2 + ln 2/h + ln h/h,

получим:

    S(n, 1, h) < (Ch)^(2h).    ■ (Часть I)

----------------------------------------
ЧАСТЬ II. Доля функций со сложностью ≤ h
         составляет исчезающе малую часть
         от общего числа булевых функций
----------------------------------------

Покажем, что булевых функций от n переменных, реализуемых схемами
сложности не более h = 2^(n−1)/n, меньше, чем 2^(2^n) — число всех
булевых функций от n переменных.

Заметим, во-первых, что если функция реализуется схемой сложности h,
то она реализуется схемой сложности h или h − 1.

Тогда всех функций, реализуемых схемами сложности ≤ h, не более, чем

    S(n, 1, h) + S(n, 1, h − 1) < 2·(Ch)^(2h).

Поскольку h = 2^(n−1)/n > n.

Рассмотрим, как ведет себя дробь

    2·(Ch)^(2h) / 2^(2^n)

при n → ∞.

Для этого рассмотрим log₂ от этой дроби:

    log₂ 2 + 2h·log₂(Ch) − 2^n·log₂ 2 =

Поскольку h = 2^(n−1)/n, подставим:

    = 1 + (2^n / n)·(log₂ C + log₂ 2^(n−1) − log₂ n) − 2^n =

    = 1 + (2^n / n)·(log₂ C + n − 1 − log₂ n) − 2^n =

    = 1 + (2^n / n)·(−1 + log₂ C − log₂ n)  →  −∞   при n → ∞.

(Последнее верно, так как −1 + log₂ C − log₂ n → −∞ при n → ∞,
а множитель 2^n/n → +∞.)

Таким образом,

    log₂(2·(Ch)^(2h) / 2^(2^n))  →  −∞   при n → ∞,

а значит:

    2·(Ch)^(2h) / 2^(2^n)  →  0   при n → ∞.    ■ (Часть II)

========================================
ЗАКЛЮЧЕНИЕ ТЕОРЕМЫ
========================================

Таким образом, при достаточно большом n НЕ ВСЕ функции от n
переменных могут быть реализованы схемами сложности не более, чем

    h = 2^(n−1) / n.

Следовательно:

    L(n) ≳ 2^(n−1) / n.

Более того, доля функций от n переменных, для которых
L(f) ≤ 2^(n−1)/n, стремится к 0 с ростом n.

Это означает, что «почти все» булевы функции имеют высокую сложность
реализации, порядка 2^n/n.

========================================
ИТОГИ КУРСА: ВЕРХНЯЯ И НИЖНЯЯ ОЦЕНКИ L(n)
========================================

Объединяя результаты Лекций 6 и 7:

    Верхняя оценка (метод Шеннона):   L(n) ≲ 2^n / n
    Нижняя оценка (метод подсчёта):   L(n) ≳ 2^(n−1) / n

Поскольку 2^(n−1)/n = (1/2)·(2^n/n), получаем:

    L(n) ~ 2^n / n   (с точностью до постоянного множителя).

Таким образом, функция Шеннона L(n) имеет порядок роста 2^n/n.
