ЛЕКЦИЯ 4. ПОЛНОТА И ЗАМКНУТОСТЬ СИСТЕМ БУЛЕВЫХ ФУНКЦИЙ

================================================================================
ЗАМЫКАНИЕ МНОЖЕСТВА БУЛЕВЫХ ФУНКЦИЙ
================================================================================

Пусть M ⊆ P₂ — произвольное множество булевых функций. Замыканием множества
M называется множество всех функций, которые можно реализовать формулами в
базисе M. Замыкание множества M будем обозначать через [M].

Примеры:
  [{x₁ ⊕ x₂, 1}] = L — множество линейных функций (deg f ≤ 1).
  [P₂] = P₂.

Свойства замыкания:
  1) M ⊆ [M]
  2) [[M]] = [M]
  3) M₁ ⊆ M₂  ⟹  [M₁] ⊆ [M₂]
  4) [M₁] ⊆ [M₂]  ⟹  [M₁] ⊆ [M₂]
  5) [M₁ ∪ M₂] = [[M₁] ∪ [M₂]]

================================================================================
ЗАМКНУТЫЕ МНОЖЕСТВА И ФУНКЦИОНАЛЬНАЯ ПОЛНОТА
================================================================================

Понятие функциональной полноты можно определить в терминах замыкания множеств:
множество M ⊆ P₂ является функционально полной системой ⟺ [M] = P₂.

Множество булевых функций R называется замкнутым множеством, если
оно совпадает со своим замыканием, т.е. [M] = M.

================================================================================
ОСНОВНЫЕ ЗАМКНУТЫЕ КЛАССЫ
================================================================================

Рассмотрим важнейшие замкнутые множества в P₂. Часто рассматриваемые ниже
замкнутые множества называются также основными замкнутыми классами.

Теорема Поста о функциональной полноте:

Для того чтобы система булевых функций M ⊆ P₂ была функционально полной,
необходимо и достаточно, чтобы M не содержалась целиком ни в одном из пяти
замкнутых классов: T₀, T₁, S, L, M.

Иначе говоря: [M] = P₂ ⟺ для каждого из классов T₀, T₁, S, L, M
существует функция из M, не принадлежащая этому классу.

================================================================================
КЛАСС T₀ — ФУНКЦИИ, СОХРАНЯЮЩИЕ НОЛЬ
================================================================================

Определение:
  f(x₁, x₂, ..., xₙ) ∈ T₀  ⟺  f(0, 0, ..., 0) = 0

Примеры:
  x, x∧y, x∨y, x⊕y  ∈ T₀
  x̄, x~y, x|y, x↓y  ∉ T₀

Теорема. Множество T₀ замкнуто.

Доказательство.
  Пусть f(x₁, x₂, ..., xₙ), fᵢ(x₁, x₂, ..., xₙ) ∈ T₀  (i = 1, ..., n).

  F(x₁, x₂, ..., xₙ) = f(f₁(x₁, ..., xₙ), f₂(x₁, ..., xₙ), ..., fₙ(x₁, x₂, ..., xₙ))

  F(0, 0, ..., 0) = f(f₁(0, ..., 0), f₂(0, ..., 0), ..., fₙ(0, ..., 0))
                   = f(0, 0, ..., 0) = 0

  ⟹ F(x₁, x₂, ..., xₙ) ∈ T₀.  ■

Мощность класса T₀:
  Пусть P₂⁽ⁿ⁾ — множество всех булевых функций от n переменных,
  T₀⁽ⁿ⁾ = T₀ ∩ P₂⁽ⁿ⁾.

  Тогда |T₀⁽ⁿ⁾| = 2^(2ⁿ − 1).

  Обоснование: функция из T₀ фиксирована на наборе (0,0,...,0) → 0,
  а на остальных 2ⁿ − 1 наборах значение может быть произвольным.

================================================================================
КЛАСС T₁ — ФУНКЦИИ, СОХРАНЯЮЩИЕ ЕДИНИЦУ
================================================================================

Определение:
  f(x₁, x₂, ..., xₙ) ∈ T₁  ⟺  f(1, 1, ..., 1) = 1

Примеры:
  x, x∧y, x∨y, x~y, x⊕y  ∈ T₁
  x̄, x|y, x↓y  ∉ T₁

Теорема. Множество T₁ замкнуто.

Доказательство.
  Пусть f(x₁, x₂, ..., xₙ), fᵢ(x₁, x₂, ..., xₙ) ∈ T₁  (i = 1, ..., n).

  F(x₁, x₂, ..., xₙ) = f(f₁(x₁, ..., xₙ), f₂(x₁, ..., xₙ), ..., fₙ(x₁, x₂, ..., xₙ))

  F(1, 1, ..., 1) = f(f₁(1, ..., 1), f₂(1, ..., 1), ..., fₙ(1, ..., 1))
                   = f(1, 1, ..., 1) = 1

  ⟹ F(x₁, x₂, ..., xₙ) ∈ T₁.  ■

Мощность класса T₁:
  Пусть P₂⁽ⁿ⁾ — множество всех булевых функций от n переменных,
  T₁⁽ⁿ⁾ = T₁ ∩ P₂⁽ⁿ⁾.

  Тогда |T₁⁽ⁿ⁾| = 2^(2ⁿ − 1).

  Обоснование: функция из T₁ фиксирована на наборе (1,1,...,1) → 1,
  а на остальных 2ⁿ − 1 наборах значение может быть произвольным.

================================================================================
КЛАСС S — САМОДВОЙСТВЕННЫЕ ФУНКЦИИ
================================================================================

Определение:
  f(x₁, x₂, ..., xₙ) ∈ S  ⟺  f* = f

  где f*(x₁, x₂, ..., xₙ) = f̄(x̄₁, x̄₂, ..., x̄ₙ) — двойственная функция.

  Эквивалентная запись:
  f(x̄₁, x̄₂, ..., x̄ₙ) = f̄(x₁, x₂, ..., xₙ)

Примеры:
  x, x̄, x₁⊕x₂⊕x₃, x₁x₂∨x₁x₃∨x₂x₃  ∈ S
  x∨y, x∧y, x|y, x↓y, x⊕y  ∉ S

Теорема. Множество S замкнуто.

Доказательство.
  Пусть f(x₁, x₂, ..., xₙ), fᵢ(x₁, x₂, ..., xₙ) ∈ S  (i = 1, ..., n).

  F(x₁, x₂, ..., xₙ) = f(f₁(x₁, ..., xₙ), f₂(x₁, ..., xₙ), ..., fₙ(x₁, x₂, ..., xₙ))

  F(x̄₁, x̄₂, ..., x̄ₙ)
  = f(f₁(x̄₁, ..., x̄ₙ), f₂(x̄₁, ..., x̄ₙ), ..., fₙ(x̄₁, ..., x̄ₙ))
  = f(f̄₁(x₁, ..., xₙ), f̄₂(x₁, ..., xₙ), ..., f̄ₙ(x₁, x₂, ..., xₙ))
  = F̄(x₁, x₂, ..., xₙ)

  ⟹ F(x₁, x₂, ..., xₙ) ∈ S.  ■

Мощность класса S:
  Пусть P₂⁽ⁿ⁾ — множество всех булевых функций от n переменных,
  S⁽ⁿ⁾ = S ∩ P₂⁽ⁿ⁾.

  Тогда |S⁽ⁿ⁾| = 2^(2ⁿ⁻¹).

  Обоснование: наборы из {0,1}ⁿ разбиваются на противоположные пары
  (α₁,...,αₙ) и (ᾱ₁,...,ᾱₙ). Таких пар 2ⁿ/2 = 2ⁿ⁻¹.
  Значение на одном наборе из пары определяет значение на другом,
  поэтому свободных параметров 2ⁿ⁻¹.

================================================================================
КЛАСС L — ЛИНЕЙНЫЕ ФУНКЦИИ
================================================================================

Определение:
  f(x₁, x₂, ..., xₙ) ∈ L  ⟺  deg f ≤ 1

  т.е. полином Жегалкина функции f имеет степень не выше 1.

Примеры:
  x, x̄, x₁⊕x₂⊕x₃, x₁~x₂  ∈ L
  x∨y, x∧y, x|y, x↓y  ∉ L

Теорема. Множество L замкнуто.

Доказательство.
  Пусть f(x₁, x₂, ..., xₙ), fᵢ(x₁, x₂, ..., xₙ) ∈ L  (i = 1, ..., n).

  F(x₁, x₂, ..., xₙ) = f(f₁(x₁, ..., xₙ), f₂(x₁, ..., xₙ), ..., fₙ(x₁, x₂, ..., xₙ))

  Так как deg f ≤ 1 и deg fᵢ ≤ 1, подстановка линейных функций в линейную
  даёт функцию степени не выше 1.

  deg F ≤ 1  ⟹  F(x₁, x₂, ..., xₙ) ∈ L.  ■

Мощность класса L:
  Пусть P₂⁽ⁿ⁾ — множество всех булевых функций от n переменных,
  L⁽ⁿ⁾ = L ∩ P₂⁽ⁿ⁾.

  Тогда |L⁽ⁿ⁾| = 2ⁿ⁺¹.

  Обоснование: линейная функция имеет вид
  f(x₁, x₂, ..., xₙ) = a₀·1 ⊕ a₁·x₁ ⊕ a₂·x₂ ⊕ ... ⊕ aₙ·xₙ,
  где каждый коэффициент aᵢ ∈ {0, 1}. Всего n+1 коэффициент,
  значит |L⁽ⁿ⁾| = 2ⁿ⁺¹.

================================================================================
КЛАСС M — МОНОТОННЫЕ ФУНКЦИИ
================================================================================

Определение:
  Частичный порядок на наборах: (α₁, ..., αₙ) ≤ (β₁, ..., βₙ)  ⟺  αᵢ ≤ βᵢ ∀i.

  f(x₁, x₂, ..., xₙ) ∈ M  ⟺  для любых наборов (α₁,...,αₙ) ≤ (β₁,...,βₙ)
  выполняется f(α₁,...,αₙ) ≤ f(β₁,...,βₙ).

Примеры:
  x, x∧y, x∨y, 0, 1  ∈ M
  x̄, x⊕y, x|y, x↓y  ∉ M

Теорема. Множество M замкнуто.

Доказательство.
  Пусть f(x₁, x₂, ..., xₙ), fᵢ(x₁, x₂, ..., xₙ) ∈ M  (i = 1, ..., n).

  F(x₁, x₂, ..., xₙ) = f(f₁(x₁, ..., xₙ), f₂(x₁, ..., xₙ), ..., fₙ(x₁, x₂, ..., xₙ))

  Пусть (α₁, ..., αₙ) ≤ (β₁, ..., βₙ). Тогда:

  fᵢ(α₁, ..., αₙ) ≤ fᵢ(β₁, ..., βₙ)  для всех i  (так как fᵢ ∈ M).

  F(α₁, ..., αₙ) = f(f₁(α₁, ..., αₙ), ..., fₙ(α₁, ..., αₙ))
                  ≤ f(f₁(β₁, ..., βₙ), ..., fₙ(β₁, ..., βₙ))  (так как f ∈ M)
                  = F(β₁, ..., βₙ)

  ⟹ F(x₁, x₂, ..., xₙ) ∈ M.  ■

================================================================================
ТЕОРЕМА ПОСТА О ФУНКЦИОНАЛЬНОЙ ПОЛНОТЕ (ФОРМУЛИРОВКА)
================================================================================

Теорема (Пост).
  Система булевых функций M ⊆ P₂ является функционально полной тогда и
  только тогда, когда M не содержится целиком ни в одном из пяти замкнутых
  классов T₀, T₁, S, L, M.

  Иначе: [M] = P₂  ⟺  M ⊄ T₀, M ⊄ T₁, M ⊄ S, M ⊄ L, M ⊄ M.

  Для проверки функциональной полноты достаточно для каждого функции из M
  определить, к каким классам она принадлежит, и убедиться, что в каждом
  столбце таблицы есть хотя бы один минус (не принадлежит).

Таблица принадлежности для стандартных функций:

  Функция    | T₀ | T₁ | S  | L  | M
  -----------+----+----+----+----+----
  0          | +  | −  | −  | +  | +
  1          | −  | +  | −  | +  | +
  x          | +  | +  | +  | +  | +
  x̄          | −  | −  | +  | +  | −
  x∧y        | +  | +  | −  | −  | +
  x∨y        | +  | +  | −  | −  | +
  x⊕y        | +  | −  | −  | +  | −
  x~y        | −  | +  | −  | +  | −
  x|y        | −  | −  | −  | −  | −
  x↓y        | −  | −  | −  | −  | −

Следствие: {x|y} — полная система (штрих Шеффера не принадлежит ни одному классу).
Следствие: {x↓y} — полная система (стрелка Пирса не принадлежит ни одному классу).
