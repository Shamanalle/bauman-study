# Транскрибация билетов по физике (Сессия)

## Билет №1

### Вопросы и задачи (из основного бланка)
1. Сложение гармонических колебаний одинакового направления близких (но не равных) частот. Биения.
2. Адиабатический процесс. Уравнение Пуассона.
3. Однородный цилиндр радиусом 10 см и массой 1 кг начинает вращаться вокруг своей оси под действием момента сил M = γt², где γ = 5 Н·м/с². Найдите его угловую скорость через 5 с. Какова работа момента силы за это время?

### Теория 1: Сложение гармонических колебаний
Гармонические колебания — колебания, совершающиеся по закону синуса или косинуса.
Пусть A₁ = A₂ := A, ω₁ = ω, ω₂ = ω + Δω, Δω ≪ ω. Тогда:
x_Σ = x₁ + x₂ = 2A cos(Δω/2 * t) cos(ωt + Δω/2 * t)
Пренебрегая во втором сомножителе величиной Δω по сравнению с ω, получаем:
x_Σ = 2A |cos(Δω/2 * t)| cos(ωt + θ)
Если cos(Δω/2 * t) > 0, то θ = 0, если < 0, то θ = π.
Явление периодического изменения амплитуды при сложении близких частот называется биением.

### Теория 2: Адиабатический процесс
Процесс, происходящий без теплообмена с окружающей средой (δQ = 0).
Первое начало термодинамики: dU + δA = 0 ⇒ dU + PdV = 0.
Для идеального газа: dU = ν C_v dT, PV = ν RT ⇒ VdP + PdV = ν RdT.
Выражая dT = (VdP + PdV) / (ν R) и подставляя в уравнение первого начала:
C_v (VdP + PdV) + R PdV = 0 ⇒ C_v V dP + (C_v + R) PdV = 0.
С учетом соотношения Майера C_v + R = C_p:
C_v V dP + C_p P dV = 0 ⇒ dP/P + γ dV/V = 0, где γ = C_p / C_v.
Интегрируя, получаем уравнение Пуассона: PV^γ = const.
Значения γ: одноатомный (γ=5/3), двухатомный (γ=7/5), многоатомный (γ=4/3).

### Решение задачи №3
Дано: R = 0.1 м, m = 1 кг, M = γt², γ = 5 Н·м/с², t = 5 с.
Найти: ω - ?, A - ?.
1. Угловое ускорение: M = I_z ε ⇒ dω = (M / I_z) dt.
2. Угловая скорость: ω = ∫₀^t (γt² / I_z) dt = γt³ / (3 I_z).
3. Момент инерции цилиндра: I_z = mR² / 2.
4. Подставляя значения: ω = (2 * 5 * 5³) / (3 * 1 * (0.1)²) = 1250 / 0.03 ≈ 41667 рад/с.
5. Работа момента сил: A = ∫₀^t M ω dt = ∫₀^t γt² (2γt³ / 3mR²) dt = 2γ²t⁶ / 18mR² = γ²t⁶ / 9mR².
6. A = (5² * 5⁶) / (9 * 1 * (0.1)²) = (25 * 15625) / 0.09 ≈ 4340277 Дж ≈ 4340 кДж.
Ответ: ω ≈ 41667 рад/с, A ≈ 4340 кДж.

## Билет №2

### Вопросы и задачи
1. Свободные затухающие колебания. Дифференциальное уравнение. Его решение. Частота свободных затухающих колебаний. Время релаксации и логарифмический декремент затухания.
2. Тепловые машины. Холодильные машины. Второе начало термодинамики в формулировках Клаузиуса и Томсона (Кельвина).
3. Уравнение волны: ξ = 2 cos(0,5t + 2,65z + π/10), где ξ — в мм, t — в мс, z — в м. Найдите макс. скорость частиц, объемную плотность энергии и вектор Умова.

### Теория 1: Свободные затухающие колебания
Уравнение движения: m x'' = -kx - r x' ⇒ x'' + 2β x' + ω₀² x = 0, где β = r / (2m), ω₀² = k / m.
Решение: x(t) = A₀ e^{-βt} sin(ωt + φ), где ω = √(ω₀² - β²).
Время релаксации τ = 1 / β — время, за которое амплитуда убывает в e раз.
Логарифмический декремент затухания δ = ln(A(t) / A(t+T)) = βT = T / τ.

### Теория 2: Тепловые и холодильные машины
КПД тепловой машины: η = A / Q₁ = (Q₁ - Q₂) / Q₁ = 1 - Q₂ / Q₁.
Холодильный коэффициент: ε = Q₂ / A = Q₂ / (Q₁ - Q₂).
**Второе начало термодинамики:**
- Клаузиус: Теплота не может самопроизвольно переходить от холодного тела к горячему.
- Томсон: Невозможен процесс, единственным результатом которого была бы работа за счет охлаждения одного резервуара.

### Решение задачи №3
Дано: ξ = 2 cos(0.5t + 2.65z + π/10), ξ [мм], t [мс], z [м].
1. Приведение к СИ: A = 2 * 10⁻³ м, ω = 0.5 мс⁻¹ = 500 с⁻¹.
2. Макс. скорость частиц: v_max = Aω = 2 * 10⁻³ * 500 = 1 м/с.
3. Объемная плотность энергии: w = ρA²ω² sin²(...). Среднее значение: ⟨w⟩ = (1/2) ρA²ω².
4. Вектор Умова: j = w * v_волны. Скорость волны v = ω / k = 500 / 2.65 ≈ 188.7 м/с.
Ответ: v_max = 1 м/с, w = ρA²ω² sin²(...), j = w * v.

## Билет №3

### Вопросы и задачи
1. Время релаксации, логарифмический декремент затухания и добротность колебательной системы. Связь добротности с убылью энергии.
2. Число степеней свободы механической системы и молекул идеального газа. Внутренняя энергия идеального газа (вывод).
3. В момент t₁ = 10 с тело массой m = 2 кг начало движение из покоя под действием силы F = b/t, где b = 10 кг·м/с. В какой момент t₂ скорость станет v₂ = 5 м/с? Какова работа силы?

### Теория 1: Добротность
Добротность Q характеризует относительную убыль энергии за время T/(2π).
Q = π / δ = ω / (2β) = π / (βT).
Связь с энергией: (W₁ - W₂) / W ≈ 2π / Q (при малом затухании).

### Теория 2: Внутренняя энергия
Число степеней свободы i: одноатомный (3), двухатомный (5), многоатомный (6).
Средняя энергия молекулы: ⟨ε⟩ = (i/2) kT.
Внутренняя энергия газа массой m: U = (m / M) * (i/2) * RT.

### Решение задачи №3
Дано: t₁ = 10 с, v₁ = 0, m = 2 кг, F = b/t, b = 10 Н·с, v₂ = 5 м/с.
1. Второй закон Ньютона: m (dv/dt) = b/t ⇒ dv = (b / mt) dt.
2. Интегрирование: ∫₀^{v₂} dv = ∫_{t_1}^{t_2} (b / mt) dt ⇒ v₂ = (b / m) ln(t₂ / t₁).
3. Подстановка: 5 = (10 / 2) ln(t₂ / 10) ⇒ 1 = ln(t₂ / 10) ⇒ t₂ = 10 e ≈ 27.18 с.
4. Работа силы (по теореме об изменении кин. энергии): A = ΔE_k = mv₂²/2 - 0 = (2 * 5²) / 2 = 25 Дж.
Ответ: t₂ = 10 e с ≈ 27 с, A = 25 Дж.

## Билет №4

### Вопросы и задачи
1. Дифференциальное уравнение вынужденных колебаний. Зависимость амплитуды вынужденных колебаний от частоты вынуждающей силы. Резонанс.
2. Теплоёмкость. Теплоёмкость идеального газа в изохорическом и изобарическом процессах. Уравнение Майера.
3. Находящаяся в изображенном на рисунке положении конструкция, состоящая из шара радиусом R=l/2 и массой M=2m и тонкого стержня массой m и длиной l=0,7 м, в результате незначительного толчка, вышла из положения неустойчивого равновесия и начала переворачиваться. Найдите угловое ускорение конструкции в момент, когда она отклонилась на угол φ=30° от первоначального положения, если известно что она вращалась без трения вокруг неподвижной горизонтальной оси, проходящей через точку O. Центр шара совпадает с центром стержня.

### Решение задачи №3
Дано: R = l/2; M = 2m; m_ст = m; l = 0,7 м; φ = 30°.
Решение:
1. Момент инерции системы относительно точки O:
   I₀ = I_шара + I_стерж
   I_шара = (2/5)MR² + M(l/2)² = (2/5)(2m)(l/2)² + 2m(l/2)² = ml²/5 + ml²/2 = 7ml²/10
   I_стерж = ml²/12 + m(l/2)² = ml²/3
   I₀ = 7ml²/10 + ml²/3 = 31ml²/30
2. Момент сил: M = (M+m)g * (l/2) sinφ = 3mg * (l/2) sinφ = (3/2)mgl sinφ
3. Угловое ускорение: ε = M / I₀ = (45g sinφ) / (31l)
   ε = (45 * 10 * 0,5) / (31 * 0,7) ≈ 10,39 рад/с²
Ответ: 10,39 рад/с².

## Билет №5

### Вопросы и задачи
1. Радиус-вектор, скорость и ускорение материальной точки. Разложение ускорения на касательную и нормальную составляющие.
2. Понятие числа степеней свободы механической системы. Число степеней свободы молекул идеального газа. Внутренняя энергия идеального газа.
3. В сосуде объемом V₀ при температуре T₀ находилось ν молей аргона. Газ адиабатически расширили, уменьшив его температуру в α раз. Каким стал объём газа? Каковы средняя длина свободного пробега атомов аргона и коэффициент вязкости газа в конечном состоянии?

### Решение задачи №3
Дано: V₀, T₀, ν, T₁ = T₀/α, Ar (i=3), d, μ, Q=0.
Решение:
1. Адиабатный процесс (TV^{γ-1} = const): γ = 5/3 ⇒ T₀ V₀^{2/3} = T₁ V₁^{2/3} ⇒ V₁ = V₀ √(α³).
2. Длина свободного пробега: ⟨l⟩ = 1 / (√2 π d² n) = V₁ / (√2 π d² ν N_A).
3. Вязкость: η = (1/3) ρ ⟨l⟩ ⟨v⟩ = (1/3) (νμ / V₁) ⟨l⟩ √(8RT₁ / πμ) = 2 / (3π d² N_A) √(μRT₁ / π).
Ответ: V₁ = V₀ √(α³); ⟨l⟩ = V₁ / (√2 π d² ν N_A); η = 2 / (3π d² N_A) √(μRT₁ / π).

## Билет №7

### Вопросы и задачи
1. Связь между импульсом и энергией релятивистской частицы (вывод на основе известных выражений для полной энергии и релятивистского импульса).
2. Диффузия в идеальных газах. Уравнение диффузии, коэффициент диффузии.
3. Найдите собственную частоту малых колебаний конструкции, состоящей из тонкого стержня массой m и длиной l=2R и жестко присоединенного к нему шара радиусом R=32,8 см и массой M=2m. Конструкция совершает колебания вокруг горизонтальной оси через точку O. Центр шара совпадает с центром стержня.

### Теория 1: Импульс и энергия
Релятивистский импульс: p = (m_0 v) / sqrt(1 - v^2/c^2) = mv.
Полная энергия: W = mc^2 = (m_0 c^2) / sqrt(1 - v^2/c^2).
Инвариантное соотношение: W^2 - (pc)^2 = (m_0 c^2)^2.

### Теория 2: Диффузия
Первый закон Фика: j_n = -D (dn/dx), где D = (1/3) ⟨v⟩ λ — коэффициент диффузии.

### Решение задачи №7
Дано: l=2R, R=0,328 м, M=2m.
Момент инерции: I_k = I_ст + I_ш = (m l^2)/3 + ((2/5) M R^2 + M R^2) = (m l^2)/3 + (7/10) m l^2 = (31/30) m l^2.
Частота: ω_0 = sqrt((m g l_c) / I_k) = sqrt((15 g) / (31 l)) = sqrt((15 * 10) / (31 * 2 * 0,328)) ≈ 2,72 рад/с.
Ответ: 2,72 рад/с.

## Билет №9

### Вопросы и задачи
1. Основное уравнение МКТ. Средняя кинетическая энергия (вывод).
2. Импульс системы. Уравнение изменения импульса. Закон сохранения импульса.
3. Частица распалась на три с массами 0,8m; 0,6m; 0,4m и скоростями 0,6c; 0,8c; 0,6c. Найти массу исходной частицы.

### Теория 1: МКТ
p = (1/3) n m_0 ⟨v^2⟩ = (2/3) n ⟨ε⟩, где ⟨ε⟩ = (3/2) k T.

### Теория 2: Импульс
dP/dt = Σ F_внеш. Если Σ F_внеш = 0, то P = const.

### Решение задачи №9
Энергии осколков:
E_1 = (0,8m c^2) / sqrt(1 - 0,6^2) = (0,8 / 0,8) m c^2 = m c^2.
E_2 = (0,6m c^2) / sqrt(1 - 0,8^2) = (0,6 / 0,6) m c^2 = m c^2.
E_3 = (0,4m c^2) / sqrt(1 - 0,6^2) = (0,4 / 0,8) m c^2 = 0,5 m c^2.
Закон сохранения энергии: M c^2 = E_1 + E_2 + E_3 = (1 + 1 + 0,5) m c^2 = 2,5 m c^2.
