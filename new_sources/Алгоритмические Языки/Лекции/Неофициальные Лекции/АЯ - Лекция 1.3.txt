Явные конструкторы 
Явный конструктор – конструктор, для которого запрещён неявный вызов. 
Объявляется с помощью ключевого слова explicit. 
В строке 13 примера 1 приведён на первый взгляд очень странный код: объекту типа 
MyClass присваивается целочисленное значение. Данный код сработает: неявно будет вызван 
конструктор из строк 7-8. Поскольку у параметров есть значения по умолчанию, при вызове 
функции (в данном случае конструктора) эти параметры могут быть опущены. Присваиваемое 
значение попадает в первый параметр, остальные параметры получат значения по умолчанию.

2. 
inline-функции 
inline-функции («встроенные функции») – функции, вызов которых заменяется 
компилятором на исходный код функции («тело»). Объявляются с помощью ключевого слова 
inline перед объявлением функции. 
 
Пример 4. inline-функция 
1 
2 
3 
4 
inline int getFist(const std::pair<int, std::string>& pair) const 
{ 
 
return pair.first; 
} 
Плюс inline-функций в том, что их использование ускоряет работу программы, т.к. 
отсутствуют издержки на переход из одной функции в другую (разные функции лежат в разных 
областях памяти).

--- Page 3 ---
3 
Минус inline-функций в том, что возникает дублирование кода, т.к. исходный код 
подставляется под каждый вызов. По этой причине «встраивать» рекомендуется только 
короткие функции, которые не сильно увеличивают код вызывающей их программы и издержки 
на вызов которых сопоставимы с временем выполнения самой функции. 
Методы класса, определённые в заголовочном файле, являются встроенными сами по 
себе и не требуют ключевого слова inline.  
3. 
Константные и статические члены классов 
Поля и методы класса могут быть константными, т.е. неизменяемыми. Константные 
поля, как и обычные переменные, предваряются ключевым словом const. В случае 
объявления константного метода, const ставится в конце объявления функции (перед 
определением, если оно есть). Константные методы не могут менять значения полей класса. 
 
Пример 5. Объявление константной функции 
1 
void print(const Vector& vector) const; 
Классы также могут содержать статические поля и методы, «помеченные» ключевым 
словом static. Эти поля и методы существуют независимо от объектов класса и могут быть 
вызваны как через объект, так и через имя класса (с помощью оператора разрешения области 
видимости). Статические методы не могут менять поля класса, т.к. существуют независимо от 
объекта. В примере 6 приведён совершенно искусственный, зато лаконичный и наглядный 
пример использования статического поля в качестве счётчиков объектов типа SomeObject.

Перегрузка операторов как членов класса 
Большинство операторов возможно перегрузить как в качестве методов класса, так и в 
качестве внешних функций. При перегрузке бинарных операторов правый операнд передаётся 
как параметр функции, а левым выступает текущий объект. 
В примере 7 приведён пример перегрузки оператора сложения для класса, 
описывающего точку на плоскости. В примере 8 приведён пример перегрузки этого же 
оператора, но уже как внешней функции. Использование оператора сложения будет выглядеть 
одинаково, и результат будет одинаковым. Отмечу, что желание перегрузить оператор 
внешней функцией, слабый аргумент для того, чтобы делать поля публичными, и в данном 
примере «опубличивание» применяется исключительно для простоты примера.

Есть случаи, когда перегрузка должна быть членом класса – это перегрузка оператора 
присваивания (=), скобок (как круглых, так и квадратных), оператора ->. Их нельзя перегрузить 
внешними функциями. 
Иногда может требоваться несколько перегрузок одного оператора. Например, для точки 
из примеров выше можно перегрузить оператор сложения, принимающий в качестве правого 
параметра значение типа float, которое будет прибавляться к обеим координатам. Т.к. 
функции будут отличаться типами параметров, обе перегрузки будут рабочими. Но куда более 
частый вариант – это перегрузки, совпадающие по имени, типу данных и кол-ву параметров, но 
отличающиеся по константности. В примере 9 приведён как раз такой случай: присутствуют 
две перегрузки квадратных скобок – она неконстантная, а вторая константная. Первая нужна 
для модификации значений, полученных при обращении через квадратные скобки, а вторая – 
для того, чтобы была возможность оперировать квадратными скобками при работе с 
константным объектом (например, при передаче параметра в функцию по константной ссылке), 
т.к. константные объекты не могут использовать неконстантные методы.

функции.

5. 
Дружественные функции и классы 
Дружественные функции (friend-функции) – функции, имеющие доступ к полям класса 
с модификаторами private и protected, но не являющиеся членом класса. Объявляется 
внутри класса с ключевым словом friend. Может быть определена как внутри класса, так и 
вне его. 
Дружественные функции возникают тогда, когда функциям, необходим доступ к полям 
класса, но они не могут стать членами класса (с точки зрения инкапсуляции или по другим 
соображениям). И этот механизм, как следует из определения, нарушает принципы 
инкапсуляции. 
Дружественные функции не являются членами классов, а, следовательно, на них 
не распространяются модификаторы доступа. 
Наиболее частый пример использования дружественных функций – это объявление 
перегрузки оператора << для вывода на экран как дружественной функции. Поскольку слева от 
оператора должен стоять поток, этот оператор не стоит перегружать как член класса. А если у 
объекта много полей, которые нужно вывести на экран, при этом для многих из них не 
определены геттеры (ну нет в них необходимости в других случаях), может быть гораздо 
удобнее предоставить доступ к полям одной функции, а не добавлять кучу геттеров.  
В примере 10 перегрузка << объявлена как друг класса Point. Несмотря на то, что 
определена она вне класса, ей доступны приватные поля.

Функторы 
Функтор (функциональный объект) – объект, для которого перегружен оператор (), что 
позволяет работать с ним, как с функцией. 
В примере 12 два вектора сортируются с помощью функции compFunction и функтора 
comp соответственно. В первом случае третьим параметром в std::sort передаётся 
указатель на функцию (так функции можно передать в качестве параметров в другие функции, 
достаточно указать название функции), во втором – сам функтор.
