Итераторы 
1. Что это? 
Итераторы – это типы данных, позволяющие перебирать элементы (чаще всего, контейнеров). 
С итераторами явно вы сталкивались в ЛР5, когда знакомились с алгоритмами STL, а неявно 
сталкиваетесь каждый раз, когда используете range-based for для контейнеров. Думаю, никто не будет 
спорить с тем, что такой формат работы удобен, а возможность применять стандартные алгоритмы 
сильно упрощает работу. Но что делать, если вы используете свой тип для хранения набора данных, у 
которого итераторов нет? Определить свои конечно же! 
Что «под капотом» у итератора? В самом простом случае итератор является обёрткой над 
указателем. Тем не менее, он может быть и более сложным типом, главное чтобы обеспечивал 
требуемый функционал.  
В С++20 итераторы поменяли свой вид, теперь они основываются на концепциях. 
Современному С++ посвящён 3 семестр, так что пока знакомимся с «классическими» итераторами. 
2. Типы итераторов 
Итераторы с т.з. доступа на чтение можно расположить по иерархии (таблица 1). Каждый 
следующий итератор в иерархии добавляет к предыдущему новые операции или новые требования к 
уже имеющимся операциям.  
Особняком стоит Output iterator, который отвечает за изменение данных. Любой из 
итераторов на чтение может одновременно обладать свойствами Output iterator, тем самым 
поддерживая изменение данных. Такие итераторы называются изменяемыми. Итераторы, которые не 
являются Output iterator, называются неизменяемыми.

Итак, у итератора должна быть категория и using для 4 типов: тип значения, тип расстояния

Строка 11 – конструктор с параметрами. Поскольку класс не будет работать с ресурсами, в

Итераторы равны тогда, когда они указывают на один и тот же элемент. Таким образом, 
операторы сравнения сравнивают значения лежащих «под капотом» указателей. Оператор 
разыменования должен возвращать объект. Т.к. итератор является Output iterator, то возвращаем 
объект по ссылке. Объект получаем разыменованием указателя. Оператор -> должен предоставлять 
доступ к полям элемента при обращении по указателю. Так что возвращаем указатель.

return *_pos;

}

Далее определяем операторы инкремента и декремента. Как вы помните, они существуют в двух 
вариантах (префиксном и постфиксном). Для того, чтобы компьютер отличал префиксную версию от 
постфиксной, вводится фиктивный параметр типа int. Он не будет использоваться, поэтому ему не 
нужно даже имя. Префиксный вариант меняет значение указателя, а затем возвращает итератор с 
модифицированным значением. Постфиксный вариант модифицирует указатель, но возвращает 
итератор до модификации. 
Квадратные скобки позволяют получить элемент, стоящий на позиции index относительно 
текущей (на которую указывает _pos). Этот механизм аналогичен доступу к index’ому элементу 
массива, начинающегося с ячейки памяти, на которую указывает _pos. Оператор сложения позволяет 
получить новый итератор, указывающий на позицию, отстоящую от текущей на diff. Сложение с 
итератором слева может быть объявлено как внутри класса, так и вне его. Сложение с итератором 
справа (слева diff) должно быть внешней функцией. Его можно реализовать с помощью геттера для 
_pos или сделать дружественной функцией.

#include "String.h" 
 
String::String(const char* str) 
{ 
 
if ((str == nullptr) || (str[0] == '\0')) 
 
{ 
 
 
_len = 0; 
 
 
_capacity = 1; 
 
 
_symbols = new char[1]; 
 
} 
 
else 
 
{ 
 
 
size_t length = 0; 
 
 
while (str[length] != '\0') 
 
 
 
++length; 
 
 
_symbols = new char[length + 1]; 
 
 
_len = length; 
 
 
_capacity = length + 1; 
 
 
for (size_t i = 0; i < _len; ++i) 
 
 
 
_symbols[i] = str[i]; 
 
} 
} 
 
String::String(String const& other) : _len(other._len), _capacity(other._capacity) 
{ 
 
if (_capacity == 1) 
 
 
_symbols = new char[1]; 
 
else 
 
{ 
 
 
_symbols = new char[_capacity]; 
 
 
for (size_t i = 0; i < _len; ++i) 
 
 
 
_symbols[i] = other._symbols[i]; 
 
} 
} 
 
String& String::operator=(String const& other) 
{ 
 
if (this != &other) 
 
{ 
 
 
if (_capacity != other._capacity) 
 
 
{ 
 
 
 
delete[] _symbols; 
 
 
 
_capacity = other._capacity; 
 
 
 
_symbols = new char[_capacity]; 
 
 
} 
 
 
_len = other._len; 
 
 
for (size_t i = 0; i < _len; ++i) 
 
 
 
_symbols[i] = other._symbols[i]; 
 
} 
 
return *this; 
}
