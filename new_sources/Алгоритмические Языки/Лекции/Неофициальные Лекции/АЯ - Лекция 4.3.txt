Интеграция с IDE 
Поскольку основная пользовательская аудитория Git – разработчики, существует 
множество расширений для различных IDE, позволяющих работать с репозиториями, не 
выходя из IDE. Далее рассмотрена работа с GitHub в Visual Studio, CLion, XCode. Это не 
единственные варианты расширений, их множество, и вы можете использовать другие, 
более удобные лично вам. 
 Visual Studio (стр. 2-5) 
 CLion (стр. 6-9) 
 XCode (стр. 10-13) 
 Visual Studio Code 
 Eclipse (ч.1, ч.2, ч.3) 
 Code::Blocks 
Какие файлы нужно грузить в удалённый репозиторий? 
Файлы, в которых содержатся ресурсы проекта (исходный код, иконки и другие 
элементы оформления), а также файлы с конфигурациями для сборки. Исходный код 
содержится в файлах с расширениями .cpp, .h, .hpp, .c++, .h++. В каких файлах хранится 
конфигурация проекта, зависит от среды разработки. 
Что не стоит грузить в удалённый репозиторий? 
Файлы и каталоги, появившиеся в результате сборки проектов, служебные файлы 
сред разработки.

CLion 
В CLion Git уже интегрирован. Если возникают проблемы, убедитесь, что 
исполняемый файл найден. 
 
1. Добавьте в настройках свой аккаунт на GitHub. 
 
 
2. Чтобы создать репозиторий, нужно выбрать соответствующий пункт в меню

7 
 
 
 
3. Чтобы закоммитить файлы, нужно войти в меню проекта и выбрать «Commit 
Directory», отметить галочками файлы, которые должны войти в коммит, написать 
комментарий для коммита и нажать кнопку для коммита. 
 
 
4. Чтобы запушить проект на Github, нужно выбрать в меню системы контроля 
версий выбрать «Поделиться проектом на GitHub»

XCode 
В XCode Git уже интегрирован. 
1. В настройках XCode->Preferences добавьте свой аккаунт GitHub 
 
 
2. При создании проекта сразу проставляется галочка для создания репозитория 
 
3. Перейти в навигатор ресурсов и в меню по клику правой кнопкой мыши на 
«Remotes» выбрать «Create…Remote…»

--- Page 11 ---
11 
 
4. Создать удалённый репозиторий. 
 
5. В главном меню в пункте «Source Control» выбрать «Commit», выбрать файлы 
для коммита.
