# Теория: Контейнеры и алгоритмы STL в C++

Стандартная библиотека шаблонов (STL — Standard Template Library) содержит готовые реализации самых популярных структур данных и алгоритмов. Их использование значительно упрощает жизнь программиста.

В основе STL лежат три понятия: **Контейнеры**, **Итераторы** и **Алгоритмы**.

## 1. Контейнеры
Контейнер — это класс, который хранит в себе набор других объектов (элементов).

В данной лабораторной мы познакомились с двумя **последовательными** контейнерами (хранят элементы строго в том порядке, в котором их положили):

### `std::vector` (Вектор)
По сути, это **динамический массив**. 
- Все элементы лежат в памяти друг за другом (непрерывным блоком).
- Выделяет память "с запасом". Когда запас исчерпывается, выделяет новый кусок памяти в 1.5-2 раза больше, старые данные извлекает и **перемещает/копирует** на новое место.
- Плюсы: Очень быстрый доступ по индексу (`v[5]`). Очень быстрая вставка и удаление в конец (`push_back`).
- Минусы: Дорогая вставка/удаление в начало или середину (требует сдвига всех остальных элементов). Дорогая переаллокация памяти.

### `std::deque` (Двухсторонняя очередь, читается как "дек")
Вектор-подобная структура данных.
- Под капотом элементы лежат "чанками" (небольшими кусочками массивов), на которые есть массив указателей.
- Плюсы: Быстрая вставка элементов как в конец (`push_back`), так и в начало (`push_front`), без необходимости перемещать весь массив.
- Доступ по индексу чуть медленнее, чем у чистого вектора (надо сначала перескочить на нужный чанк по указателю), но все еще за O(1) и очень быстрый.

### `std::list` (Двунаправленный список)
Классический **двусвязный список**.
- Каждый элемент хранит указатели на предыдущий и следующий.
- Плюсы: Очень быстрая вставка/удаление в произвольную позицию (за O(1), если есть итератор).
- Минусы: Нет доступа по индексу. Для поиска n-го элемента надо пройти по цепочке.
- Сортировка: У `list` есть **собственный** метод `list::sort()` (нельзя использовать `std::sort`, т.к. он требует итераторы произвольного доступа).

## 2. Итераторы
Итератор — это "умный указатель" на элемент внутри контейнера STL. 
- `begin()` возвращает итератор на первый элемент.
- `end()` возвращает итератор на элемент, следующий за последним (конец контейнера).
Итераторы позволяют алгоритмам работать с *любыми* контейнерами одинаково.

## 3. Алгоритмы
Алгоритмы STL живут в заголовочном файле `<algorithm>`. Мы использовали два:

### 1) `std::sort`
```cpp
std::sort(vector.begin(), vector.end(), myCompareFunc);
```
Эта функция реализует быструю сортировку (QuickSort/IntroSort) под капотом за время O(N * log N). Чтобы функции `sort` было понятно, **по какому критерию** нужно сортировать объекты нашего класса (ведь она не умеет их просто сравнивать оператором `<`), мы передаем ей третьим параметром свою функцию-компаратор.

**Для `std::list`** алгоритм `std::sort` нельзя использовать, т.к. `std::list` предоставляет только двунаправленные итераторы, а не итераторы произвольного доступа. Вместо этого используется встроенный метод `list::sort()`.

### 2) `std::copy`
```cpp
std::copy(v.begin(), v.end(), d.begin());
```
Функция берет элементы из первого контейнера (от `begin` до `end`) и последовательно присваивает (оператор `=`) в другой. ВАЖНО: целевой контейнер `d` должен заранее иметь нужный размер для вставки, иначе произойдет переполнение (ведь copy не выделяет память, а просто перезаписывает ячейки). 
(Или можно использовать адаптеры вставки `std::back_inserter(d)`).

## 4. Конструктор копирования vs перемещения
В нашем классе есть поля `std::string`. Класс `std::string` хранит текст динамически.
- Если вызовется **конструктор копирования**, текст скопируется символ-за-символом. Это дорогая операция.
- Если мы помещаем в класс временный объект `string`, выгоднее вызвать **конструктор перемещения** (`&&`), который просто сворует указатель на этот текст (заберет себе ownership), оставив временный объект пустым. Обмен указателями работает за мгновенное O(1). Это крайне полезно, когда контейнер `std::vector` переполняется и решает переложить все свои данные в новую, расширенную память. Вектор воспользуется вашими конструкторами перемещения!
