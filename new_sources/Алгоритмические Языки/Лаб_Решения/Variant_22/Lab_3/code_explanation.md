# Разбор кода: Лабораторная работа 3 (Вариант 22)

Ниже представлен полный исходный код из `main.cpp` для удобного ознакомления. 
В последующих разделах этот код разбит на логические блоки с детальным объяснением конструкций наследования и полиморфизма.

## Полный исходный код программы
```cpp
#include <iostream>

using namespace std;

class Vec2D {
protected:
    double x, y;

public:
    Vec2D(double x, double y) : x(x), y(y) {}

    virtual void print() const {
        cout << "Вектор на плоскости (2D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ")" << endl;
    }

    virtual ~Vec2D() {}
};

class Vec3D : public Vec2D {
private:
    double z;

public:
    Vec3D(double x, double y, double z) : Vec2D(x, y), z(z) {}

    void print() const override {
        Vec2D::print();
        cout << "  Вектор в пространстве (3D):" << endl;
        cout << "  Координата z = " << z << endl;
        cout << "  Полные координаты: (" << x << ", " << y << ", " << z << ")" << endl;
    }
};

int main() {
    setlocale(LC_ALL, "Russian");

    cout << "=== Создание объектов ===" << endl;
    Vec2D v2(3.0, 4.0);
    Vec3D v3(1.0, 2.0, 5.0);

    cout << "\n=== Прямой вызов функций (объекты) ===" << endl;
    v2.print();
    cout << endl;
    v3.print();

    cout << "\n=== 1. СТАТИЧЕСКИЙ ПОЛИМОРФИЗМ (Статическое связывание) ===" << endl;

    Vec2D* ptr_v1 = &v2;
    Vec2D* ptr_v2 = &v3;

    cout << "\n[Явный вызов базового метода] ptr_v2->Vec2D::print():" << endl;
    ptr_v2->Vec2D::print();

    cout << "\n=== 2. ДИНАМИЧЕСКИЙ ПОЛИМОРФИЗМ (Динамическое связывание) ===" << endl;

    cout << "\nВызов ptr_v1->print() (указывает на Vec2D):" << endl;
    ptr_v1->print();

    cout << "\nВызов ptr_v2->print() (указывает на Vec3D):" << endl;
    ptr_v2->print();

    return 0;
}

```

---

## 1. Базовый Класс `Vec2D`

```cpp
class Vec2D {{
protected:
    double x, y;
```
- Поля `x` и `y` (координаты конца вектора) объявлены как **`protected`**. Начало вектора находится в точке (0, 0), поэтому `x` и `y` определяют направление и длину вектора.
- `protected` позволяет наследнику `Vec3D` напрямую обращаться к этим полям, но запрещает доступ из `main()`.

```cpp
public:
    Vec2D(double x, double y) : x(x), y(y) {{}}
```
- Конструктор с **списком инициализации**. Параметры `x` и `y` копируются в одноимённые поля класса.

```cpp
    virtual void print() const {{
        cout << "Вектор на плоскости (2D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ")" << endl;
    }}
```
- **Виртуальный** метод печати координат. `virtual` позволяет наследнику переопределить этот метод.
- **`const`** означает, что метод только читает данные объекта, не изменяя их.

```cpp
    virtual ~Vec2D() {{}}
```
- **Виртуальный деструктор** обязателен для базовых классов. Без него при удалении объекта `Vec3D` через указатель `Vec2D*` может произойти утечка памяти.

---

## 2. Производный Класс `Vec3D`

```cpp
class Vec3D : public Vec2D {{
private:
    double z;
```
- `Vec3D` наследует `x` и `y` от `Vec2D` и добавляет третью координату `z`.

```cpp
    Vec3D(double x, double y, double z) : Vec2D(x, y), z(z) {{}}
```
- Конструктор вызывает `Vec2D(x, y)` для инициализации родительской части, затем инициализирует `z`.

```cpp
    void print() const override {{
        Vec2D::print();
        cout << "  Вектор в пространстве (3D):" << endl;
        cout << "  Координата z = " << z << endl;
        cout << "  Полные координаты: (" << x << ", " << y << ", " << z << ")" << endl;
    }}
```
- **Ключевой момент по заданию:** внутри переопределённой функции **в первую очередь вызывается** `Vec2D::print()`. Это выводит «Вектор на плоскости (2D): Координаты: (x, y)», после чего `Vec3D` дополняет вывод координатой z и полными 3D-координатами.
- **`override`** проверяет, что мы действительно переопределяем виртуальный метод родителя.
- Поля `x` и `y` доступны без геттеров благодаря `protected`.

## 3. Полиморфизм в `main`

```cpp
    Vec2D v2(3.0, 4.0);
    Vec3D v3(1.0, 2.0, 5.0);
```
- Создаются два объекта: 2D-вектор (3, 4) и 3D-вектор (1, 2, 5).

```cpp
    Vec2D* ptr_v1 = &v2;
    Vec2D* ptr_v2 = &v3;
```
- Оба указателя имеют тип `Vec2D*` (базовый класс). Но `ptr_v2` указывает на `Vec3D`. Это разрешено — 3D-вектор **является** расширенным 2D-вектором.

### Статическое связывание
```cpp
    ptr_v2->Vec2D::print();
```
- Явная квалификация `Vec2D::print()` заставляет вызвать базовый метод. Будут выведены только координаты x и y, **без z**. Компилятор привязывает вызов на этапе компиляции.

### Динамическое связывание
```cpp
    ptr_v2->print();
```
- Без квалификации программа через **vtable** (таблицу виртуальных функций) определяет реальный тип объекта (`Vec3D`) и вызывает `Vec3D::print()`. Будет выведена **полная** информация, включая координату z.
- Это и есть главное преимущество виртуальных функций: один и тот же код (`ptr->print()`) работает по-разному в зависимости от реального типа объекта.
