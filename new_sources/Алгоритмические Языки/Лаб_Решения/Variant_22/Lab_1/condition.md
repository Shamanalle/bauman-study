# Условие лабораторной работы №1 (Вариант 22)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *22 % 27 = **22***.
- **Класс:** «Квартира (стоимость комнаты)» (`ApartmentRooms`).
- **Поля (private):** стоимость, количество комнат.
- **Метод:** определение средней стоимости одной комнаты.
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Напечатать квартиры, стоимость одной комнаты в которых не превышает заданной суммы (вводится с клавиатуры).
