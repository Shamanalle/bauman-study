# Условие лабораторной работы №4 (Вариант 30)

## Тема: Использование последовательных контейнеров STL и алгоритмов

**Цель работы:**
Освоить работу со стандартной библиотекой шаблонов (STL) в части последовательных контейнеров (`std::vector`, `std::deque`, `std::list`) и универсальных алгоритмов сортировки и копирования.

## Общее задание:
1. Разработать пользовательский класс согласно своему варианту. Класс должен содержать не менее трех-четырех полей различных типов, конструкторы (в том числе правильные конструкторы копирования и перемещения, если это необходимо), геттеры/сеттеры.
2. Подготовить текстовый файл `input.txt` с входными характеристиками нескольких объектов (не менее 5 строк). Перегрузить оператор потока ввода `>>` для этого класса, чтобы удобно считывать объекты из файла за один раз.
3. Процесс работы программы:
   - Прочитать данные из файла и добавить сгенерированные объекты в **исходный контейнер** №1 (добавлять с помощью методов последовательных контейнеров, таких как `push_back`).
   - Напечатать исходный контейнер (вывести объекты, в нем лежащие). (Для этого обязательно перегрузить оператор потока вставки `<<` для вашего пользовательского класса).
   - Отсортировать объекты в этом базовом контейнере согласно критерию (использовать алгоритм `std::sort` и написать собственный компаратор).
   - Распечатать отсортированный контейнер.
   - Скопировать данные из первого контейнера во **второй целевой контейнер** другого типа с помощью обобщенного алгоритма `std::copy`. Для целевого контейнера необходимо предварительно выделить нужное количество памяти.
   - Распечатать целевой скопированный контейнер.

## Индивидуальное задание (Вариант 30 из Таблицы 1):
1. **Название класса:** «Студент»
   - *Характеристики (поля):* ФИО, группа, номер зачётной книжки, массив 4-х оценок за сессию.
2. **Исходный контейнер (№1):** `std::deque`
3. **Целевой контейнер (№2):** `std::list`
4. **Критерий сортировки:** по ФИО.
