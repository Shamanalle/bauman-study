# Условие лабораторной работы №1 (Вариант 16)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *16 % 27 = **16***.
- **Класс:** «Выражение из целых чисел и знаков операций» (`Expression`).
- **Поля (private):** массив чисел, количество, массив знаков операций.
- **Метод:** вычисление результата (одинаковый приоритет операций).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Ввести несколько выражений и вывести результаты в обратном порядке.
