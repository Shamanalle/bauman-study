# Условие лабораторной работы №1 (Вариант 24)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *24 % 27 = **24***.
- **Класс:** «Книга в библиотеке» (`LibraryBook`).
- **Поля (private):** автор, название, количество экземпляров, количество читателей.
- **Метод:** определение средней длины очереди на чтение каждого экземпляра.
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Напечатать параметры книг и наиболее читаемую книгу.
