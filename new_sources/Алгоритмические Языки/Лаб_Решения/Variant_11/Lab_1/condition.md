# Условие лабораторной работы №1 (Вариант 11)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *11 % 27 = **11***.
- **Класс:** «Межсетевой экран (МЭ)» (`Firewall`).
- **Поля (private):** название, класс защищённости (1-5, 1 — высший).
- **Метод:** проверка пригодности для заданного класса (номер МЭ ≤ заданного).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести МЭ, подходящие для заданного класса защищённости (вводится с клавиатуры).
