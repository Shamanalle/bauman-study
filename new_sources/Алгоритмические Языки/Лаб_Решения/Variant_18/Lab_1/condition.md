# Условие лабораторной работы №1 (Вариант 18)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *18 % 27 = **18***.
- **Класс:** «Товар в магазине (с наценкой)» (`ProductMarkup`).
- **Поля (private):** наименование, количество, закупочная цена.
- **Метод:** определение стоимости с учётом заданного % прибыли.
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Напечатать параметры товаров и суммарную стоимость с наценкой (процент вводится с клавиатуры).
