# Разбор кода: Лабораторная работа 3 (Вариант 12)

Ниже представлен полный исходный код из `main.cpp` для удобного ознакомления. 
В последующих разделах этот код разбит на логические блоки с детальным объяснением конструкций наследования и полиморфизма.

## Полный исходный код программы
```cpp
#include <iostream>
#include <cmath>

using namespace std;

const double PI = 3.14159265358979;

class Circle {
protected:
    double r;

public:
    Circle(double r) : r(r) {}

    virtual void print() const {
        cout << "Круг:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь: " << PI * r * r << endl;
    }

    virtual ~Circle() {}
};

class Ellipse : public Circle {
private:
    double b;

public:
    Ellipse(double a, double b) : Circle(a), b(b) {}

    void print() const override {
        Circle::print();
        cout << "  Эллипс:" << endl;
        cout << "  Полуось a (из базового): " << r << endl;
        cout << "  Полуось b: " << b << endl;
        cout << "  Площадь эллипса: " << PI * r * b << endl;
    }
};

int main() {
    setlocale(LC_ALL, "Russian");

    cout << "=== Создание объектов ===" << endl;
    Circle ci(5.0);
    Ellipse el(4.0, 2.0);

    cout << "\n=== Прямой вызов функций (объекты) ===" << endl;
    ci.print();
    cout << endl;
    el.print();

    cout << "\n=== 1. СТАТИЧЕСКИЙ ПОЛИМОРФИЗМ (Статическое связывание) ===" << endl;

    Circle* ptr_c1 = &ci;
    Circle* ptr_c2 = &el;

    cout << "\n[Явный вызов базового метода] ptr_c2->Circle::print():" << endl;
    ptr_c2->Circle::print();

    cout << "\n=== 2. ДИНАМИЧЕСКИЙ ПОЛИМОРФИЗМ (Динамическое связывание) ===" << endl;

    cout << "\nВызов ptr_c1->print() (указывает на Circle):" << endl;
    ptr_c1->print();

    cout << "\nВызов ptr_c2->print() (указывает на Ellipse):" << endl;
    ptr_c2->print();

    return 0;
}

```

---

## 1. Базовый Класс `Circle`

```cpp
const double PI = 3.14159265358979;
```
- Глобальная константа π. Используется для вычисления площади круга (πr²) и площади эллипса (πab).

```cpp
class Circle {{
protected:
    double r;
```
- Поле `r` (радиус) объявлено как **`protected`**. Наследник `Ellipse` использует его в качестве первой полуоси (a), поэтому прямой доступ необходим. Из `main()` к нему обратиться нельзя.

```cpp
public:
    Circle(double r) : r(r) {{}}
```
- Конструктор с **списком инициализации**. Параметр и поле имеют одинаковые имена — компилятор различает их по контексту: в `: r(r)` левый `r` — поле класса, правый — параметр.

```cpp
    virtual void print() const {{
        cout << "Круг:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь: " << PI * r * r << endl;
    }}
```
- Виртуальный метод печати. Выводит радиус и площадь круга (πr²). **`virtual`** позволяет наследнику переопределить поведение для эллипса.

```cpp
    virtual ~Circle() {{}}
```
- Виртуальный деструктор — обязателен для корректного удаления объектов через базовый указатель.

## 2. Производный Класс `Ellipse`

```cpp
class Ellipse : public Circle {{
private:
    double b;
```
- `Ellipse` наследует радиус `r` (используется как первая полуось a) и добавляет вторую полуось `b`.

```cpp
    Ellipse(double a, double b) : Circle(a), b(b) {{}}
```
- Параметр `a` передаётся конструктору `Circle`, где сохраняется в поле `r`. Таким образом, `r` теперь хранит первую полуось эллипса, а `b` — вторую.

```cpp
    void print() const override {{
        Circle::print();
        cout << "  Эллипс:" << endl;
        cout << "  Полуось a (из базового): " << r << endl;
        cout << "  Полуось b: " << b << endl;
        cout << "  Площадь эллипса: " << PI * r * b << endl;
    }}
```
- **Ключевой момент задания:** `Circle::print()` вызывается первой — выводит радиус (полуось a) и площадь круга. Далее дополняется информацией об эллипсе и его площади (πab).
- Обратите внимание: площадь круга (πa²) и площадь эллипса (πab) — различаются, когда a ≠ b. При a = b эллипс вырождается в круг.
- **`override`** обеспечивает проверку корректности переопределения.

## 3. Полиморфизм в `main`

```cpp
    Circle ci(5.0);
    Ellipse el(4.0, 2.0);
```
- Круг с радиусом 5 (площадь ≈ 78.54) и эллипс с полуосями 4 и 2 (площадь ≈ 25.13).

```cpp
    Circle* ptr_c2 = &el;
```
- `Circle*` указывает на `Ellipse`. Эллипс — «расширенный круг» (добавлена вторая полуось).

### Статическое связывание
```cpp
    ptr_c2->Circle::print();
```
- Явная квалификация вызывает только `Circle::print()`. Будет выведен радиус 4 и площадь круга с этим радиусом (π×4² ≈ 50.27), информация о второй полуоси **потеряется**.

### Динамическое связывание
```cpp
    ptr_c2->print();
```
- Через vtable вызывается `Ellipse::print()`. Выводится полная информация: и данные круга (через `Circle::print()`), и дополнительные данные эллипса (вторая полуось, площадь πab).
