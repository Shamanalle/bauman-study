# Теория: Перегрузка стандартных операций в C++

В данной лабораторной работе изучается возможность распространения стандартных операций (таких как `+`, `=`, `[]`, `<<`, `>>` и других) на создаваемые пользователем объекты классов.

## 1. Зачем нужна перегрузка операторов?
В С++ стандартные типы, такие как `int` или `double`, "понимают", что делать, когда вы пишете `a + b`. Однако новые, написанные вами классы (например, класс `Vector` из ЛР2) по умолчанию не знают, как складываются, умножаются или присваиваются друг другу.

Чтобы мы могли писать элегантный код, например:
```cpp
Vector v1, v2;
Vector v3 = v1 + v2; // вместо вызова функций, например, v1.addWith(v2)
cout << v3; // вместо вызова v3.print()
```
В язык введен механизм перегрузки, который заставляет стандартные символы операций (операторы) работать по написанному нами сценарию.

## 2. Способы перегрузки операторов
Операторы можно перегрузить двумя основными способами:

1. **Как метод класса** (внутри класса). Тогда неявным первым (левым) операндом становится сам объект (`*this`), для которого вызывается оператор.
   *Обязательно* так перегружаются операторы `=`, `[]`, `()`, `->`.
   
   Пример (оператор `[]`):
   ```cpp
   double& operator[](int index) {
       return p[index];
   }
   ```

2. **Как глобальная (свободная) функция**, часто объявляемая в классе как дружественная (`friend`). Тогда функция получает все свои операнды явно через параметры.
   Этот способ крайне необходим, когда первым (левым) операндом выступает объект *чужого* класса, изменения в который мы не можем внести (например, `ostream` для `cout << v`, или обычный указатель `int*`).

## 3. Конструкторы и операторы Копирования и Перемещения
Если класс содержит dynamically allocated memory (через `new`), обязательно реализуется "Правило пяти": деструктор, копирующий конструктор, оператор копирующего присваивания, перемещающий конструктор, оператор перемещающего присваивания.

1. **Копирующее** (Copy Constructor / Copy Assignment) `(const Vector& V)`:
   Осуществляет *глубокое копирование*. Сначала в новой памяти выделяется место (через `new array[n]`), а затем значения из исходного объекта последовательно перезаписываются (копируются) в целевой объект. 
2. **Перемещающее** (Move Constructor / Move Assignment) `(Vector&& V)`:
   Появилось в С++11. Вместо дорогого копирования данных из временного объекта (например, возвращаемого функцией) происходит передача ("кража") указателя. Временный объект после этого остается пустым `nullptr`. Это значительно ускоряет программу при возврате больших объектов.
