# Условие лабораторной работы №1 (Вариант 1)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *1 % 27 = **1***.
- **Класс:** «Сотрудник предприятия» (`Employee`).
- **Поля (private):** ФИО, оклад, надбавка к окладу в %.
- **Метод:** вычисление зарплаты (оклад + процентная надбавка).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести параметры всех сотрудников и суммарную их зарплату.
