# Разбор кода: Лабораторная работа 3 (Вариант 1)

Ниже представлен полный исходный код из `main.cpp` для удобного ознакомления. 
В последующих разделах этот код разбит на логические блоки с детальным объяснением конструкций наследования и полиморфизма.

## Полный исходный код программы
```cpp
#include <iostream>
#include <cmath>

using namespace std;

class Vector2D {
protected:
    double x, y;

public:
    Vector2D(double x, double y) : x(x), y(y) {}

    virtual double length() const {
        return sqrt(x * x + y * y);
    }

    virtual void print() const {
        cout << "Вектор на плоскости (2D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ")" << endl;
        cout << "  Длина: " << length() << endl;
    }

    virtual ~Vector2D() {}
};

class Vector3D : public Vector2D {
private:
    double z;

public:
    Vector3D(double x, double y, double z) : Vector2D(x, y), z(z) {}

    double length() const override {
        return sqrt(x * x + y * y + z * z);
    }

    void print() const override {
        cout << "Вектор в пространстве (3D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ", " << z << ")" << endl;
        cout << "  Длина 2D-проекции: " << Vector2D::length() << endl;
        cout << "  Длина 3D: " << length() << endl;
    }
};

int main() {
    setlocale(LC_ALL, "Russian");

    cout << "=== Создание объектов ===" << endl;
    Vector2D v2(3.0, 4.0);
    Vector3D v3(1.0, 2.0, 2.0);

    cout << "\n=== Прямой вызов функций (объекты) ===" << endl;
    v2.print();
    cout << endl;
    v3.print();

    cout << "\n=== 1. СТАТИЧЕСКИЙ ПОЛИМОРФИЗМ (Статическое связывание) ===" << endl;

    Vector2D* ptr_v1 = &v2;
    Vector2D* ptr_v2 = &v3;

    cout << "\n[Явный вызов базового метода] ptr_v2->Vector2D::print():" << endl;
    ptr_v2->Vector2D::print();

    cout << "\n=== 2. ДИНАМИЧЕСКИЙ ПОЛИМОРФИЗМ (Динамическое связывание) ===" << endl;

    cout << "\nВызов ptr_v1->print() (указывает на Vector2D):" << endl;
    ptr_v1->print();

    cout << "\nВызов ptr_v2->print() (указывает на Vector3D):" << endl;
    ptr_v2->print();

    cout << "\nВызов ptr_v2->length() (указывает на Vector3D):" << endl;
    cout << "  Длина = " << ptr_v2->length() << endl;

    return 0;
}

```

## 1. Базовый Класс `Vector2D`

```cpp
class Vector2D {{
protected:
    double x, y;
```
- Ключевое слово **`class`** объявляет базовый класс для вектора на плоскости.
- Блок **`protected:`** означает, что поля `x` и `y` (координаты конца вектора) **закрыты** от прямого доступа из внешнего кода (из функции `main` написать `v.x = 5` нельзя), но при этом **доступны** классам-наследникам. Это принципиальное отличие от `private`, который закрывает доступ вообще для всех, включая наследников.

```cpp
public:
    Vector2D(double x, double y) : x(x), y(y) {{}}
```
- **Конструктор** со **списком инициализации** (`: x(x), y(y)`). Такая запись эквивалентна присвоению `this->x = x; this->y = y;` внутри тела конструктора, но является более эффективной и считается стандартной практикой в C++.

```cpp
    virtual double length() const {{
        return sqrt(x * x + y * y);
    }}
```
- Метод вычисляет длину вектора на плоскости по формуле √(x² + y²) с использованием функции `sqrt()` из заголовочного файла `<cmath>`.
- Ключевое слово **`virtual`** — это самое главное слово в теме полиморфизма. Оно указывает компилятору, что если кто-то позже унаследует этот класс, он **может переопределить** (*override*) эту функцию. Без `virtual` переопределение в наследнике не будет работать через указатели базового типа.
- Ключевое слово **`const`** после скобок параметров означает, что метод не изменяет внутреннее состояние (поля) объекта, а только читает их.

```cpp
    virtual void print() const {{
        cout << "Вектор на плоскости (2D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ")" << endl;
        cout << "  Длина: " << length() << endl;
    }}
```
- Виртуальный метод для печати параметров вектора. Обратите внимание, что внутри `print()` вызывается `length()` — и поскольку `length()` тоже виртуальный, при вызове через указатель будет вызвана правильная версия (2D или 3D) в зависимости от реального типа объекта.

```cpp
    virtual ~Vector2D() {{}}
```
- **Виртуальный деструктор**. Обязателен, если класс используется как базовый. Без него при удалении объекта наследника через указатель базового типа (`delete ptr`) деструктор наследника не будет вызван, что приведет к утечке памяти.

## 2. Производный Класс `Vector3D`

```cpp
class Vector3D : public Vector2D {{
```
- Запись **`: public Vector2D`** означает публичное наследование. Класс `Vector3D` получает все `public` и `protected` члены из `Vector2D`. То есть поля `x` и `y` доступны напрямую внутри `Vector3D`, но остаются недоступны из внешнего кода.

```cpp
private:
    double z;
```
- Дополнительное поле `z` — третья координата. Объявлено как `private`, т.к. никто больше от `Vector3D` наследоваться не будет.

```cpp
    Vector3D(double x, double y, double z) : Vector2D(x, y), z(z) {{}}
```
- Конструктор наследника **обязан** инициализировать родительскую часть. Поэтому мы **явно вызываем конструктор базового класса** `Vector2D(x, y)` в списке инициализации. Затем инициализируем собственное поле `z(z)`.
- Без явного вызова `Vector2D(x, y)` компилятор попытается вызвать конструктор без параметров `Vector2D()`, которого не существует, и выдаст ошибку компиляции.

```cpp
    double length() const override {{
        return sqrt(x * x + y * y + z * z);
    }}
```
- **Переопределённый** метод `length()`. Формула длины вектора в 3D: √(x² + y² + z²).
- Ключевое слово **`override`** (появилось в C++11) говорит компилятору: «Я хочу переопределить виртуальную функцию родителя. Проверь, чтобы имя и параметры точно совпадали». Если мы опечатаемся в имени — компилятор выдаст ошибку, а не молча создаст новую функцию.

```cpp
    void print() const override {{
        cout << "Вектор в пространстве (3D):" << endl;
        cout << "  Координаты: (" << x << ", " << y << ", " << z << ")" << endl;
        cout << "  Длина 2D-проекции: " << Vector2D::length() << endl;
        cout << "  Длина 3D: " << length() << endl;
    }}
```
- Переопределённая функция печати. Обратите внимание на **вызов базового метода** `Vector2D::length()` — это позволяет показать длину 2D-проекции вектора для сравнения с полной 3D-длиной.
- Доступ к полям `x` и `y` возможен напрямую, потому что они объявлены как `protected` в базовом классе.

## 3. Полиморфизм в `main`

```cpp
    Vector2D v2(3.0, 4.0);
    Vector3D v3(1.0, 2.0, 2.0);
```
- Создаются два объекта: вектор на плоскости (3, 4) с длиной 5, и вектор в пространстве (1, 2, 2) с длиной 3.

```cpp
    Vector2D* ptr_v1 = &v2;
    Vector2D* ptr_v2 = &v3;
```
- Оба указателя имеют тип `Vector2D*` (базовый класс). Но `ptr_v2` указывает на объект типа `Vector3D` (наследник). **Указатель базового типа может безопасно указывать на объект любого унаследованного типа** — это базовая фишка C++ и основа полиморфизма.

### Статическое связывание
```cpp
    ptr_v2->Vector2D::print();
```
- Мы **принудительно вызываем метод базового класса** в обход динамической диспетчеризации. Запись `Vector2D::print()` — это **явная квалификация** имени метода. Несмотря на то, что `ptr_v2` указывает на `Vector3D`, будет вызвана именно функция `Vector2D::print()`. Это статическое связывание (решение принимается на этапе компиляции).

### Динамическое связывание
```cpp
    ptr_v2->print();
```
- Поскольку `print()` помечен словом `virtual`, компилятор **не привязывает** вызов жестко. Во время работы программы она идет по указателю `ptr_v2`, заглядывает внутрь объекта `v3`, находит там «Таблицу виртуальных функций» и видит: реальный тип объекта — это `Vector3D`! Значит, нужно вызвать функцию `Vector3D::print()`. Это и есть динамический полиморфизм.

```cpp
    ptr_v2->length();
```
- Аналогично, `length()` вызовет `Vector3D::length()`, возвращая 3D-длину вектора, а не 2D-проекцию.
