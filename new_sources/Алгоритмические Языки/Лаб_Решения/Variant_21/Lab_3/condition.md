# Условие лабораторной работы №3 (Вариант 21)

## Тема: Наследование классов и Полиморфизм

**Цель работы:**
Изучить отношения между базовыми и производными классами в C++, а также понять механизмы реализации раннего (статического) и позднего (динамического) связывания вызовов функций.

## Общее задание:
1. Создать иерархию из двух классов (базового родителя и класса-наследника).
2. Класс-наследник должен использовать конструктор базового класса (передавая ему параметры через список инициализации конструктора).
3. В базовом классе определить виртуальные (virtual) функции. Переопределить эти функции (override) в наследнике.
4. Добавить в функции-члены вывод информации о том, для какого класса (базового или производного) произошел их вызов, и вывести значения всех полей объекта. Причем внутри переопределенной функции в наследнике в первую очередь должна вызываться функция из базового класса.
5. Инкапсулировать поля базового класса таким образом, чтобы защитить их от внешнего доступа (из метода main), но разрешить прямой доступ из производного класса-наследника (использовать модификатор `protected`).
6. В функции `main` продемонстрировать разницу между **статическим** (ранним) и **динамическим** (поздним) связыванием:
   - Создать указатели базового типа `Base*`.
   - Присвоить им адреса объектов производного типа (`Base* b = new Derived()`).
   - Осуществить вызовы виртуальных и невиртуальных методов и объяснить разницу.

## Индивидуальное задание:
- **Базовый класс:** «Вещественное число» (`RealNumber`)
  - *Поля (protected):* значение числа (double).
  - *Виртуальные методы:*
    1. Расчет модуля (абсолютного значения).
    2. Печать параметров.
- **Производный класс:** «Комплексное число» (`ComplexNumber`)
  - *Дополнительное поле:* мнимая часть комплексного числа.
  - *Переопределение методов:*
    1. Расчет модуля по формуле для комплексного числа (√(re² + im²)).
    2. Вывод комплексного числа в математическом формате (a + bi).
