# Условие лабораторной работы №6 (Вариант 21)

## Тема: Обработка исключений (Exceptions) в С++

**Цель работы:**
Освоить механизм безопасности и обработки ошибок времени выполнения: создание собственных классов-исключений, генерацию исключений (throw) и их перехват с помощью блоков try-catch.

## Общее задание:
1. Создать собственный класс исключительной ситуации, наследуемый от стандартного исключения.
2. Класс должен содержать приватные поля для хранения некорректных значений и метод `printErrorData()`.
3. Разработать целевой класс. В конструкторе реализовать валидацию параметров и генерацию исключения при недопустимых значениях.
4. В `main` продемонстрировать перехват через `try-catch`.

## Индивидуальное задание:
- Формула: *21 % 9 = **3***.
- **Целевой класс:** «Точка в пространстве внутри единичного куба» (`UnitCubePoint`). Координаты X, Y, Z ∈ [0, 1].
- **Исключение:** наследник `std::out_of_range`.
