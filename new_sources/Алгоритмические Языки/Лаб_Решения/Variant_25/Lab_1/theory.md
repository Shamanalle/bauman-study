# Теория: Классы и объекты в C++

## 1. Что такое класс
Класс — это пользовательский тип данных, объединяющий данные (**поля**) и функции для их обработки (**методы**). Переменные типа класса называются **объектами**.

```cpp
class MyClass {
private:
    int field1;     // Поле класса (данные)
public:
    void method();  // Метод класса (функция)
};
```

## 2. Инкапсуляция и модификаторы доступа
Инкапсуляция — принцип ООП, который скрывает внутреннее устройство объекта от внешнего мира. В C++ есть три уровня доступа:
- **`private`** — доступ только из методов самого класса (по умолчанию для `class`).
- **`public`** — доступ отовсюду (из `main`, из других классов).
- **`protected`** — доступ из класса и его наследников.

Поля обычно делают `private`, а методы — `public`. Для чтения приватных полей пишут **геттеры** (`getField()`).

## 3. Конструктор
Конструктор — специальный метод, имя которого совпадает с именем класса. Он не имеет типа возвращаемого значения и вызывается автоматически при создании объекта.
```cpp
class Apartment {
public:
    Apartment(double area, double price) {
        totalArea = area;
        pricePerSqm = price;
    }
};
```
Конструктор можно перегружать (иметь несколько версий с разным числом параметров).

## 4. Контейнер `vector`
`vector` — динамический массив из стандартной библиотеки C++. В отличие от обычного массива, `vector` автоматически управляет памятью и может менять свой размер.
```cpp
vector<Apartment> apartments;
apartments.push_back(Apartment(50.0, 1000.0));
```

## 5. Цикл `for` по диапазону (Range-based for)
```cpp
for (const auto& apt : apartments) {
    apt.print();
}
```
Автоматически проходит по всем элементам контейнера. `const auto&` берёт каждый элемент по константной ссылке (без копирования).

## 6. Ключевое слово `const` у методов
```cpp
void print() const { ... }
```
Означает, что метод не изменяет поля объекта. Такие методы можно вызывать у `const`-объектов.
