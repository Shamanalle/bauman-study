# Условие лабораторной работы №2 (Вариант 25)

## Тема: Перегрузка стандартных операций в C++

**Цель работы:** 
Освоить механизм перегрузки операций (operators overloading), а также управление динамической памятью через реализацию "Правила пяти" (Rule of Five) для классов в C++.

## Общее задание (для всех вариантов):
1. Разработать класс **`Vector`**.
   - Тип элементов динамического массива вектора — `double (вещественный)`.
2. Для класса `Vector` необходимо вручную реализовать управление памятью:
   - Конструктор по умолчанию (создающий пустой вектор).
   - Конструктор с параметрами (исходный массив и его размер).
   - **Конструктор копирования** (создающий независимую (глубокую) копию объекта-вектора).
   - **Конструктор перемещения** (для оптимизации перехвата указателей на память временных объектов).
   - Деструктор, освобождающий динамически выделенную память.
3. Перегрузить оператор присваивания:
   - **Оператор копирующего присваивания** (`=`).
   - **Оператор перемещающего присваивания** (`=`).
4. Перегрузить стандартные операции:
   - Оператор `[]` (для доступа к элементам массива по их индексу).
   - Обязательная перегрузка операторов потоков **`<<`** (для вывода вектора на экран / в файл) и **`>>`** (для ввода из консоли / из файла).
5. Продемонстрировать файловый ввод-вывод данных (использовать `input.txt` и `output.txt`).

## Индивидуальное задание (Вариант 25):
- **Операция:** Сложение (`+`) двух векторов одинаковой размерности.
- Каждый элемент результата равен сумме соответствующих элементов операндов.
- **Формат перегрузки:** `Vector + Vector → Vector`
