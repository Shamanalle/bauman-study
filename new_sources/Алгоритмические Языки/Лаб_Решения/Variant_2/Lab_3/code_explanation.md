# Разбор кода: Лабораторная работа 3 (Вариант 2)

Ниже представлен полный исходный код из `main.cpp` для удобного ознакомления. 
В последующих разделах этот код разбит на логические блоки с детальным объяснением конструкций наследования и полиморфизма.

## Полный исходный код программы
```cpp
#include <iostream>

using namespace std;

class Point2D {
protected:
    double x, y;

public:
    Point2D(double x, double y) : x(x), y(y) {}

    virtual void print() const {
        cout << "Точка на плоскости (2D):" << endl;
        cout << "  x = " << x << ", y = " << y << endl;
    }

    virtual ~Point2D() {}
};

class Point3D : public Point2D {
private:
    double z;

public:
    Point3D(double x, double y, double z) : Point2D(x, y), z(z) {}

    void print() const override {
        Point2D::print();
        cout << "  Точка в пространстве (3D):" << endl;
        cout << "  z = " << z << endl;
        cout << "  Полные координаты: (" << x << ", " << y << ", " << z << ")" << endl;
    }
};

int main() {
    setlocale(LC_ALL, "Russian");

    cout << "=== Создание объектов ===" << endl;
    Point2D p2(3.0, 4.0);
    Point3D p3(1.0, 2.0, 5.0);

    cout << "\n=== Прямой вызов функций (объекты) ===" << endl;
    p2.print();
    cout << endl;
    p3.print();

    cout << "\n=== 1. СТАТИЧЕСКИЙ ПОЛИМОРФИЗМ (Статическое связывание) ===" << endl;

    Point2D* ptr_p1 = &p2;
    Point2D* ptr_p2 = &p3;

    cout << "\n[Явный вызов базового метода] ptr_p2->Point2D::print():" << endl;
    ptr_p2->Point2D::print();

    cout << "\n=== 2. ДИНАМИЧЕСКИЙ ПОЛИМОРФИЗМ (Динамическое связывание) ===" << endl;

    cout << "\nВызов ptr_p1->print() (указывает на Point2D):" << endl;
    ptr_p1->print();

    cout << "\nВызов ptr_p2->print() (указывает на Point3D):" << endl;
    ptr_p2->print();

    return 0;
}

```

---

## 1. Базовый Класс `Point2D`

```cpp
class Point2D {{
protected:
    double x, y;
```
- Ключевое слово **`protected`** означает, что поля `x` и `y` (координаты точки) закрыты от прямого доступа извне (из `main`), но доступны классам-наследникам. Это промежуточный уровень между `private` (закрыто для всех, включая наследников) и `public` (открыто для всех).

```cpp
public:
    Point2D(double x, double y) : x(x), y(y) {{}}
```
- **Конструктор** использует **список инициализации** `: x(x), y(y)` для присвоения значений полям. Это более эффективный способ инициализации, чем присвоение в теле конструктора.

```cpp
    virtual void print() const {{
        cout << "Точка на плоскости (2D):" << endl;
        cout << "  x = " << x << ", y = " << y << endl;
    }}
```
- Метод `print()` объявлен как **`virtual`**. Это ключевое слово создает механизм динамической диспетчеризации: при вызове через указатель базового типа будет вызвана версия метода, соответствующая **реальному** типу объекта в памяти.
- Модификатор **`const`** после скобок означает, что метод не изменяет состояние объекта.

```cpp
    virtual ~Point2D() {{}}
```
- **Виртуальный деструктор** обязателен для базовых классов. Без него при удалении объекта наследника через указатель базового типа деструктор наследника не будет вызван, приводя к утечке памяти.

## 2. Производный Класс `Point3D`

```cpp
class Point3D : public Point2D {{
```
- **`: public Point2D`** — публичное наследование. `Point3D` получает все `public` и `protected` члены базового класса.

```cpp
private:
    double z;
```
- Дополнительное поле `z` — третья координата. Объявлено как `private`.

```cpp
    Point3D(double x, double y, double z) : Point2D(x, y), z(z) {{}}
```
- Конструктор наследника **обязан** инициализировать родительскую часть — `Point2D(x, y)`. Затем инициализируется собственное поле `z`.
- Без вызова `Point2D(x, y)` компилятор попытается вызвать конструктор по умолчанию `Point2D()`, которого нет, и выдаст ошибку.

```cpp
    void print() const override {{
        Point2D::print();
        cout << "  Точка в пространстве (3D):" << endl;
        cout << "  z = " << z << endl;
        cout << "  Полные координаты: (" << x << ", " << y << ", " << z << ")" << endl;
    }}
```
- **Переопределённый** метод `print()`. Ключевое слово `override` (С++11) обеспечивает проверку компилятором совпадения сигнатуры с базовым методом.
- **Важный момент по заданию:** внутри переопределённой функции **сначала вызывается** метод базового класса `Point2D::print()`. Это выводит информацию о координатах x и y, после чего добавляется информация о z.
- Поля `x` и `y` доступны напрямую, т.к. они `protected` в базовом классе.

## 3. Полиморфизм в `main`

```cpp
    Point2D p2(3.0, 4.0);
    Point3D p3(1.0, 2.0, 5.0);
```
- Создаются два объекта: 2D-точка (3, 4) и 3D-точка (1, 2, 5).

```cpp
    Point2D* ptr_p1 = &p2;
    Point2D* ptr_p2 = &p3;
```
- Оба указателя имеют тип `Point2D*` (базовый класс). Но `ptr_p2` фактически указывает на объект типа `Point3D` — это разрешено и является основой полиморфизма.

### Статическое связывание
```cpp
    ptr_p2->Point2D::print();
```
- **Явная квалификация** имени метода: `Point2D::print()`. Даже если `ptr_p2` указывает на `Point3D`, будет вызван именно метод `Point2D`. Компилятор на этапе компиляции жёстко привязывает вызов к `Point2D::print()`.

### Динамическое связывание
```cpp
    ptr_p2->print();
```
- Поскольку `print()` помечен словом `virtual`, программа во время выполнения заглядывает в **таблицу виртуальных функций** (vtable) объекта, находит реальный тип (`Point3D`) и вызывает `Point3D::print()`. Это динамический полиморфизм.
