# Условие лабораторной работы №3 (Вариант 2)

## Тема: Наследование классов и Полиморфизм

**Цель работы:**
Изучить отношения между базовыми и производными классами в C++, а также понять механизмы реализации раннего (статического) и позднего (динамического) связывания вызовов функций.

## Общее задание:
1. Создать иерархию из двух классов (базового родителя и класса-наследника).
2. Класс-наследник должен использовать конструктор базового класса (передавая ему параметры через список инициализации конструктора).
3. В базовом классе определить виртуальные (virtual) функции. Переопределить эти функции (override) в наследнике.
4. Внутри переопределенной функции в наследнике в первую очередь должна вызываться функция из базового класса.
5. Инкапсулировать поля базового класса с модификатором `protected`.
6. В функции `main` продемонстрировать разницу между **статическим** и **динамическим** полиморфизмом.

## Индивидуальное задание:
- **Базовый класс:** «Точка на плоскости» (`Point2D`)
  - *Поля (protected):* координаты точки x, y.
  - *Виртуальные методы:*
    1. Печать значений полей.
- **Производный класс:** «Точка в трехмерном пространстве» (`Point3D`)
  - *Дополнительное поле:* координата z.
  - *Переопределение методов:*
    1. Печать значений полей (внутри в первую очередь вызывается метод базового класса).
