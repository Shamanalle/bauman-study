# Условие лабораторной работы №1 (Вариант 2)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *2 % 27 = **2***.
- **Класс:** «Студент» (`Student`).
- **Поля (private):** ФИО, массив из m оценок за последнюю сессию.
- **Метод:** проверка возможности получения стипендии (все оценки без троек).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести на печать всех студентов, получающих стипендию.
