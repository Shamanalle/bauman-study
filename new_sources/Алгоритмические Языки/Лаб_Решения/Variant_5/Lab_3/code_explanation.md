# Разбор кода: Лабораторная работа 3 (Вариант 5)

Ниже представлен полный исходный код из `main.cpp` для удобного ознакомления. 
В последующих разделах этот код разбит на логические блоки с детальным объяснением конструкций наследования и полиморфизма.

## Полный исходный код программы
```cpp
#include <iostream>
#include <cmath>

using namespace std;

const double PI = 3.14159265358979;

class Circle {
protected:
    double r;

public:
    Circle(double r) : r(r) {}

    virtual double calculate() const {
        return PI * r * r;
    }

    virtual void print() const {
        cout << "Круг:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь: " << calculate() << endl;
    }

    virtual ~Circle() {}
};

class Sphere : public Circle {
public:
    Sphere(double r) : Circle(r) {}

    double calculate() const override {
        return (4.0 / 3.0) * PI * r * r * r;
    }

    void print() const override {
        cout << "Шар:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь круга (сечение): " << Circle::calculate() << endl;
        cout << "  Объём шара: " << calculate() << endl;
    }
};

int main() {
    setlocale(LC_ALL, "Russian");

    cout << "=== Создание объектов ===" << endl;
    Circle ci(5.0);
    Sphere sp(3.0);

    cout << "\n=== Прямой вызов функций (объекты) ===" << endl;
    ci.print();
    cout << endl;
    sp.print();

    cout << "\n=== 1. СТАТИЧЕСКИЙ ПОЛИМОРФИЗМ (Статическое связывание) ===" << endl;

    Circle* ptr_c1 = &ci;
    Circle* ptr_c2 = &sp;

    cout << "\n[Явный вызов базового метода] ptr_c2->Circle::print():" << endl;
    ptr_c2->Circle::print();

    cout << "\n[Явный вызов базового calculate()] ptr_c2->Circle::calculate():" << endl;
    cout << "  Результат (площадь круга): " << ptr_c2->Circle::calculate() << endl;

    cout << "\n=== 2. ДИНАМИЧЕСКИЙ ПОЛИМОРФИЗМ (Динамическое связывание) ===" << endl;

    cout << "\nВызов ptr_c1->print() (указывает на Circle):" << endl;
    ptr_c1->print();

    cout << "\nВызов ptr_c2->print() (указывает на Sphere):" << endl;
    ptr_c2->print();

    cout << "\nВызов ptr_c2->calculate() (указывает на Sphere):" << endl;
    cout << "  Результат (объём шара): " << ptr_c2->calculate() << endl;

    return 0;
}

```

## 1. Базовый Класс `Circle`

```cpp
const double PI = 3.14159265358979;
```
- Глобальная константа π. Используется в формулах площади круга и объёма шара.

```cpp
class Circle {{
protected:
    double r;
```
- Поле `r` (радиус круга) объявлено как **`protected`** — оно закрыто от прямого доступа из `main()`, но доступно классу-наследнику `Sphere`. Если бы мы использовали `private`, наследник не смог бы напрямую обращаться к `r`, и пришлось бы добавлять геттеры.

```cpp
public:
    Circle(double r) : r(r) {{}}
```
- Конструктор принимает радиус и инициализирует поле через **список инициализации** `: r(r)`. Запись выглядит необычно — параметр и поле называются одинаково, но компилятор различает их: в `: r(r)` левый `r` — это поле класса, правый — параметр конструктора.

```cpp
    virtual double calculate() const {{
        return PI * r * r;
    }}
```
- Виртуальный метод, вычисляющий площадь круга: S = πr².
- **`virtual`** позволяет наследнику `Sphere` переопределить этот метод для вычисления объёма вместо площади.
- **`const`** означает, что метод не изменяет состояние объекта.

```cpp
    virtual void print() const {{
        cout << "Круг:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь: " << calculate() << endl;
    }}
```
- Виртуальный метод печати. Внутри вызывается `calculate()` — благодаря виртуальности, при вызове через указатель базового типа будет вызвана правильная версия (площадь круга или объём шара).

```cpp
    virtual ~Circle() {{}}
```
- **Виртуальный деструктор** обязателен для базовых классов. Если через указатель `Circle*` удалить объект `Sphere`, виртуальный деструктор гарантирует корректное удаление.

## 2. Производный Класс `Sphere`

```cpp
class Sphere : public Circle {{
public:
    Sphere(double r) : Circle(r) {{}}
```
- `Sphere` наследуется от `Circle` публично. **Новых полей не добавляет** — шар определяется тем же радиусом, что и круг.
- Конструктор **передаёт** радиус конструктору базового класса `Circle(r)`. Без этого вызова компилятор попытался бы вызвать `Circle()` без аргументов, что приведёт к ошибке.

```cpp
    double calculate() const override {{
        return (4.0 / 3.0) * PI * r * r * r;
    }}
```
- Переопределённый метод. Вместо площади круга (πr²) вычисляет **объём шара**: V = (4/3)πr³.
- Обратите внимание на `4.0 / 3.0` — деление вещественных чисел. Если написать `4 / 3`, C++ выполнит целочисленное деление и результат будет 1, а не 1.333..., что приведёт к ошибочному расчёту.
- **`override`** гарантирует, что мы переопределяем виртуальный метод родителя.

```cpp
    void print() const override {{
        cout << "Шар:" << endl;
        cout << "  Радиус: " << r << endl;
        cout << "  Площадь круга (сечение): " << Circle::calculate() << endl;
        cout << "  Объём шара: " << calculate() << endl;
    }}
```
- Переопределённая печать. **Вызывает метод базового класса** `Circle::calculate()` для вычисления площади сечения (круга) и свой `calculate()` для объёма шара. Это демонстрирует, как можно использовать обе версии метода одновременно.

## 3. Полиморфизм в `main`

```cpp
    Circle ci(5.0);
    Sphere sp(3.0);
```
- Создаются два объекта: круг с радиусом 5 и шар с радиусом 3.

```cpp
    Circle* ptr_c1 = &ci;
    Circle* ptr_c2 = &sp;
```
- Оба указателя имеют тип `Circle*` (базовый класс). Но `ptr_c2` фактически указывает на `Sphere`. Это разрешено — шар **является** разновидностью круга (у него есть радиус и площадь сечения).

### Статическое связывание
```cpp
    ptr_c2->Circle::print();
    ptr_c2->Circle::calculate();
```
- Явная квалификация `Circle::` заставляет вызвать метод базового класса. `calculate()` вернёт площадь круга (πr² ≈ 28.27), а не объём шара.
- Компилятор на этапе компиляции жёстко привязывает вызов к методу `Circle`.

### Динамическое связывание
```cpp
    ptr_c2->print();
    ptr_c2->calculate();
```
- Без квалификации программа использует **таблицу виртуальных функций** (vtable) объекта. Реальный тип объекта — `Sphere`, поэтому вызываются методы `Sphere`. `calculate()` вернёт объём шара ((4/3)πr³ ≈ 113.1).
