# Условие лабораторной работы №7 (Вариант 20)

## Тема: Многопоточное программирование в C++

**Цель работы:**
Ознакомиться с многопоточностью в C++: создавать потоки с помощью `std::thread`, работать с `std::async`/`std::future`, освоить синхронизацию через `std::mutex` и `std::lock_guard`.

## Общее задание:
1. Разработать приложение с тремя дочерними потоками.
2. Программа запускается двумя способами: `std::thread` + `join()` и `std::async` + `future::wait()`.
3. Синхронизация вывода через `std::mutex` и `std::lock_guard`.
4. Задержка `sleep_for` для наглядности конкуренции потоков.

## Индивидуальное задание (Вариант 20):
- Формула: *20 % 5 = **5***.
- **Сценарий потоков (Задание №5):**
  - Поток 1: сортирует первую половину массива. Поток 2: сортирует вторую половину. Поток 3: сортирует весь массив после завершения 1 и 2. Метод сортировки: **прямого включения (Insertion Sort)**.
