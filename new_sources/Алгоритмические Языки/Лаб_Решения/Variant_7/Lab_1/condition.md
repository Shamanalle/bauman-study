# Условие лабораторной работы №1 (Вариант 7)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *7 % 27 = **7***.
- **Класс:** «Автомобиль» (`Car`).
- **Поля (private):** марка, максимальная скорость (км/ч).
- **Метод:** фильтрация по скорости.
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести автомобили, скорость которых превышает заданное значение (вводится с клавиатуры).
