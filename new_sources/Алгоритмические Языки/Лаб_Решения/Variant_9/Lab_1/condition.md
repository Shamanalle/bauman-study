# Условие лабораторной работы №1 (Вариант 9)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *9 % 27 = **9***.
- **Класс:** «Полином an*x^n + ... + a1*x + a0» (`Polynomial`).
- **Поля (private):** степень n, массив коэффициентов.
- **Метод:** вычисление значения полинома при заданном x.
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести параметры полиномов и сумму их значений при заданном x (вводится с клавиатуры).
