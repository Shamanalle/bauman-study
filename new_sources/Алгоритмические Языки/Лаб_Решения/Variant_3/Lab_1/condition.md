# Условие лабораторной работы №1 (Вариант 3)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *3 % 27 = **3***.
- **Класс:** «Банковский вклад» (`BankDeposit`).
- **Поля (private):** ФИО владельца, текущая сумма, годовая процентная ставка.
- **Метод:** расчёт суммы на счёте через заданное число лет (с капитализацией).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести параметры всех вкладов и суммарную сумму через заданное число лет (вводится с клавиатуры).
