# Условие лабораторной работы №1 (Вариант 4)

## Тема: Введение в классы и объекты

**Цель работы:**
Ознакомиться с базовыми концепциями ООП: инкапсуляция, классы, объекты, конструкторы и методы.

## Задание по варианту:
- Формула: *4 % 27 = **4***.
- **Класс:** «Аппаратно-программное средство защиты от НСД» (`SecurityTool`).
- **Поля (private):** название, номер класса защищённости (1-7, 1 — высший).
- **Метод:** проверка, подходит ли СЗ для заданного класса (номер СЗ ≤ заданного).
- **В `main`:** создать `vector` объектов, заполнить данными, напечатать параметры.
- **Действие:** Вывести СЗ, подходящие для заданного класса защищённости (вводится с клавиатуры).
