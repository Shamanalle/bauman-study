Полный курс: интегралы + ОДУ · 6 позиций
1. Таблица интегралов + методы (Комплект 1)
$\int x^n dx = \frac{x^{n+1}}{n+1}+C, \quad \int \frac{dx}{x} = \ln|x|+C$
$\int e^x dx = e^x+C, \quad \int a^x dx = \frac{a^x}{\ln a}+C$
$\int \sin x\,dx = -\cos x+C, \quad \int \cos x\,dx = \sin x+C$
$\int \frac{dx}{\cos^2 x} = \tan x+C, \quad \int \frac{dx}{\sin^2 x} = -\cot x+C$
$\int \frac{dx}{1+x^2} = \arctan x+C, \quad \int \frac{dx}{\sqrt{1-x^2}} = \arcsin x+C$
$\int \frac{dx}{a^2+x^2} = \frac{1}{a}\arctan\frac{x}{a}+C$
$\int \frac{dx}{a^2-x^2} = \frac{1}{2a}\ln\left|\frac{a+x}{a-x}\right|+C$
$\int \frac{dx}{\sqrt{x^2\pm a^2}} = \ln|x+\sqrt{x^2\pm a^2}|+C$
Правило ЛИАП (для по частям): Лог → Инверс.триг → Алгебра → Периодическ.
Универсальная подст.: $t = \tan(x/2)$
2. Геометрические приложения (Комплект 2)
Площадь (декарт.): $S = \int_a^b|f(x)-g(x)|dx$
Площадь (полярн.): $S = \frac{1}{2}\int_\alpha^\beta \rho^2 d\varphi$
Объём (вокруг Ox): $V = \pi\int_a^b f^2(x)dx$
Объём (вокруг Oy): $V = 2\pi\int_a^b x|f(x)|dx$
Длина (декарт.): $L = \int_a^b\sqrt{1+(y')^2}dx$
Длина (полярн.): $L = \int_\alpha^\beta\sqrt{\rho^2+(\rho')^2}d\varphi$
Площадь поверхности: $S = 2\pi\int|y|\sqrt{1+(y')^2}dx$
3. Несобственные интегралы (Комплект 3)
Эталоны:
$\int_1^\infty \frac{dx}{x^p}$: сх. $p>1$, расх. $p \le 1$
$\int_0^1 \frac{dx}{x^p}$: сх. $p<1$, расх. $p \ge 1$
Предельный признак: $\lim\frac{f}{g} = L \neq 0$ → одновр. сх./расх.
Абс. сходимость: если $\int|f|$ сх. → $\int f$ сх.
4. ДУ с понижением порядка (Комплект 4)
Не содержит $y$ явно: $F(x,y',y'')=0$
Замена $p = y'$, $p' = y''$. ДУ 1-го порядка для $p(x)$.
Не содержит $x$ явно: $F(y,y',y'')=0$
Замена $y' = p(y)$, $y'' = p\cdot p'_y$. ДУ 1-го порядка для $p(y)$.
После нахождения $p$ → $y' = p$ → интегрируем.
5. Линейные ДУ высших порядков (Комплект 5)
Хар. уравнение: $\lambda^n + a_{n-1}\lambda^{n-1}+\ldots+a_0=0$
ФСР: действ. $\lambda$ → $e^{\lambda x}$; кратн. $k$ → $x^j e^{\lambda x}$; компл. $\alpha\pm i\beta$ → $e^{\alpha x}\cos\beta x,\;e^{\alpha x}\sin\beta x$
Подбор частного: $f = e^{\alpha x}P_n(x)$ → $\tilde{y} = x^s e^{\alpha x}Q_n(x)$
где $s$ = кратность $\alpha$ как корня хар. ур.
$f = e^{\alpha x}[P\cos\beta x + R\sin\beta x]$ → $\tilde{y} = x^s e^{\alpha x}[Q\cos\beta x + T\sin\beta x]$
где $s$ = кратность $\alpha+i\beta$
6. Метод вариации постоянных (Комплект 6)
Для $y''+py'+qy=f(x)$:
1. Решить однородное → ФСР $y_1, y_2$
2. $y = C_1(x)y_1+C_2(x)y_2$
3. Система:
$\begin{cases}C_1'y_1+C_2'y_2=0\\C_1'y_1'+C_2'y_2'=f(x)\end{cases}$
4. $C_1' = -\frac{y_2 f}{W}$, $C_2' = \frac{y_1 f}{W}$
5. Интегрируем $C_1', C_2'$
