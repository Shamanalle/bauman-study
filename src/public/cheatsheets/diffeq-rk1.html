Определённые интегралы, методы интегрирования · 9 позиций
1. Площадь в декартовых координатах
Площадь между двумя кривыми:
$S = \int_a^b |f(x) - g(x)|\,dx$
Площадь в параметрической форме ($x = x(t)$, $y = y(t)$):
$S = \int_{t_1}^{t_2} y(t)\,x'(t)\,dt$
2. Площадь в полярных координатах
Площадь криволинейного сектора $\rho = \rho(\varphi)$, $\varphi \in [\alpha, \beta]$:
$S = \frac{1}{2}\int_\alpha^\beta \rho^2(\varphi)\,d\varphi$
3. Объём тела вращения
Вокруг оси Ox (метод дисков):
$V = \pi\int_a^b f^2(x)\,dx$
Вокруг оси Oy (метод оболочек):
$V = 2\pi\int_a^b x|f(x)|\,dx$
Параметрически:
$V = \pi\int_{t_1}^{t_2} y^2(t)\,x'(t)\,dt$
В полярных (вокруг полярной оси):
$V = \frac{2\pi}{3}\int_\alpha^\beta \rho^3(\varphi)\sin\varphi\,d\varphi$
4. Длина дуги кривой
Декартовы (y = f(x)):
$L = \int_a^b \sqrt{1 + (f'(x))^2}\,dx$
Параметрически:
$L = \int_{t_1}^{t_2} \sqrt{(x'(t))^2 + (y'(t))^2}\,dt$
Полярные:
$L = \int_\alpha^\beta \sqrt{\rho^2 + (\rho')^2}\,d\varphi$
5. Площадь поверхности вращения
Вокруг оси Ox:
$S = 2\pi\int_a^b |f(x)|\sqrt{1 + (f'(x))^2}\,dx$
Параметрически:
$S = 2\pi\int_{t_1}^{t_2} |y(t)|\sqrt{(x')^2 + (y')^2}\,dt$
6. Несобственные интегралы — признаки сходимости
Эталонные:
$\int_1^{+\infty}\frac{dx}{x^p}: \text{сх. при } p > 1, \text{ расх. при } p \le 1$
$\int_0^1 \frac{dx}{x^p}: \text{сх. при } p < 1, \text{ расх. при } p \ge 1$
Признак сравнения:
$0 \le f(x) \le g(x)$: если $\int g$ сх. → $\int f$ сх.; если $\int f$ расх. → $\int g$ расх.
Предельный признак:
$\lim_{x \to +\infty}\frac{f(x)}{g(x)} = L \neq 0$ → оба сходятся или оба расходятся.
Абсолютная сходимость:
Если $\int|f|$ сх. → $\int f$ сх. (абсолютно).
7. Формулы Валлиса (Wallis)
Для нечётного $n$:
$\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx = \frac{(n-1)!!}{n!!}$
Для чётного $n$:
$\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx = \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2}$
Произведение $\sin^m x \cos^n x$:
$\int_0^{\pi/2}\sin^m x \cos^n x\,dx = \frac{(m-1)!!(n-1)!!}{(m+n)!!} \cdot \begin{cases}\frac{\pi}{2} & \text{m, n — оба чётные}\\1 & \text{иначе}\end{cases}$
Факториалы: $n!! = n(n-2)(n-4)\ldots$, причём $0!! = 1!! = 1$.
Интеграл от 0 до $\pi$:
$\int_0^\pi \sin^n x\,dx = 2\int_0^{\pi/2}\sin^n x\,dx \text{ (для любого n)}$
$\int_0^\pi \cos^n x\,dx = 0 \text{ (для нечётного n)}$
8. Понижение степени тригонометрических функций
Основные формулы:
$\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}$
$\sin x \cos x = \frac{\sin 2x}{2}$
Формулы произведений:
$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$
$\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha-\beta)+\cos(\alpha+\beta)]$
$\sin\alpha\sin\beta = \frac{1}{2}[\cos(\alpha-\beta)-\cos(\alpha+\beta)]$
9. Гиперболические функции и подстановки
Основные:
$\sinh x = \frac{e^x - e^{-x}}{2}, \quad \cosh x = \frac{e^x + e^{-x}}{2}$
$\cosh^2 x - \sinh^2 x = 1$
Обратные:
$\text{arcsh}\,x = \ln(x + \sqrt{x^2+1})$
$\text{arcch}\,x = \ln(x + \sqrt{x^2-1})$
Когда использовать:
• $\sqrt{1+t^2}$ → замена $t = \sinh u$, тогда $\sqrt{1+t^2} = \cosh u$
• $\sqrt{t^2-1}$ → замена $t = \cosh u$
