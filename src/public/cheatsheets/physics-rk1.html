⚛️ Физика · РК-1 · Формулы

Механика: кинематика, динамика, энергия, импульс, колебания · 11 позиций
1. Кинематика материальной точки
Вектор перемещения:
$\vec{\Delta r} = \vec{r}(t_2) - \vec{r}(t_1)$
Мгновенная скорость:
$\vec{v} = \frac{d\vec{r}}{dt}$
Мгновенное ускорение:
$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$
Тангенциальное ускорение (изменяет модуль скорости):
$a_\tau = \frac{dv}{dt}$
Нормальное ускорение (изменяет направление):
$a_n = \frac{v^2}{R}$
Полное ускорение:
$a = \sqrt{a_\tau^2 + a_n^2}$
2. Вращательное движение
Угловая скорость и ускорение:
$\omega = \frac{d\varphi}{dt}, \qquad \varepsilon = \frac{d\omega}{dt} = \frac{d^2\varphi}{dt^2}$
Связь с линейными величинами:
$v = \omega R, \qquad a_\tau = \varepsilon R, \qquad a_n = \omega^2 R$
Период и частота:
$T = \frac{2\pi}{\omega}, \qquad \nu = \frac{1}{T} = \frac{\omega}{2\pi}$
Равноускоренное вращение:
$\omega = \omega_0 + \varepsilon t, \qquad \varphi = \omega_0 t + \frac{\varepsilon t^2}{2}$
3. Законы Ньютона и типы сил
II закон Ньютона:
$\vec{F} = m\vec{a} \qquad \text{или} \qquad \frac{d\vec{p}}{dt} = \vec{F}$
Сила упругости (Гук):
$F = -kx$
Сила трения скольжения:
$F_{\text{тр}} = \mu N$
Закон всемирного тяготения:
$F = G\frac{m_1 m_2}{r^2}, \quad G \approx 6{,}67 \cdot 10^{-11}\;\text{Н·м}^2/\text{кг}^2$
Сила сопротивления среды:
$\vec{F}_{\text{сопр}} = -b\vec{v}$
4. Импульс и закон сохранения
Импульс тела:
$\vec{p} = m\vec{v}$
II закон Ньютона (импульсная форма):
$\frac{d\vec{p}}{dt} = \vec{F}_{\text{внеш}}$
Закон сохранения импульса (при $\vec{F}_{\text{внеш}} = 0$):
$\sum m_i \vec{v}_i = \text{const}$
Центр масс:
$\vec{r}_C = \frac{\sum m_i \vec{r}_i}{\sum m_i}$

6. Момент силы и момент импульса
Момент силы:
$\vec{M} = \vec{r} \times \vec{F}, \qquad M = Fd$
Момент импульса:
$\vec{L} = \vec{r} \times \vec{p} = I\vec{\omega}$
Уравнение моментов:
$\frac{d\vec{L}}{dt} = \vec{M}_{\text{внеш}}$
Основное уравнение динамики вращения:
$I\varepsilon = M$
Закон сохранения момента импульса (при $M_{\text{внеш}} = 0$):
$I_1\omega_1 = I_2\omega_2$
7. Работа и энергия
Работа:
$A = \int \vec{F} \cdot d\vec{r}$
Кинетическая энергия:
$E_k = \frac{mv^2}{2}, \qquad E_k^{\text{вращ}} = \frac{I\omega^2}{2}$
Полная кинетическая энергия (поступательное + вращательное):
$E_k = \frac{mv_C^2}{2} + \frac{I_C\omega^2}{2}$
Потенциальная энергия:
$W_{\text{гр}} = mgh, \quad W_{\text{упр}} = \frac{kx^2}{2}$
Связь силы и потенциальной энергии:
$\vec{F} = -\text{grad}\,W = -\left(\frac{\partial W}{\partial x}, \frac{\partial W}{\partial y}, \frac{\partial W}{\partial z}\right)$
Теорема о кинетической энергии:
$A = \Delta E_k$
Закон сохранения механической энергии:
$E_k + W_{\text{пот}} = \text{const}$
8. Столкновения
Абсолютно упругий удар (центральный):
$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1 + \frac{2m_2}{m_1 + m_2}v_2$
$v_2' = \frac{2m_1}{m_1 + m_2}v_1 + \frac{m_2 - m_1}{m_1 + m_2}v_2$
Абсолютно неупругий удар:
$u = \frac{m_1 v_1 + m_2 v_2}{m_1 + m_2}$
Потеря энергии при неупругом ударе:
$|\Delta E_k| = \frac{m_1 m_2}{2(m_1+m_2)}(v_1 - v_2)^2$
9. Гармонические колебания
Уравнение и решение:
$\ddot{x} + \omega_0^2 x = 0 \quad \Rightarrow \quad x = A\cos(\omega_0 t + \varphi_0)$
Пружинный маятник:
$\omega_0 = \sqrt{\frac{k}{m}}, \quad T = 2\pi\sqrt{\frac{m}{k}}$
Математический маятник:
$\omega_0 = \sqrt{\frac{g}{l}}, \quad T = 2\pi\sqrt{\frac{l}{g}}$
Физический маятник:
$\omega_0 = \sqrt{\frac{mgd}{I}}, \quad T = 2\pi\sqrt{\frac{I}{mgd}}$
где $d$ — расстояние от оси до ц.м.
Энергия колебаний:
$E = \frac{kA^2}{2} = \frac{m\omega_0^2 A^2}{2}$
10. Затухающие и вынужденные колебания
Затухающие колебания:
$\ddot{x} + 2\beta\dot{x} + \omega_0^2 x = 0$
$x = A_0 e^{-\beta t}\cos(\omega t + \varphi), \quad \omega = \sqrt{\omega_0^2 - \beta^2}$
Коэффициент затухания: $\beta = \frac{r}{2m}$
Время релаксации: $\tau = \frac{1}{\beta}$ (амплитуда убывает в $e$ раз)
Логарифмический декремент: $\delta = \beta T = \frac{T}{\tau}$
Добротность: $Q = \frac{\pi}{\delta} = \frac{\omega_0}{2\beta}$
Резонансная частота:
$\omega_{\text{рез}} = \sqrt{\omega_0^2 - 2\beta^2}$
11. Сложение колебаний
Одинаковое направление, равные частоты:
$A = \sqrt{A_1^2 + A_2^2 + 2A_1 A_2 \cos(\varphi_2 - \varphi_1)}$
Близкие частоты (биения):
$x = 2A\cos\left(\frac{\Delta\omega}{2}t\right)\cos(\bar{\omega}t)$
$T_{\text{биений}} = \frac{2\pi}{|\omega_1 - \omega_2|}$
