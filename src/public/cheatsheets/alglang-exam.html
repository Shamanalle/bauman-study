1. Класс: объявление, поля, методы
Объявление класса:
class ИмяКласса {
private:
    тип поле;          // данные
public:
    ИмяКласса();       // конструктор
    ~ИмяКласса();      // деструктор
    тип метод();       // метод
};

Определение метода за пределами класса:
тип ИмяКласса::метод() {
    // реализация
}

Доступ к членам:
`объект.поле` или `указатель->поле`
2. Конструкторы и деструктор
Виды конструкторов:
class A {
public:
    A();                    // по умолчанию
    A(int n);               // с параметром
    A(const A& other);      // копирования
    A(A&& other) noexcept;  // перемещения
    ~A();                   // деструктор
};

Список инициализации:
A::A(int n) : size(n), data(new int[n]) {}

`explicit` — запрещает неявное преобразование.
`= delete` — удаляет конструктор.
`= default` — генерирует по умолчанию.
3. Модификаторы доступа
Три статуса:
• `public:` — доступно всем
• `private:` — только внутри класса
• `protected:` — класс + наследники
Умолчания:
• `class` → `private`
• `struct` → `public`
• `union` → `public`
4. Наследование
Синтаксис:
class Derived : public Base {
public:
    Derived(параметры) : Base(аргументы) {}
};

Типы наследования:
• `public` — public→public, protected→protected
• `protected` — public→protected, protected→protected
• `private` — всё→private
Множественное:
class C : public A, public B {};

Виртуальное (ромб):
class B1 : virtual public A {};
class B2 : virtual public A {};
class C : public B1, public B2 {};
5. Виртуальные функции и полиморфизм
virtual + override:
class Base {
public:
    virtual void f() { /* ... */ }
    virtual void g() = 0;  // чисто виртуальная
};
class Derived : public Base {
public:
    void f() override { /* ... */ }
    void g() override { /* ... */ }
};

Динамический полиморфизм:
Base* p = new Derived();
p->f();  // вызовется Derived::f()
delete p;

Статический полиморфизм — без `virtual`:
вызовется метод по типу указателя, а не объекта.
6. Перегрузка операторов
Как метод класса (левый операнд = this):
class A {
public:
    A operator+(const A& r) const;
    A& operator=(const A& r);
    A& operator++();      // префикс
    A operator++(int);    // постфикс
};

Как свободная функция:
A operator+(const A& l, const A& r);

Перегрузка ():
class Functor {
public:
    int operator()(int x) { return x * 2; }
};
7. Исключения: try / catch / throw
Генерация и перехват:
try {
    throw std::runtime_error("msg");
} catch (const std::exception& e) {
    std::cerr << e.what();
} catch (...) {
    // ловим всё
}

Свой класс исключения:
class MyError : public std::out_of_range {
    int code;
public:
    MyError(const std::string& msg, int c)
        : std::out_of_range(msg), code(c) {}
    int getCode() const { return code; }
};
8. Шаблоны классов
Объявление:
template 
class Stack {
    T* data;
    int top;
public:
    Stack(int n) : data(new T[n]), top(0) {}
    void push(const T& val) { data[top++] = val; }
    T pop() { return data[--top]; }
    ~Stack() { delete[] data; }
};

Использование:
Stack si(100);
Stack sd(50);
9. Многопоточность: thread, mutex
Создание потока:
#include 
void func(int n, std::string name) { /* ... */ }
std::thread t(func, 10, "T1");
t.join();

Мьютекс:
#include 
std::mutex mtx;
{
    std::lock_guard lock(mtx);
    // критическая секция
}

Условная переменная:
#include 
std::condition_variable cv;
bool ready = false;
// Поток-отправитель:
{ std::lock_guard lk(mtx); ready = true; }
cv.notify_one();
// Поток-получатель:
std::unique_lock lk(mtx);
cv.wait(lk, []{ return ready; });
10. STL: контейнеры и лямбды
Требования к элементам контейнеров:
• `vector`, `list`: конструктор по умолчанию
• `set`, `map`: `operator<` (или компаратор)
• `unordered_set`, `unordered_map`: `std::hash` + `operator==`
Лямбда-функция:
auto cmp = [](const A& a, const A& b) {
    return a.x < b.x;
};
std::sort(v.begin(), v.end(), cmp);

Функтор:
struct Cmp {
    bool operator()(const A& a, const A& b) const {
        return a.x < b.x;
    }
};
std::set s;
