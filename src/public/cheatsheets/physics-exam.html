⚛️ Физика · Экзамен · Формулы

Полный курс: механика + термодинамика · 9 позиций
1. Кинематика МТ
Прямолинейное:
$v = v_0 + at, \quad s = v_0 t + at^2/2, \quad v^2 = v_0^2 + 2as$
Криволинейное: $\vec{a} = \vec{a}_\tau + \vec{a}_n$, $a_\tau = dv/dt$, $a_n = v^2/R$
Вращательное:
$\omega = d\varphi/dt, \quad \varepsilon = d\omega/dt$
$v = \omega R, \quad a_\tau = \varepsilon R, \quad a_n = \omega^2 R$
2. Динамика: законы Ньютона и силы
2-й закон: $\vec{F} = m\vec{a}$
Трение: $F_{\text{тр}} = \mu N$
Импульс: $\vec{p} = m\vec{v}$, $\vec{F} = d\vec{p}/dt$
ЗСИ: $\sum \vec{p}_i = \text{const}$ (замкнутая система)
3. Энергия и столкновения
Кинетическая: $T = mv^2/2 + I\omega^2/2$ (поступательная + вращательная)
Потенциальная: $U = mgh$, $U = kx^2/2$ (пружина), $F = -dU/dx$
ЗСЭ: $T_1 + U_1 = T_2 + U_2$ (+ работа неконсерв. сил)
АУУ: $m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$; при центральном: $v_2' = 2m_1 v_1/(m_1+m_2)$
4. Вращение ТТ
Основное уравнение: $M = I\varepsilon$
Момент инерции: $I = \sum m_i r_i^2$
Стержень (ось через конец): $ml^2/3$. Через центр: $ml^2/12$.
Диск/цилиндр: $mR^2/2$. Шар: $2mR^2/5$. Кольцо: $mR^2$.
Штейнер: $I = I_C + md^2$
Момент импульса: $L = I\omega$, $\vec{M} = d\vec{L}/dt$
ЗСМИ: $I_1\omega_1 = I_2\omega_2$
5. Колебания
Гармоническое: $x = A\cos(\omega_0 t + \varphi_0)$
Пружина: $\omega_0 = \sqrt{k/m}$;
Мат. маятник: $\omega_0 = \sqrt{g/l}$;
Физ. маятник: $\omega_0 = \sqrt{mgd/I}$
Затухание: $x = A_0 e^{-\beta t}\cos(\omega t + \varphi)$, $\omega = \sqrt{\omega_0^2 - \beta^2}$
$\delta = \beta T = \ln(A_n/A_{n+1})$, $Q = \pi/\delta$
6. Волны
Бегущая волна: $\xi = A\cos(\omega t - kx)$
$k = 2\pi/\lambda = \omega/v$, $v = \lambda\nu = \omega/k$
Стоячая: $\xi = 2A\cos(kx)\cos(\omega t)$
Энергия:
$\langle w \rangle = \frac{1}{2}\rho\omega^2 A^2, \quad I = \langle w \rangle v$
7. МКТ идеального газа
Менделеев–Клапейрон: $pV = \nu RT$
Средняя энергия: $\langle\varepsilon\rangle = (i/2)kT$
$i = 3$ одноатомный, $i = 5$ двухатомный
Скорости: $v_{\text{в}} = \sqrt{2kT/m}$, $\bar{v} = \sqrt{8kT/(\pi m)}$, $v_{\text{ск}} = \sqrt{3kT/m}$
Барометр: $p(h) = p_0 e^{-Mgh/(RT)}$
8. Термодинамика
Первое начало: $Q = \Delta U + A$, $\Delta U = \nu C_V \Delta T$
$C_V = iR/2$, $C_p = (i+2)R/2$, $\gamma = C_p/C_V$
Адиабата: $pV^\gamma = \text{const}$, $TV^{\gamma-1} = \text{const}$
КПД Карно: $\eta = 1 - T_2/T_1$
Энтропия: $\Delta S = \int \delta Q/T = \nu C_V \ln(T_2/T_1) + \nu R\ln(V_2/V_1)$
9. СТО
Лоренц: $\gamma_L = 1/\sqrt{1-\beta^2}$, $\beta = v/c$
$l = l_0/\gamma_L$, $\Delta t = \gamma_L \Delta t_0$
Сложение скоростей: $u = (v_1+v_2)/(1+v_1v_2/c^2)$
Энергия: $E = \gamma_L m_0 c^2 = E_0 + T$
Импульс: $p = \gamma_L m_0 v$
Инвариант: $E^2 = (pc)^2 + (m_0c^2)^2$
