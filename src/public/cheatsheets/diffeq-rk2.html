∫ Интегралы и ДУ · РК-2 · Формулы

Несобственные интегралы, ОДУ · 7 позиций
1. Характеристическое уравнение ЛОДУ n-го порядка
Для ЛОДУ $y^{(n)} + a_{n-1}y^{(n-1)} + \ldots + a_1 y' + a_0 y = 0$
Характеристическое уравнение:
$\lambda^n + a_{n-1}\lambda^{n-1} + \ldots + a_1\lambda + a_0 = 0$
2. ФСР при разных типах корней
Действительный простой корень $\lambda$: → $e^{\lambda x}$
Действительный корень $\lambda$ кратности $k$: → $e^{\lambda x},\; xe^{\lambda x},\; \ldots,\; x^{k-1}e^{\lambda x}$
Комплексные $\alpha \pm i\beta$ (простые): → $e^{\alpha x}\cos\beta x,\; e^{\alpha x}\sin\beta x$
Комплексные $\alpha \pm i\beta$ кратности $k$: → $x^j e^{\alpha x}\cos\beta x,\; x^j e^{\alpha x}\sin\beta x$ при $j = 0, 1, \ldots, k-1$
3. Формула Остроградского-Лиувилля
Для ЛОДУ 2-го порядка $y'' + p(x)y' + q(x)y = 0$:
$W(x) = W(x_0) \cdot e^{-\int_{x_0}^x p(t)\,dt}$
где $W$ — определитель Вронского (вронскиан):
$W = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_1' y_2$
4. Метод вариации постоянных (Лагранжа)
Для ЛНДУ 2-го порядка $y'' + p y' + q y = f(x)$:
Общее решение: $y = C_1(x)y_1 + C_2(x)y_2$
Система для $C_1', C_2'$:
$\begin{cases} C_1' y_1 + C_2' y_2 = 0 \\ C_1' y_1' + C_2' y_2' = f(x) \end{cases}$
Решение:
$C_1' = -\frac{y_2 f}{W}, \quad C_2' = \frac{y_1 f}{W}$
5. Частное решение для правой части специального вида
Для $y'' + ay' + by = e^{\alpha x}P_n(x)$:
$\tilde{y} = x^s e^{\alpha x} Q_n(x)$
где $s$ = кратность $\alpha$ как корня хар. уравнения, $Q_n$ — полином степени $n$.
Для $y'' + ay' + by = e^{\alpha x}[P_n\cos\beta x + R_m\sin\beta x]$:
$\tilde{y} = x^s e^{\alpha x}[\hat{Q}_N\cos\beta x + \hat{T}_N\sin\beta x]$
где $N = \max(n,m)$, $s$ = кратность $\alpha + i\beta$.
6. Понижение порядка ДУ
Случай 1: ДУ не содержит $y$ явно — $F(x, y', y'') = 0$:
Замена $p = y'$, $p' = y''$. Получаем ДУ 1-го порядка для $p(x)$.
После нахождения $p(x)$: $y = \int p(x)\,dx + C$.
Случай 2: ДУ не содержит $x$ явно — $F(y, y', y'') = 0$:
Замена $y' = p(y)$, тогда $y'' = p \cdot p'_y$.
Получаем ДУ 1-го порядка для $p(y)$.
После: $\int \frac{dy}{p(y)} = x + C$.
Пример: $xy'' + y' + x = 0$ → $(xp)' = -x$ → $xp = -\frac{x^2}{2} + C_1$.
7. Подстановки Эйлера (иррациональные ДУ)
Для $\int R(x, \sqrt{ax^2+bx+c})\,dx$:
1-я подстановка ($a > 0$):
$\sqrt{ax^2+bx+c} = t \pm x\sqrt{a}$
2-я подстановка ($c > 0$):
$\sqrt{ax^2+bx+c} = tx \pm \sqrt{c}$
3-я подстановка (если есть действ. корень $x_0$):
$\sqrt{a(x-x_0)(x-x_1)} = t(x-x_0)$
