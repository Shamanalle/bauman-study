## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org/) >= 18
- npm >= 9

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/bauman-study.git
cd bauman-study

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Откроется на `http://localhost:5173`

### Сборка

```bash
# Продакшен-сборка
npm run build

# Собрать оффлайн-бандлы (HTML-файлы)
npm run bundle

# Собрать единый файл «Платформа.html»
node scripts/build-platform.js
```

## 🛠 Технологии

- **Vite** — сборка и dev-сервер
- **Vanilla JS** — без фреймворков, максимальная производительность
- **KaTeX** — рендеринг математических формул
- **SVG** — кастомные диаграммы с поддержкой тем
- **CSS Variables** — тёмная/светлая тема

## 📖 Режимы работы

### 🔬 Справочник
Подготовка к конкретному экзамену/КН/КР — вопросы, формулы, определения, карточки для запоминания.

### 📕 Учебник
Полный курс по предмету — теория, примеры, доказательства, разбитые по главам.

### 🧪 Лабораторные
Задания и решения лабораторных работ (АЯ, ТиМП) с разбором по вариантам.
