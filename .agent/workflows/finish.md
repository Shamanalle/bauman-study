# 🏁 Финализация изменений

Выполни эти шаги **после каждой завершённой задачи** (добавление контента, правка кода, исправление багов и т.д.).

## 1. Проверка сборки

Если были изменены файлы JS, CSS или HTML — убедись, что проект собирается без ошибок:

// turbo
```
npm run build
```

Если билд упал — **исправь ошибки** прежде чем продолжать.

## 2. Пересборка бандлов (если нужно)

Если были изменены любые файлы в `src/data/`, `src/js/`, `src/css/`, или `scripts/build-*.js` — пересобери бандлы:

```
npm run bundle
node scripts/build-platform.js
```

> Бандлы — это оффлайн HTML-файлы в `bundles/`. Пересборка гарантирует, что они актуальны.

## 3. Git-коммит

Сделай коммит со ВСЕМИ изменениями. Сообщение коммита должно кратко описывать суть изменений на русском языке.

// turbo
```
git add -A
```

```
git commit -m "<emoji> <краткое описание изменений>"
```

Формат сообщений:
- `✨ <описание>` — новая фича или контент
- `🐛 <описание>` — баг-фикс
- `💄 <описание>` — визуальные/CSS изменения
- `📝 <описание>` — добавление/изменение данных (JSON, SVG)
- `🔧 <описание>` — изменения конфига или скриптов
- `♻️ <описание>` — рефакторинг кода

## 4. Push на GitHub

// turbo
```
git push
```

## 5. Краткий отчёт пользователю

В конце кратко сообщи:
- Что было сделано
- Что было закоммичено
- Были ли пересобраны бандлы
- Был ли push успешным
