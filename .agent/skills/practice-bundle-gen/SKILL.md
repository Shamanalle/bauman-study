# Practice Bundle Generator

Генерация JSON-данных практических контрольных мероприятий для платформы `bauman-study`.
Практический бандл — это **самодостаточный инструмент для подготовки к решению задач**.

---

## 1. Когда использовать этот скилл

- КР (контрольная работа) — решение задач
- Практическая часть РК (задачи на площади, объёмы, НИ и т.д.)
- Практическая часть экзамена (задачи из билетов)
- Любой «задачник» или «тренажёр решения»

> **НЕ** используй для теоретических вопросов (определения, теоремы) — для этого есть `theory-bundle-gen`.

---

## 2. Архитектура UI: табы а-ля лабы

Практический бандл использует **табовый интерфейс** (как лабы) — `practice-browser.js`.
Файл `meta.json` с `"practiceMode": true` активирует этот рендерер вместо стандартного карточного UI.

### 2.1 Общая визуальная структура

```
┌──────────────────────────────────────────────────────┐
│  ∫  Интегралы и ДУ                                   │  ← heroTitle (meta.icon + meta.title)
│  РК-1 · Практика                                     │  ← heroSubtitle (meta.subtitle)
├──────────────────────────────────────────────────────┤
│  [📋 Формулы] [📚 Методы] [✏️ Задачи] [🎫 Билеты]   │  ← Табы (по одному на секцию)
├──────────────────────────────────────────────────────┤
│                                                      │
│  Содержимое текущей вкладки (#pracContent)            │  ← Рендерится по icon секции
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 2.2 Маршрутизация рендереров

Каждая секция (JSON-файл) содержит поле `icon`. При переключении вкладки, код выбирает рендерер:

```
icon: "📋" → renderFormulas()   — сетка карточек с формулами
icon: "📚" → renderMethods()    — карточки-алгоритмы с шагами
icon: "✏️" → renderProblems()   — задачи со скрытыми решениями
icon: "🎫" → renderTickets()    — билеты с per-task toggle
fallback   → renderFormulas()   — по умолчанию
```

> **КРИТИЧЕСКИ ВАЖНО:** `icon` определяет рендерер! Неверный icon = неверное отображение.

### 2.3 Что рендерит каждая вкладка

#### 📋 Формулы (`renderFormulas`)
Простая **сетка карточек** — всё видно сразу, ничего не скрыто.
```
┌─[1]──────────────────────┐  ┌─[2]──────────────────────┐
│ Табличные интегралы      │  │ Тригонометрические       │
│ ∫xⁿdx = xⁿ⁺¹/(n+1)+C   │  │ ∫sinx dx = -cosx + C     │
│ ∫dx/x = ln|x| + C       │  │ ∫cosx dx = sinx + C      │
└──────────────────────────┘  └──────────────────────────┘
```
**Поля:** `title` (заголовок) + `formalText` (содержимое). Больше ничего не используется.

#### 📚 Методы (`renderMethods`)
**Полноразмерные карточки** с номером, заголовком, бейджем (tldr), и пронумерованными шагами:
```
┌─────────────────────────────────────────────────────┐
│ ① Алгоритм: с разд. переменными  [badge: tldr]     │
├─────────────────────────────────────────────────────┤
│ ❶ Определи тип                                     │
│   Уравнение вида f(x)g(y)dx + h(x)p(y)dy = 0      │
│                                                     │
│ ❷ Раздели переменные                               │
│   Дели на g(y)·h(x)...                              │
│   $$\frac{f(x)}{h(x)}dx = -\frac{p(y)}{g(y)}dy$$  │  ← step.math
│                                                     │
│ ❸ Интегрируй обе части                             │
│   Левая — по x, правая — по y.                     │
└─────────────────────────────────────────────────────┘
```
**Поля:** `title`, `tldr` (badge), `steps[].title`, `steps[].text` (md), `steps[].math` (raw KaTeX).

#### ✏️ Задачи (`renderProblems`)
**Карточки с progressive disclosure** — условие видно, подсказка и решение скрыты:
```
┌─────────────────────────────────────────────────────┐
│ [1.1] Площадь: астроида x=cos³t, y=sin³t            │
│       Задача · 3 балла · Площадь                     │
├─────────────────────────────────────────────────────┤
│ Найти площадь фигуры, ограниченной кривой...        │  ← formalText (всегда видно)
│                                                     │
│ [💡 Подсказка]  [👁 Показать решение]               │  ← две кнопки
│                                                     │
│ ┌── подсказка (по клику «Подсказка») ──────────┐    │
│ │ 💡 Используй S = ∫y·x'dt и симметрию (×4)   │    │  ← hint
│ └──────────────────────────────────────────────┘    │
│                                                     │
│ ┌── решение (по клику «Показать решение») ─────┐    │
│ │ [график canvas + data-plot]                   │   │  ← plot
│ │ Формула: S = ∫y(t)·x'(t)dt...                │   │  ← steps
│ │ $$S = 12∫...$$                                │   │  ← step.math
│ │ Ответ: S = 3π/8                              │   │  ← formula
│ └───────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```
**Поля:** `id`, `title`, `type`, `formalText`, `tldr`, `hint`, `steps[]`, `formula`, `plot`.

#### 🎫 Билеты (`renderTickets`)
**Билеты с per-task раскрытием** — каждая задача раскрывается отдельно:
```
┌─────────────────────────────────────────────────────┐
│ [1] Образец экзаменационного билета — Вариант 1     │
│     Билет экзамена · 36 баллов                      │
├─────────────────────────────────────────────────────┤
│ Задача 1 (6 б.): Проинтегрировать...                │  ← formalText (все задачи)
│ Задача 2 (6 б.): Вычислить площадь...               │
│                                                     │
│ [👁 Показать решение]                                │  ← общий toggle
│                                                     │
│  ┌ Задача 1 ── [▶ раскрыть] ─────────────────────┐  │  ← per-task toggle
│  │ Замечаем: dx/x = d(ln x)...                   │  │
│  │ $$∫dx/(x·ln²x) = -1/lnx + C$$                │  │
│  └───────────────────────────────────────────────┘  │
│                                                     │
│  ┌ Задача 2 ── [▶ раскрыть] ─────────────────────┐  │
│  │ ...                                           │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```
**Поля:** `id`, `title`, `type`, `formalText`, `steps[]` (1 step = 1 задача билета).

### 2.4 Файловая структура

```
src/data/<subject>/<assessment>/
├── meta.json                    # practiceMode: true!
├── index.json                   # ["section-00-...", "section-01-...", ...]
├── section-00-формулы.json      # icon: "📋"
├── section-01-методы.json       # icon: "📚"
├── section-02-задачи.json       # icon: "✏️"
└── section-03-билеты.json       # icon: "🎫"
```

### 2.5 Поток данных: JSON → UI

```
meta.json (practiceMode: true)
    ↓
app.js определяет: это practice bundle
    ↓
practice-browser.js :: initPracticeBrowser(data)
    ↓
Создаёт табы из data.sections[].section (заголовок таба)
    ↓
При клике на таб → renderCurrentTab()
    ↓
Читает section.icon → выбирает рендерер
    ↓
Рендерер генерирует HTML из section.questions[]
    ↓
requestAnimationFrame → renderMath(el) — KaTeX рендеринг
```

## 3. ЗОЛОТЫЕ ПРАВИЛА ФОРМАТИРОВАНИЯ

> ⚠️ **ЭТО САМЫЙ ВАЖНЫЙ РАЗДЕЛ. 90% ошибок происходят здесь.**

### 3.1 Текстовые поля обрабатываются функцией `md()`

Функция `md()` поддерживает:
- `**bold**` → `<strong>bold</strong>`
- `\n` → `<br>` (перенос строки)
- `- item\n- item` → `<ul><li>item</li><li>item</li></ul>` (bullet list)
- `$...$` и `$$...$$` — **сохраняются как есть** (передаются в KaTeX)

Функция `md()` применяется к полям: `title`, `text`, `tldr`, `formalText`, `keyIdea`.
Поле `math` вставляется **напрямую** (без md()) — оно должно быть **чистый KaTeX** в `$$...$$`.

### 3.2 Правила LaTeX в JSON

**ВСЕ обратные слэши в JSON удваиваются!** `\int` → `\\int`, `\frac{}{}` → `\\frac{}{}`.

```json
✅ "text": "Замена $t = \\ln x$ даёт $dt = \\frac{dx}{x}$."
✅ "math": "$$\\int \\frac{dx}{x\\ln^2 x} = -\\frac{1}{\\ln x} + C$$"
❌ "text": "Замена t = ln x"          // нет KaTeX — будет сырой текст
❌ "text": "Замена $t = \ln x$"       // одинарная \ — сломается
```

### 3.3 Inline-math ОБЯЗАТЕЛЬНО в `$...$`

Каждая математическая переменная, формула, выражение **ДОЛЖНА** быть в `$...$`:

```json
✅ "text": "$\\alpha = 2$ — простой корень → $s = 1$."
✅ "text": "ИМ: $\\mu = e^{\\int p(x)dx}$. Домножаем: $(\\mu y)' = \\mu q$"
❌ "text": "α = 2 — простой корень → s = 1."     // Unicode вместо KaTeX
❌ "text": "ИМ: μ = e^{∫ p(x)dx}"                // Unicode — не рендерится
```

**НИКОГДА не используй Unicode-символы для математики** (α, β, ∫, √, ², ₁ и т.д.) в полях `text`, `formalText`, `steps[].text`.
Единственное исключение — поле `tldr`, где Unicode допустим, т.к. это справочный бейдж.

### 3.4 Поле `tldr` — особый формат

`tldr` отображается как **бейдж** (зелёная плашка) рядом с заголовком карточки.
Он **короткий** (< 60 символов), **без LaTeX**, **с Unicode-сокращениями**:

```json
✅ "tldr": "Собираем x к dx, y к dy, интегрируем"
✅ "tldr": "e^αx·Pₙ(x) → x^s·e^αx·Qₙ(x)"
✅ "tldr": "Параметрически: V = π∫y²·x'dt"
❌ "tldr": "$e^{\\alpha x} P_n(x) \\to x^s \\cdot e^{\\alpha x} Q_n(x)$"  // слишком длинный LaTeX
```

### 3.5 Поле `math` — блочная формула

Поле `math` (в steps) вставляется **напрямую в HTML** (без md()) и должно содержать ТОЛЬКО `$$...$$`:

```json
✅ "math": "$$\\int_0^1 t\\ln^2 t\\,dt = \\frac{1}{4}$$"
❌ "math": "\\int_0^1 t\\ln^2 t\\,dt = \\frac{1}{4}"     // нет $$..$$
❌ "math": "Формула: $$...$$"                              // текст не пишем в math
```

### 3.6 Нумерация ID

ID задач и билетов — **числовые строки**, начинаются с `"1"`:

```json
✅ "id": "1"           // задачи в section-02
✅ "id": "1.1"         // если есть подзадачи
❌ "id": "sep-1"       // текстовые ID запрещены
❌ "id": "ticket-1"    // текстовые ID запрещены
```

Для методов (section-01) допустимы `"m-1"`, `"m-2"`, т.к. они не нумеруются в UI напрямую.

### 3.7 Bold-маркеры в тексте

`**bold**` работает в `text` и `formalText`. Используй для:
- Названий методов: `**Вещественный случай:**`
- Примеров: `**Пример:**`
- Предупреждений: `**Важно:**`, `**Частая ошибка:**`

```json
✅ "text": "**Пример:** $y'' - 4y = e^{2x}$. Хар. уравнение: $\\lambda^2 - 4 = 0$."
```

### 3.8 Bullet-листы в тексте

Bullet-листы работают через `\n- `:

```json
✅ "text": "Типы корней:\n- Вещественный $\\lambda$: $e^{\\lambda x}$\n- Кратный: $e^{\\lambda x}, xe^{\\lambda x}$\n- Комплексные $\\alpha \\pm i\\beta$: $e^{\\alpha x}\\cos\\beta x$"
```

## 4. Схемы карточек

### 4.1 Секция «Формулы» (icon: `📋`)

Простые карточки с формулами. Показываются полностью (без скрытия).

```json
{
  "section": "📋 Формулы и справочник",
  "icon": "📋",
  "questions": [
    {
      "id": "f-1",
      "title": "Табличные интегралы",
      "formalText": "$$\\int x^n dx = \\frac{x^{n+1}}{n+1} + C, \\quad n \\neq -1$$\n\n$$\\int \\frac{dx}{x} = \\ln|x| + C$$"
    }
  ]
}
```

Рендерер `renderFormulas()` показывает: `title` + `formalText`. Больше ничего.

### 4.2 Секция «Методы» (icon: `📚`)

Карточки-алгоритмы с пошаговыми инструкциями. Показываются полностью.

```json
{
  "section": "📚 Методы решения",
  "icon": "📚",
  "questions": [
    {
      "id": "m-1",
      "title": "Алгоритм: с разделяющимися переменными",
      "type": "Алгоритм",
      "tldr": "Собираем x к dx, y к dy, интегрируем каждую часть",
      "formalText": "$$y' + p(x)y = q(x)$$",
      "steps": [
        {
          "title": "Определи тип",
          "text": "Уравнение вида $f(x)g(y)\\,dx + h(x)p(y)\\,dy = 0$."
        },
        {
          "title": "Раздели переменные",
          "text": "Дели на $g(y) \\cdot h(x)$ (если $\\neq 0$):\n\n**Пример:** $\\frac{dx}{x(y-1)}+\\frac{dy}{y(x+2)}=0$ → домножаем на $x(y-1)y(x+2)$.",
          "math": "$$\\frac{f(x)}{h(x)}dx = -\\frac{p(y)}{g(y)}dy$$"
        }
      ],
      "keyIdea": "Все три метода дают одну и ту же формулу",
      "note": "Типичная ошибка: забыть проверить особые решения"
    }
  ]
}
```

Рендерер `renderMethods()` показывает: порядковый номер + title + badge(tldr) + steps.
Каждый step рендерит: `step-num` + `step-title` (md) + `step-text` (md) + `step-math` (raw).

> **ПРАВИЛО ПОДРОБНОСТИ МЕТОДОВ:** Каждый шаг метода должен содержать:
> 1. Что делать (формула или действие)
> 2. Как делать (конкретная подстановка или операция)
> 3. **Пример** (конкретное вычисление, не абстрактное «решаем стандартно»)
>
> ❌ `"text": "Стандартным методом (ИМ или формула)."` — **СЛИШКОМ КРАТКО**
> ✅ `"text": "ИМ: $\\mu = e^{\\int 2\\tan x\\,dx} = \\frac{1}{\\cos^2 x}$. Домножаем:"` — **ПОДРОБНО**

### 4.3 Секция «Задачи» (icon: `✏️`)

Задачи с решениями. Решение **скрыто** по умолчанию.

```json
{
  "section": "✏️ Задачи",
  "icon": "✏️",
  "questions": [
    {
      "id": "1",
      "title": "Площадь: астроида x=cos³t, y=sin³t",
      "type": "Задача · 3 балла · Площадь",
      "formalText": "Найти площадь фигуры, ограниченной кривой $x = \\cos^3 t$, $y = \\sin^3 t$.",
      "tldr": "Параметрически: S = ∫y·x'dt, симметрия ×4",
      "steps": [
        {
          "title": "Формула",
          "text": "Параметрическая площадь: $S = \\int y(t) \\cdot x'(t)\\,dt$. По симметрии: $S = 4 \\cdot S_{\\text{1 кв.}}$"
        },
        {
          "title": "Производная",
          "text": "$x'(t) = -3\\cos^2 t \\sin t$. Пределы 1-го квадранта: $t \\in [0, \\pi/2]$.",
          "math": "$$S = 4\\int_0^{\\pi/2} \\sin^3 t \\cdot 3\\cos^2 t \\sin t\\,dt = 12\\int_0^{\\pi/2} \\sin^4 t \\cos^2 t\\,dt$$"
        },
        {
          "title": "Формула понижения степени",
          "text": "Используем формулу Валлиса: $\\int_0^{\\pi/2}\\sin^m t \\cos^n t\\,dt$.",
          "math": "$$= 12 \\cdot \\frac{3 \\cdot 1 \\cdot 1}{6 \\cdot 4 \\cdot 2} \\cdot \\frac{\\pi}{2} = \\frac{3\\pi}{8}$$"
        }
      ],
      "formula": "S = \\frac{3\\pi}{8}",
      "hint": "Используй параметрическую формулу площади S = |int y*x' dt| и симметрию астроиды (×4)",
      "plot": {
        "curves": [{"type": "parametric", "x": "pow(cos(t),3)", "y": "pow(sin(t),3)", "tRange": [0, 6.2832], "label": "Астроида"}],
        "xRange": [-1.3, 1.3],
        "yRange": [-1.3, 1.3],
        "points": [{"x": 1, "y": 0, "label": "(1,0)"}, {"x": 0, "y": 1, "label": "(0,1)"}]
      }
    }
  ]
}
```

**Поля:** `id`, `title`, `type`, `formalText`, `tldr`, `hint`, `steps[]`, `formula`, `plot`.

> **Поле `hint`** — опциональная подсказка для студента. Отображается по кнопке **«Подсказка»** ПЕРЕД полным решением.
> Кнопка — **toggle**: клик открывает подсказку, повторный клик сворачивает её обратно.
> Студент видит условие → нажимает «Подсказка» → получает краткий намёк → пробует сам → если не получилось, нажимает «Показать решение».
>
> Приоритет: `hint` → `keyIdea` → `tldr`. Если ни одно поле не задано — кнопка «Подсказка» не отображается.
>
> **ОБЯЗАТЕЛЬНО используй `$...$` для формул в `hint`!** Текст проходит через `md()` + `renderMath()`.
>
> `hint` должен быть **кратким** (1-2 предложения), указывать **метод/приём**, но НЕ давать готовый ответ:
> - ✅ `"hint": "Используй формулу понижения порядка: подстановка $y' = p(x)$"`
> - ✅ `"hint": "Полярные координаты: $S = \\frac{1}{2}\\int \\rho^2\\,d\\varphi$. Пределы: от $0$ до $\\pi/3$"`
> - ✅ `"hint": "Метод оболочек: $V = 2\\pi\\int_a^b x|f(x)-g(x)|\\,dx$"`
> - ❌ `"hint": "Ответ: S = 3π/8"` — это НЕ подсказка, это ответ
> - ❌ `"hint": "Используй формулу S = ½∫ρ²dφ"` — Unicode вместо KaTeX!

> **ПРАВИЛО ПОЛНОТЫ РЕШЕНИЙ (универсальное):**
> - Каждый нетривиальный переход — **ОТДЕЛЬНЫЙ шаг** с промежуточным результатом
> - Каждая подстановка/замена — **ОТДЕЛЬНЫЙ шаг** с выводом нового выражения
> - Каждое условие (начальное, граничное, проверка) — **ОТДЕЛЬНЫЙ шаг** с конкретным числом
> - НИКОГДА не пиши «аналогично», «вычисляется стандартно», «по формуле из лекций»
> - Вместо этого ПОКАЖИ каждый шаг явно, с числами или символами
>
> **Примеры для разных предметов:**
> - Математика: каждое интегрирование по частям, каждая замена, каждая подстановка ЗК
> - Физика: каждая подстановка значений в формулу, перевод единиц, численный результат
> - Программирование: каждый блок кода, объяснение логики, пример ввода/вывода
> - Линейная алгебра: каждый шаг метода Гаусса, каждой операции над матрицами

### 4.4 Секция «Билеты» (icon: `🎫`)

Образцы вариантов КР/экзамена. Решение скрыто, + решение каждой задачи раскрывается отдельно.

```json
{
  "section": "🎫 Образцы билетов",
  "icon": "🎫",
  "questions": [
    {
      "id": "1",
      "title": "Образец экзаменационного билета — Вариант 1",
      "type": "Билет экзамена · 36 баллов",
      "formalText": "**Задача 1** (6 б.): ...\n\n**Задача 2** (6 б.): ...",
      "steps": [
        {
          "title": "Задача 1 — Интеграл (подведение)",
          "text": "Замечаем: $\\frac{dx}{x} = d(\\ln x)$. Обозначим $t = \\ln x$:",
          "math": "$$\\int \\frac{dx}{x\\ln^2 x} = -\\frac{1}{\\ln x}+C$$"
        },
        {
          "title": "Задача 2 — Площадь",
          "text": "**Точки пересечения:** $(x-4)^2 = 16-x^2$ → $x = 0, 4$.\n\n**Определяем, кто выше:** при $x=2$: верхняя кривая $y=16-x^2$.",
          "math": "$$S = \\int_0^4 [(16-x^2)-(x-4)^2]dx = \\frac{64}{3}$$"
        }
      ]
    }
  ]
}
```

Рендерер `renderTickets()`: каждый step рендерится как отдельная задача с кнопкой раскрытия.

> **ПРАВИЛО ДЛЯ БИЛЕТОВ:** Решение каждой задачи билета должно быть ПОЛНЫМ и САМОДОСТАТОЧНЫМ.
> Студент видит его отдельно от методов — нельзя писать «стандартным методом» или «аналогично».
> Каждый шаг = 1 задача билета с полными промежуточными выкладками и ответом.

## 5. Интерактивные графики (plot) — ОПЦИОНАЛЬНО

Поле `plot` — **опциональное**. Используй его ТОЛЬКО для задач с геометрическим/визуальным смыслом:
- Площади, объёмы, длины дуг (математика)
- Кривые, области интегрирования (мат. анализ)
- Графики функций, линии уровня (ФНП)

**НЕ нужен** для: программирования, абстрактной алгебры, теоретической физики, дискретной математики и т.д.

### 5.1 Структура plot

```json
"plot": {
  "curves": [
    {"type": "function", "expr": "x^2", "xRange": [0, 3], "label": "y=x²"},
    {"type": "parametric", "x": "cos(t)", "y": "sin(t)", "tRange": [0, 6.2832], "label": "Окр."},
    {"type": "polar", "expr": "1+cos(t)", "tRange": [0, 6.2832], "label": "Кардиоида"}
  ],
  "fills": [
    {"between": [0, 1], "xRange": [0, 2]}
  ],
  "points": [
    {"x": 1, "y": 0, "label": "(1,0)"},
    {"x": 0, "y": 1, "label": "(0,1)"}
  ],
  "xRange": [-1.5, 1.5],
  "yRange": [-1.5, 1.5]
}
```

### 5.2 Правила графиков

1. **Оси БЕЗ числовых подписей** — только кривые, точки, заливка
2. **Подписи точек** — ОБЯЗАТЕЛЬНЫ для всех ключевых точек:
   - Точки пересечения кривых
   - Вершины (астроид, эллипс)
   - Максимумы/минимумы (кардиоида)
   - Каспы (особые точки)
3. **Label кривой** — короткий (< 15 символов)
4. **Диапазоны** — с запасом 10-20% от реальных размеров фигуры
5. **Математическая корректность** — ПРОВЕРЬ, что:
   - `tRange` покрывает ПОЛНУЮ кривую (кардиоида: `[0, 6.2832]`)
   - Выражения в `expr`/`x`/`y` используют JS-синтаксис: `pow(x,3)` а не `x^3`, `Math.PI` и т.д.
   - Заливка `fills` между правильными индексами кривых

## 7. Алгоритм генерации (пошагово)

### Шаг 1: Определить источники

1. **Файл задач** (ПРИОРИТЕТ):
   - `new_sources/<предмет>/Контрольное Мероприятие/<Код> - КР - N.txt`
   - `new_sources/<предмет>/Сессия/<Код> - Сессия - Билеты.txt`
   - `new_sources/<предмет>/Контрольное Мероприятие/<Код> - РК - N - Вопросы.txt`
2. **Textbook / Лекции** — теоретическая основа для формул и методов
3. **ДКР** — доп. задачи

### Шаг 2: Проанализируй и сгруппируй

1. Определи типы задач и методы решения
2. Определи баллы за каждую задачу
3. Сгруппируй по темам (для подзадач: `1.1`, `1.2`, ... `2.1`, `2.2`, ...)

### Шаг 3: Создай Секцию 00 — Формулы

Справочная таблица формул. Простые карточки `title` + `formalText`.
icon: `📋`.

### Шаг 4: Создай Секцию 01 — Методы

Для КАЖДОГО типа задач:
1. Заголовок: `"Алгоритм: <название метода>"`
2. tldr: краткое описание (< 60 символов, Unicode-safe)
3. steps: пошаговый рецепт с **ПРИМЕРАМИ** на каждом шаге
4. note: типичные ошибки

icon: `📚`.

> **ПРАВИЛО:** Не пиши шаги вроде «решаем стандартным методом» или «интегрируем». 
> Каждый шаг должен содержать КОНКРЕТНЫЕ формулы и действия.

### Шаг 5: Создай Секцию 02 — Задачи

Для КАЖДОЙ задачи из источника:
1. `id` — числовой (`"1"`, `"1.1"`, `"2"`, ...)
2. `formalText` — **ТОЧНАЯ** формулировка (KaTeX, не перефразируй!)
3. `steps` — ПОЛНОЕ пошаговое решение с ПРОМЕЖУТОЧНЫМИ выкладками
4. `formula` — финальный ответ (в KaTeX, без `$$`)
5. `plot` — для задач с визуальным смыслом (опционально, см. §5)

icon: `✏️`.

> **ПРАВИЛО ПОЛНОТЫ РЕШЕНИЙ:**
> - Каждое интегрирование по частям — **ОТДЕЛЬНЫЙ шаг** с `$u = ...$`, `$dv = ...$`
> - Каждая замена переменных — **ОТДЕЛЬНЫЙ шаг** с выводом новых пределов
> - Каждая подстановка ЗК — **ОТДЕЛЬНЫЙ шаг** с конкретным числом
> - НИКОГДА не пиши «аналогично», «вычисляется стандартно», «несколько раз по частям»
> - Вместо этого ПОКАЖИ каждый шаг явно

### Шаг 6: Создай Секцию 03 — Билеты

Каждый вариант → одна карточка:
1. `id` — числовой (`"1"`, `"2"`, ...)
2. `formalText` — все задачи варианта
3. `steps` — решение КАЖДОЙ задачи (1 step = 1 задача)
4. В каждом step: `title` с номером задачи, `text` с ПОЛНЫМ решением, `math` с итогом

icon: `🎫`.

### Шаг 7: Запиши и валидируй

1. Запиши `meta.json`, `index.json`, все `section-*.json`
2. Выполни `npx vite build && node scripts/build-platform.js`
3. Проверь в браузере: `http://localhost:5173/?subject=<subject>&assessment=<assessment>`
4. Проверь каждую вкладку: формулы → методы → задачи → билеты
5. Раскрой несколько решений и проверь рендеринг KaTeX

## 9. Типичные ошибки (из реального опыта)

### Ошибка 1: «Решение — заглушка»
```json
❌ "steps": [{"title": "Ответ", "text": "Вычисляется через многократное интегрирование по частям."}]
```
**Правильно:** разбить на 2-3 шага с полными подстановками u, dv, вычислениями.

### Ошибка 2: «Текстовые ID»
```json
❌ "id": "sep-1"
❌ "id": "ticket-1"
✅ "id": "1"
```

### Ошибка 3: «Unicode вместо KaTeX в text»
```json
❌ "text": "ИМ: μ = e^{∫ p(x)dx}"
✅ "text": "ИМ: $\\mu = e^{\\int p(x)dx}$"
```

### Ошибка 4: «Формула без $$»
```json
❌ "math": "V = \\pi a^3 / 2"
✅ "math": "$$V = \\frac{\\pi a^3}{2}$$"
```

### Ошибка 5: «Badge слишком длинный»
```json
❌ "tldr": "$e^{\\alpha x} P_n(x) \\to x^s \\cdot e^{\\alpha x} \\cdot Q_n(x)$, где $s$ = кратность корня"
✅ "tldr": "e^αx·Pₙ(x) → x^s·e^αx·Qₙ(x), s = кратность"
```

### Ошибка 6: «Graph без key points»
```json
❌ "points": []
✅ "points": [{"x": 1, "y": 0, "label": "(1,0)"}, {"x": 0, "y": 1, "label": "(0,1)"}]
```

### Ошибка 7: «Неверная иконка секции»
```json
❌ {"section": "✏️ Задачи", "icon": "📋"}     // будет рендериться как формулы!
✅ {"section": "✏️ Задачи", "icon": "✏️"}
```

### Ошибка 8: «md() ломает LaTeX»
Функция md() защищает `$...$` и `$$...$$` от bold/list regex.
Но если LaTeX содержит `*` (не как умножение) — может сломаться.
Используй `\\cdot` вместо `*` для умножения в LaTeX.

## 10. Стратегии по предметам

## 10. Адаптация под разные предметы

Скилл универсален для любого технического предмета. Ниже — рекомендации по адаптации.

### 10.1 Универсальный шаблон

Для ЛЮБОГО предмета структура одна и та же:

| Секция | Что содержит | Примеры для разных предметов |
|--------|-------------|------------------------------|
| 📋 Формулы | Справочные формулы, таблицы, определения | Табл. интегралов, формулы кинематики, синтаксис С++ |
| 📚 Методы | Алгоритмы решения типовых задач | Метод подстановки, закон Ньютона, шаблон класса |
| ✏️ Задачи | Задачи с пошаговыми решениями | Вычислить интеграл, найти ускорение, написать класс |
| 🎫 Билеты | Образцы вариантов КР/экзамена | Полные варианты с решениями |

### 10.2 Математические предметы (ИиДУ, ЛинАлг, МатАнализ)

**Формулы:** справочные таблицы (интегралы, производные, определители, ряды).

**Методы:** пошаговые алгоритмы. Каждый шаг = формула + подстановка + пример.
Ключевое: **примеры** обязательны. Не «решаем стандартно», а «вот конкретное числовое вычисление».

**Задачи:** используй `plot` для всех задач с геометрическим смыслом (площади, объёмы, кривые, поля).
`formula` = финальный ответ в KaTeX.

**Билеты:** полные решения, каждый шаг = 1 задача билета.

### 10.3 Физика

**Формулы:** основные законы, единицы измерения, константы.

**Методы:** алгоритм решения типовой задачи:
1. Определи систему (тело, поле, заряд...)
2. Выбери закон
3. Запиши уравнения
4. Подставь числа
5. Проверь размерность

**Задачи:** в `steps` обязательно:
- Рисунок / схема (можно описать текстом или через `plot`)
- Запись исходных данных ($m = ...$, $v_0 = ...$)
- Подстановка в формулу с **числами**
- Численный ответ с **единицами** ($= 4{,}2 \text{ м/с}$)

**`formula`:** числовой ответ с единицами.

### 10.4 Программирование (C++, Python, Java...)

**Формулы:** синтаксические шаблоны, ключевые конструкции языка.

**Методы:** алгоритмы/паттерны (шаблон класса, паттерн наследования, обработка исключений).

**Задачи:** `formalText` = условие. В `steps`:
- Объяснение подхода (text)
- **Код**: `<pre class="code-block"><code class="language-cpp">...</code></pre>`
- Пояснение ключевых моментов
- Пример ввода/вывода

**`formula`:** краткое описание результата (нет KaTeX).

### 10.5 Как определить типы задач для нового предмета

1. **Прочитай источник** (файл с задачами / билетами)
2. **Выдели повторяющиеся паттерны** — какие методы используются
3. **Сгруппируй задачи по методам** — каждый метод → одна карточка в секции «Методы»
4. **Определи, нужны ли графики** — есть ли геометрический / визуальный смысл
5. **Определи формат ответа** — формула? число? код? текст?

### 10.6 Специфичные поля по типу предмета

| Предмет | `formula` | `plot` | Код в `steps` |
|---------|-----------|--------|---------------|
| Математика | KaTeX формула | Кривые, области | Нет |
| Физика | Число + единицы | Схемы сил (если можно) | Нет |
| Программирование | Текстовое описание | Нет | `<pre><code>` |
| Линейная алгебра | KaTeX матрица/число | Нет (обычно) | Нет |
