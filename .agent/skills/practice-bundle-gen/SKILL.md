# Practice Bundle Generator

Генерация JSON-данных практических контрольных мероприятий для платформы `bauman-study`.
Практический бандл — это **самодостаточный инструмент для подготовки к решению задач**.

---

## 1. Когда использовать этот скилл

- КР (контрольная работа) — решение задач
- Практическая часть РК (задачи на площади, объёмы, НИ и т.д.)
- Практическая часть экзамена (задачи из билетов)
- Любой «задачник» или «тренажёр решения»

> **НЕ** используй для теоретических вопросов (определения, теоремы) — для этого есть `theory-bundle-gen`.

---

## 2. Ключевая концепция: три слоя

Практический бандл состоит из **трёх слоёв**:

### 🧠 Слой 1: «Секция 0 — Формулы и методы»
Карточки `type: "Алгоритм"` / `"Справочник"` — **всегда первая секция**.
Это сжатый справочник решателя: формулы, методы, алгоритмы действий.
> Эти карточки показываются полностью (без скрытия решения).

### 📝 Слой 2: «Секции задач»
Карточки `type: "Задача"` — задачи из источника с пошаговыми решениями.
> Решение **СКРЫТО по умолчанию** (practiceMode). Студент видит только условие.
> Кнопка «Показать решение» раскрывает: keyIdea, steps, formula (ответ), examSay.

### 📋 Слой 3: «Образцы билетов»
Последняя секция — полные варианты КР/экзамена для финальной самопроверки.
> Тоже с progressive disclosure (решение скрыто).

---

## 3. Структура выходных файлов

```
src/data/<subject>/<assessment>/
├── meta.json                              # practiceMode: true!
├── index.json
├── section-00-формулы-и-методы.json       # Слой 1: справочник
├── section-01-<тип-задач>.json            # Слой 2: задачи
├── section-02-<тип-задач>.json
├── ...
└── section-NN-образцы-билетов.json        # Слой 3: варианты
```

### meta.json

```json
{
  "title": "Интегралы и ДУ",
  "subtitle": "КР-1 · Техника интегрирования",
  "icon": "∫",
  "shortCode": "idkr1",
  "bundleName": "ИнтДУ_КР-1",
  "practiceMode": true
}
```

> **ОБЯЗАТЕЛЬНО** `"practiceMode": true` — это активирует скрытие решений в UI.

## 4. Схемы карточек

### 4.1 Карточка «Алгоритм» / «Справочник» (Слой 1)

Показывается полностью — это теоретическая основа для решения задач.

```json
{
  "id": "method-1",
  "title": "Метод подведения под знак дифференциала",
  "type": "Алгоритм",
  "tldr": "Ищем f(g(x))·g'(x) dx = f(t) dt",
  "formalText": "Если подынтегральное выражение можно представить в виде $f(g(x)) \\cdot g'(x)\\,dx$, то вводя замену $t = g(x)$, $dt = g'(x)\\,dx$, получаем табличный или более простой интеграл.",
  "keyIdea": "Заметить, что часть подынтегральной функции — производная аргумента другой части",
  "steps": [
    {
      "title": "1. Идентифицируй составную функцию",
      "text": "Найди $f(g(x))$ — внешнюю функцию от «внутренней»."
    },
    {
      "title": "2. Проверь наличие g'(x)",
      "text": "Убедись, что оставшаяся часть — это $g'(x)\\,dx$ (или отличается на константу)."
    },
    {
      "title": "3. Подведи под знак дифференциала",
      "text": "Запиши $g'(x)\\,dx = d(g(x))$ и сделай замену $t = g(x)$."
    },
    {
      "title": "4. Вычисли и обратно подставь",
      "text": "Вычисли $\\int f(t)\\,dt$ и подставь обратно $t = g(x)$."
    }
  ],
  "formula": "\\int f(g(x)) \\cdot g'(x)\\,dx = \\int f(t)\\,dt,\\quad t = g(x)",
  "example": {
    "title": "📝 Простой пример",
    "text": "$\\int \\sin(3x)\\,dx$. Замена $t = 3x$, $dt = 3\\,dx$:\n$\\frac{1}{3}\\int \\sin t\\,dt = -\\frac{\\cos 3x}{3} + C$"
  },
  "note": "Типичная ошибка: забыть множитель при замене (если $dg = 3dx$, нужен коэфф. $1/3$)."
}
```

**Типы карточек Слоя 1**:
- `"Алгоритм"` — метод решения с пошаговым алгоритмом
- `"Справочник"` — таблица формул (напр., табличные интегралы)
- `"Метод"` — краткое описание метода без развёрнутых шагов

### 4.2 Карточка «Задача» (Слой 2)

Решение скрыто по умолчанию — студент видит только `formalText` (условие).

```json
{
  "id": "task-1.1",
  "title": "Интеграл с корнем и логарифмом",
  "type": "Задача · 1 балл",
  "formalText": "Вычислить: $$\\int \\frac{\\sqrt[4]{5 + \\ln x}}{x}\\,dx$$",
  "tldr": "Подведение: dx/x = d(ln x)",
  "keyIdea": "Замена: t = 5 + ln x, тогда dt = dx/x",
  "steps": [
    {
      "title": "Подстановка",
      "text": "Заметим, что $\\frac{dx}{x} = d(\\ln x)$. Обозначим $t = 5 + \\ln x$, тогда $dt = \\frac{dx}{x}$.",
      "math": "$$\\int \\frac{\\sqrt[4]{t}}{1}\\,dt = \\int t^{1/4}\\,dt$$"
    },
    {
      "title": "Вычисление",
      "text": "Применяем степенную формулу:",
      "math": "$$\\int t^{1/4}\\,dt = \\frac{t^{5/4}}{5/4} = \\frac{4}{5}t^{5/4} + C$$"
    },
    {
      "title": "Обратная замена",
      "text": "Подставляем $t = 5 + \\ln x$:",
      "math": "$$\\frac{4}{5}(5 + \\ln x)^{5/4} + C$$"
    }
  ],
  "formula": "\\frac{4}{5}(5 + \\ln x)^{5/4} + C",
  "examSay": "Проверка: возьмите производную от ответа — должны получить подынтегральную функцию.",
  "note": "Этот тип задачи — классический на подведение п.з.д. На КР обычно 1-2 таких."
}
```

**Что видит студент ДО раскрытия**: только зелёный блок с условием (formalText).
**Что видит студент ПОСЛЕ нажатия «Показать решение»**: tldr, keyIdea, steps, formula (ответ), examSay, note.

### 4.3 Карточка «Билет» (Слой 3)

То же самое что «Задача», но `type: "Вариант КР"` и условие содержит несколько задач:

```json
{
  "id": "ticket-1",
  "title": "Вариант 0",
  "type": "Вариант КР",
  "formalText": "**Задача 1 (1 б.)**: Вычислить $\\int ...$\n\n**Задача 2 (2 б.)**: Вычислить $\\int ...$\n\n**Задача 3 (3 б.)**: ...",
  "steps": [
    {"title": "Задача 1", "text": "...решение..."},
    {"title": "Задача 2", "text": "...решение..."},
    {"title": "Задача 3", "text": "...решение..."}
  ],
  "formula": "Задача 1: ..., Задача 2: ..., Задача 3: ..."
}
```

## 5. Алгоритм генерации

### Шаг 1: Определить источники

1. **Файл задач** (ПРИОРИТЕТ):
   - `new_sources/<предмет>/Контрольное Мероприятие/<Код> - КР - N.txt`
   - или `new_sources/<предмет>/Сессия/<Код> - Сессия - Билеты.txt`
   - или `new_sources/<предмет>/Контрольное Мероприятие/<Код> - РК - N - Вопросы.txt` (раздел задач)

2. **Файл решений** (если есть):
   - `new_sources/<предмет>/Сессия/<Код> - Сессия - Решения.txt`

3. **Textbook / Лекции** — теоретическая основа для Слоя 1

4. **ДКР (домашние контрольные)** — доп. задачи:
   - `new_sources/<предмет>/Домашнее Задание/<Код> - ДКР - N.txt`

### Шаг 2: Проанализируй задачи и сгруппируй по методам

Прочитай файл задач. Определи:
- Какие **типы/методы** решения используются
- Как задачи **группируются** (обычно по разделам или методам)
- Какие **баллы** присвоены каждой задаче

### Шаг 3: Создай Слой 1 — «Формулы и методы»

Для каждого типа задач создай карточку-алгоритм:
1. Проанализируй, какая **теория** нужна для решения этого типа
2. Найди формулы и алгоритмы в textbook/лекциях
3. Создай пошаговый **рецепт** решения (steps)
4. Добавь простейший **пример** (example)
5. Добавь **типичные ошибки** (note)

> Если нужна справочная таблица (табличные интегралы, формулы сокращ. умножения и т.д.) — создай карточку `type: "Справочник"`.

### Шаг 4: Создай Слой 2 — задачи

Для каждой задачи из источника:
1. `formalText` — **точная** формулировка из источника (не перефразируй!)
2. `steps` — полное пошаговое решение
3. `formula` — финальный ответ
4. `keyIdea` — ключевой приём (для быстрого повторения)
5. `tldr` — тип задачи одним предложением
6. `examSay` — на что обратить внимание

> **КРИТИЧЕСКИ ВАЖНО**: Формулировку задачи (`formalText`) записывай **ТОЧНО** как в источнике. Перевод в KaTeX — ОК, но условие не изменяй.

### Шаг 5: Создай Слой 3 — образцы билетов

Если в файле-источнике есть образцы вариантов:
1. Каждый вариант → одна карточка
2. Полное решение в steps

### Шаг 6: Запиши и валидируй

1. Запиши все JSON-файлы
2. `meta.json` с `"practiceMode": true`
3. `index.json` со списком секций (секция 0 первая!)
4. Проверь в браузере: `http://localhost:5173/?subject=<subject>&assessment=<assessment>`

## 6. Стратегии по предметам

### 6.1 ИиДУ — КР по интегрированию

**Типы задач** → секции:
- Подведение под знак дифференциала
- Интегрирование по частям
- Тригонометрические подстановки
- Квадратный трёхчлен в знаменателе
- Дробно-рациональные функции
- Подстановки (универсальная, Эйлера)
- Смешанные методы

**Слой 1**: Табличные интегралы + алгоритм для каждого метода.

### 6.2 ИиДУ — Практика РК

**Типы задач**:
- Вычисление площадей (декартовы и полярные)
- Вычисление объёмов (вращение вокруг Ox, Oy)
- Длина дуги (декартовы и полярные)
- Площадь поверхности вращения
- Исследование НИ (несобственных интегралов)

### 6.3 ИиДУ — Практика экзамена

6 комплектов по 18 задач:
1. Интегралы
2. Геометрические приложения
3. Несобственные интегралы
4. ДУ (задачи Коши для ОДУ 2-го порядка)
5. Линейные ДУ (общий вид решения)
6. Метод вариации постоянной

### 6.4 ЛинАлг — КР по ФНП

**Типы задач**:
- Область определения ФНП
- Линии уровня
- Градиент и производная по направлению
- Пределы ФНП
- Частные производные
- Неявная функция
- Полный дифференциал

### 6.5 АЯ C++ — Практика экзамена

26 типовых задач на:
- Создание классов (1-10)
- Наследование и полиморфизм (11-20)
- Исключения (21-22)
- Многопоточность (23-26)

**Слой 1**: Шаблоны классов, паттерны наследования, синтаксис.
**Задачи**: formalText = полное условие, steps = решение с кодом.
**Код** в `steps`: использовать `<pre class="code-block"><code class="language-cpp">...</code></pre>`.
