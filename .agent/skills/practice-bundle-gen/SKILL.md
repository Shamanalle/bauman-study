# Practice Bundle Generator

Генерация JSON-данных практических контрольных мероприятий для платформы `bauman-study`.
Практический бандл — это **самодостаточный инструмент для подготовки к решению задач**.

---

## 1. Когда использовать этот скилл

- КР (контрольная работа) — решение задач
- Практическая часть РК (задачи на площади, объёмы, НИ и т.д.)
- Практическая часть экзамена (задачи из билетов)
- Любой «задачник» или «тренажёр решения»

> **НЕ** используй для теоретических вопросов (определения, теоремы) — для этого есть `theory-bundle-gen`.

---

## 2. Архитектура UI: табы а-ля лабы

Практический бандл использует **табовый интерфейс** (как лабы) — `practice-browser.js`.
Файл `meta.json` с `"practiceMode": true` активирует этот рендерер вместо стандартного карточного UI.

### 2.1 Общая визуальная структура

```
┌──────────────────────────────────────────────────────┐
│  ∫  Интегралы и ДУ                                   │  ← heroTitle (meta.icon + meta.title)
│  РК-1 · Практика                                     │  ← heroSubtitle (meta.subtitle)
├──────────────────────────────────────────────────────┤
│  [📋 Формулы] [📚 Методы] [✏️ Задачи] [🎯 Доп.] [🎫]│  ← Табы (по одному на секцию)
├──────────────────────────────────────────────────────┤
│  Все   Подведение₆  По частям₆  Кв.трёхчлен₂  ...   │  ← Фильтры по темам (только в ✏️)
├──────────────────────────────────────────────────────┤
│                                                      │
│  Содержимое текущей вкладки (#pracContent)            │  ← Рендерится по icon секции
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 2.2 Маршрутизация рендереров

Каждая секция (JSON-файл) содержит поле `icon`. При переключении вкладки, код выбирает рендерер:

```
icon: "📋" → renderFormulas()   — сетка карточек с формулами
icon: "📚" → renderMethods()    — карточки-алгоритмы с шагами
icon: "✏️" → renderProblems()   — задачи со скрытыми решениями + фильтры по темам
icon: "🎫" → renderTickets()    — билеты с per-task toggle
fallback   → renderFormulas()   — по умолчанию
```

> **КРИТИЧЕСКИ ВАЖНО:** `icon` определяет рендерер! Неверный icon = неверное отображение.
> И «Задачи» и «Доп. задачи» используют icon `"✏️"` — рендерятся одинаково.

### 2.3 Что рендерит каждая вкладка

#### 📋 Формулы (`renderFormulas`)
Простая **сетка карточек** — всё видно сразу, ничего не скрыто.
**Поля:** `title` (заголовок) + `formalText` (содержимое). Больше ничего не используется.

#### 📚 Методы (`renderMethods`)
**Полноразмерные карточки** с номером, заголовком, бейджем (tldr), и пронумерованными шагами:
**Поля:** `title`, `tldr` (badge), `steps[].title`, `steps[].text` (md), `steps[].math` (raw KaTeX).

#### ✏️ Задачи и Доп. задачи (`renderProblems`)
**Карточки с progressive disclosure** — условие видно, подсказка и решение скрыты.

**Фильтры по темам:** появляются автоматически, если ≥2 уникальных темы из last segment поля `type` (после последнего `·`). Длинные названия сокращаются в JS (`shortLabel`).

**Решение** рендерится с пронумерованными шагами:
```
┌─ (1) Анализ ─────────────────────────┐
│   Текст шага с объяснением...         │  ← prac-sol-step-text
│   $$формула$$                         │  ← prac-step-math
├─ (2) Замена ─────────────────────────┤
│   Обозначим t = ...                   │
│   $$\int ... = ...$$                  │
├─ (3) Ответ ──────────────────────────┤
│   $$\boxed{ответ}$$                   │
└──────────────────────────────────────┘
```

**Поля:** `id`, `title`, `type`, `formalText`, `tldr`, `hint`, `steps[]`, `formula`, `plot`.

#### 🎫 Билеты (`renderTickets`)
**Билеты с per-task раскрытием** — каждая задача раскрывается отдельно.
**Поля:** `id`, `title`, `type`, `formalText`, `steps[]` (1 step = 1 задача билета).

### 2.4 Файловая структура

```
src/data/<subject>/<assessment>/
├── meta.json                         # practiceMode: true!
├── index.json                        # ["section-00-...", "section-01-...", ...]
├── section-00-формулы.json           # icon: "📋"
├── section-01-методы.json            # icon: "📚"
├── section-02-задачи.json            # icon: "✏️"
├── section-03-доп-задачи.json        # icon: "✏️" (ОБЯЗАТЕЛЬНО)
└── section-04-билеты.json            # icon: "🎫"
```

> **ОБЯЗАТЕЛЬНО:** каждый практический бандл должен содержать **секцию «Доп. задачи»** (section-03-доп-задачи.json) с дополнительными задачами для тренировки; icon="✏️".

## 3. ЗОЛОТЫЕ ПРАВИЛА ФОРМАТИРОВАНИЯ

> ⚠️ **ЭТО САМЫЙ ВАЖНЫЙ РАЗДЕЛ. 90% ошибок происходят здесь.**

### 3.1 Текстовые поля обрабатываются функцией `md()`

Функция `md()` поддерживает:
- `**bold**` → `<strong>bold</strong>`
- `\n` → `<br>` (перенос строки)
- `- item\n- item` → `<ul><li>item</li><li>item</li></ul>` (bullet list)
- `$...$` и `$$...$$` — **сохраняются как есть** (передаются в KaTeX)

Функция `md()` применяется к полям: `title`, `text`, `tldr`, `formalText`, `keyIdea`.
Поле `math` вставляется **напрямую** (без md()) — оно должно быть **чистый KaTeX** в `$$...$$`.

### 3.2 Правила LaTeX в JSON

**ВСЕ обратные слэши в JSON удваиваются!** `\int` → `\\int`, `\frac{}{}` → `\\frac{}{}`.

```json
✅ "text": "Замена $t = \\ln x$ даёт $dt = \\frac{dx}{x}$."
✅ "math": "$$\\int \\frac{dx}{x\\ln^2 x} = -\\frac{1}{\\ln x} + C$$"
❌ "text": "Замена t = ln x"          // нет KaTeX — будет сырой текст
❌ "text": "Замена $t = \ln x$"       // одинарная \ — сломается
```

### 3.3 Inline-math ОБЯЗАТЕЛЬНО в `$...$`

Каждая математическая переменная, формула, выражение **ДОЛЖНА** быть в `$...$`:

```json
✅ "text": "$\\alpha = 2$ — простой корень → $s = 1$."
❌ "text": "α = 2 — простой корень → s = 1."     // Unicode вместо KaTeX
```

**НИКОГДА не используй Unicode-символы для математики** (α, β, ∫, √, ², ₁ и т.д.) в полях `text`, `formalText`, `steps[].text`.
Единственное исключение — поле `tldr`, где Unicode допустим, т.к. это справочный бейдж.

### 3.4 Поле `tldr` — краткое описание метода

`tldr` отображается как **бейдж** и должен быть:
- **Коротким** (< 60 символов)
- **Содержательным** — кратко описывает МЕТОД или ПРИЁМ
- Допускает Unicode
- **НЕ дублирует заголовок шага** (нельзя "Анализ", "Шаг 1:", "Подведение")

```json
✅ "tldr": "Подведение: dx/x = d(ln x)"
✅ "tldr": "Однородное ОДУ: t = y/x"
✅ "tldr": "Параметрически: S = ∫y·x'dt, ×4"
❌ "tldr": "Анализ"                          // бесполезно
❌ "tldr": "Шаг 1: Разложение:"              // это не описание метода
❌ "tldr": "Подведение п.з.д."               // дублирует type
```

### 3.5 Поле `hint` — подсказка для студента

Подсказка показывается по кнопке **«💡 Подсказка»** ПЕРЕД раскрытием решения.
Она должна давать **ключевую идею** без полного ответа:

```json
✅ "hint": "Подведение: $t = 5 + \\ln x$, $dt = \\frac{dx}{x}$"
✅ "hint": "Это уравнение Бернулли ($n=2$). Замена $z = y^{-1}$ → линейное"
✅ "hint": "Полярные координаты: $S = \\frac{1}{2}\\int \\rho^2\\,d\\varphi$"
❌ "hint": "Ответ: S = 3π/8"              // это ответ, не подсказка
❌ "hint": "Используй формулу S = ½∫ρ²dφ" // Unicode вместо KaTeX!
```

> **Приоритет:** `hint` → `keyIdea` → `tldr`. Если есть `hint` — он показывается.
> **ОБЯЗАТЕЛЬНО:** у КАЖДОЙ задачи в section-02 и section-03 должен быть `hint`.

### 3.6 Поле `math` — блочная формула

Поле `math` (в steps) вставляется **напрямую в HTML** и должно содержать ТОЛЬКО `$$...$$`:

```json
✅ "math": "$$\\int_0^1 t\\ln^2 t\\,dt = \\frac{1}{4}$$"
❌ "math": "\\int_0^1 t\\ln^2 t\\,dt = \\frac{1}{4}"    // нет $$..$$
❌ "math": "Формула: $$...$$"                             // текст в math
```

### 3.7 `\\boxed{}` — обязателен для финального ответа

Последний шаг каждого решения (или поле `math` в step «Ответ») **ОБЯЗАН** содержать `\\boxed{}`:

```json
✅ "math": "$$\\boxed{\\frac{4}{5}(5+\\ln x)^{5/4} + C}$$"
❌ "math": "$$= \\frac{4}{5}(5+\\ln x)^{5/4} + C$$"    // нет boxed
```

### 3.8 Поле `type` — тема задачи (для фильтров)

Поле `type` используется для **автоматических фильтров по темам**. Последний сегмент после `·` — это тема:

```json
✅ "type": "Задача · 1 балл · Подведение"     → тема: "Подведение"
✅ "type": "Задача · Бернулли"                → тема: "Бернулли"
✅ "type": "Задача · 3 балла · Площадь (полярные)" → тема: "Площадь (полярные)"
❌ "type": "Задача"                            // нет темы → фильтра не будет
```

Фильтры появляются если ≥2 разных темы в секции. Длинные названия автоматически сокращаются в UI.

### 3.9 Нумерация ID

```json
✅ "id": "1.1"         // задачи в section-02 (Группа.Номер)
✅ "id": "Д1.1"        // доп. задачи в section-03
✅ "id": "1"           // билеты в section-04
❌ "id": "ticket-1"    // текстовые ID запрещены
```

## 4. ПРАВИЛА КАЧЕСТВА РЕШЕНИЙ

> ⚠️ Это ВТОРОЙ по важности раздел. Именно здесь происходят самые частые проблемы.

### 4.1 Каждый шаг должен быть УНИКАЛЬНЫМ

Никогда не дублируй информацию между шагами:

```json
❌ ПЛОХО — дублирование между "Анализ" и "Подведение":
{
  "steps": [
    {"title": "Анализ", "text": "Замечаем: $d(x^2+1)=2x\\,dx$ → подведение"},
    {"title": "Подведение", "text": "Ключевое наблюдение: $d(x^2+1)=2x\\,dx$"},
    {"title": "Подведение", "text": "Применяем замену..."}
  ]
}

✅ ХОРОШО — каждый шаг уникален:
{
  "steps": [
    {"title": "Анализ", "text": "Видим $\\frac{x}{x^2+1}$ — числитель пропорционален производной знаменателя. Метод: подведение."},
    {"title": "Замена", "text": "Пусть $t = x^2+1$, $dt = 2x\\,dx$:", "math": "$$\\int\\frac{x\\,dx}{x^2+1} = \\frac{1}{2}\\int\\frac{dt}{t}$$"},
    {"title": "Интегрирование", "math": "$$= \\frac{1}{2}\\ln|t| + C$$"},
    {"title": "Ответ", "math": "$$\\boxed{\\frac{1}{2}\\ln(x^2+1) + C}$$"}
  ]
}
```

### 4.2 Минимум 3 шага для простых задач, 4-5 для сложных

| Сложность | Минимум шагов | Типичная структура |
|-----------|---|---|
| 1 балл (простая) | 3 | Анализ → Замена/Вычисление → Ответ |
| 1-2 балла | 4 | Анализ → Замена → Интегрирование → Ответ |
| 2-3 балла (сложная) | 5+ | Анализ → Замена → Разложение → Интегрирование → Обратная замена → Ответ |

### 4.3 Структура каждого шага

Каждый шаг решения должен содержать:
1. **title** — УНИКАЛЬНОЕ название (не "Подведение" два раза подряд)
2. **text** — объяснение: ЧТО делаем и ПОЧЕМУ
3. **math** (опционально) — формула или промежуточный результат

```json
✅ Хороший шаг:
{
  "title": "Разложение числителя",
  "text": "Ищем $4x+1 = \\alpha(2+4x-x^2)' + \\beta$. Производная: $(2+4x-x^2)' = 4-2x$.\n\nСравниваем: $-2\\alpha = 4 \\Rightarrow \\alpha = -2$; $4\\alpha + \\beta = 1 \\Rightarrow \\beta = 9$.",
  "math": "$$4x+1 = -2(4-2x) + 9$$"
}

❌ Плохой шаг (две проблемы: нет объяснения + заглушка):
{
  "title": "Решение",
  "text": "Стандартным методом.",
  "math": "$$\\text{Решение через замену Бернулли}$$"
}
```

### 4.4 ЗАПРЕЩЁННЫЕ фразы

Следующие фразы **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНЫ** в решениях:

| Запрещённая фраза | Что делать вместо |
|---|---|
| "вычисляется стандартно" | Покажи каждый шаг вычисления |
| "аналогично" | Покажи явно (даже если похоже) |
| "по формуле из лекций" | Напиши формулу и покажи подстановку |
| "несколько раз по частям" | Покажи КАЖДЫЙ раз по частям с $u$, $dv$ |
| "Решение через замену X" | Покажи замену, промежуточные шаги, итог |
| "Сводится к рациональной дроби" | Покажи разложение и интегрирование |

### 4.5 Эталон решения: задача КР-1 "Подведение"

Вот как должно выглядеть идеальное решение на 1 балл:

```json
{
  "id": "1.1",
  "title": "∫ ⁴√(5+ln x) / x dx",
  "type": "Задача · 1 балл · Подведение",
  "formalText": "**Вычислить:**\n$$\\int \\frac{\\sqrt[4]{5 + \\ln x}}{x}\\,dx$$",
  "tldr": "Подведение: dx/x = d(ln x)",
  "hint": "Подведение: $t = 5 + \\ln x$, $dt = \\frac{dx}{x}$",
  "steps": [
    {
      "title": "Анализ",
      "text": "В числителе стоит $\\sqrt[4]{5 + \\ln x}$ — составная функция от $\\ln x$. Замечаем, что $\\frac{dx}{x} = d(\\ln x)$. Это классический признак подведения."
    },
    {
      "title": "Замена переменной",
      "text": "Обозначим $t = 5 + \\ln x$. Тогда $dt = \\frac{dx}{x}$.\n\nПодынтегральное выражение переписывается:",
      "math": "$$\\int \\frac{\\sqrt[4]{5 + \\ln x}}{x}\\,dx = \\int t^{1/4}\\,dt$$"
    },
    {
      "title": "Интегрирование",
      "text": "Табличный интеграл $\\int t^n\\,dt = \\frac{t^{n+1}}{n+1} + C$ при $n = \\frac{1}{4}$:",
      "math": "$$\\int t^{1/4}\\,dt = \\frac{t^{5/4}}{5/4} = \\frac{4}{5}\\,t^{5/4} + C$$"
    },
    {
      "title": "Ответ",
      "text": "Обратная замена $t = 5 + \\ln x$:",
      "math": "$$\\boxed{\\frac{4}{5}(5 + \\ln x)^{5/4} + C}$$"
    }
  ],
  "formula": "\\frac{4}{5}(5 + \\ln x)^{5/4} + C"
}
```

Вот как должно выглядеть идеальное решение на 3 балла (ДУ):

      "title": "Замена Бернулли",

      "title": "Линейное ОДУ для z",
      "text": "ИМ: $\\mu = e^{\\int 2\\tan x\\,dx} = e^{-2\\ln|\\cos x|} = \\frac{1}{\\cos^2 x}$.\n\n$(z/\\cos^2 x)' = \\tan^2 x$. Интегрируем:",

    {

      "text": "ЗК $y(0) = 1$: $z(0) = 1$, $\\cos^2(0)(0 - 0 + C) = 1$ → $C = 1$.",

## 5. Схемы секций (JSON)

### 5.1 Секция «Формулы» (icon: `📋`)

```json
{
  "section": "📋 Формулы и справочник",
  "icon": "📋",
  "questions": [
    {
      "id": "f-1",
      "title": "Табличные интегралы",
      "formalText": "$$\\int x^n dx = \\frac{x^{n+1}}{n+1} + C$$\n\n$$\\int \\frac{dx}{x} = \\ln|x| + C$$"
    }
  ]
}
```

### 5.2 Секция «Методы» (icon: `📚`)

```json
{
  "section": "📚 Методы решения",
  "icon": "📚",
  "questions": [
    {
      "id": "m-1",
      "title": "Алгоритм: с разделяющимися переменными",
      "tldr": "Собираем x к dx, y к dy, интегрируем",
      "steps": [
        {
          "title": "Определи тип",
          "text": "Уравнение вида $f(x)g(y)\\,dx + h(x)p(y)\\,dy = 0$."
        },
        {
          "title": "Раздели переменные",
          "text": "Дели на $g(y) \\cdot h(x)$:\n\n**Пример:** $\\frac{dx}{x(y-1)}+\\frac{dy}{y(x+2)}=0$",
          "math": "$$\\frac{f(x)}{h(x)}dx = -\\frac{p(y)}{g(y)}dy$$"
        }
      ]
    }
  ]
}
```

> **ПРАВИЛО ПОДРОБНОСТИ МЕТОДОВ:** Каждый шаг метода должен содержать: (1) Что делать, (2) Как делать, (3) **Пример** с конкретными числами.

### 5.3 Секция «Задачи» (icon: `✏️`)

Все поля задачи — см. §4.5 выше.

> **ОБЯЗАТЕЛЬНЫЕ поля:** `id`, `title`, `type` (с темой!), `formalText`, `tldr`, `hint`, `steps[]`.
> **Последний шаг** ОБЯЗАН содержать `\\boxed{}` в `math`.

### 5.4 Секция «Доп. задачи» (icon: `✏️`)

```json
{
  "section": "🎯 Доп. задачи",
  "icon": "✏️",
  "questions": [...]
}
```

> **ВАЖНО:** icon = `"✏️"` (не `"🎯"`!), section label = `"🎯 Доп. задачи"`.
> Задачи имеют такую же полную структуру как в section-02. ID начинаются с "Д" (Д1.1, Д1.2...).
> Минимум **30 задач** для КР, **50 задач** для РК.
> Покрывай ВСЕ темы из section-02.

### 5.5 Секция «Билеты» (icon: `🎫`)

Каждый шаг билета = **одна задача** с полным пошаговым решением:

```json
{
  "section": "🎫 Образцы билетов",
  "icon": "🎫",
  "questions": [
    {
      "id": "1",
      "title": "Вариант 0 (билет 1)",
      "type": "Вариант КР · 8 задач · min 7 / max 12 баллов",
      "formalText": "**Задача 1** (1 б.): $\\int ...$\n\n**Задача 2** (1 б.): ...",
      "steps": [
        {
          "title": "Задача 1 · Подведение (1 б.)",
          "text": "**Тип:** подведение.\n\n**Замена:** $t = ..., dt = ...$\n\n**Интегрирование:** ...\n\n**Обратная замена:**",
          "math": "$$\\boxed{ответ}$$"
        }
      ]
    }
  ]
}
```

> **ПРАВИЛО ДЛЯ БИЛЕТОВ:**
> - Каждый step = 1 задача с **ПОЛНЫМ** решением (не "стандартным методом")
> - Каждый step ОБЯЗАН иметь `math` с `\\boxed{ответ}`
> - Текст решения: пошаговый (Тип → Замена → Вычисление → Ответ)
> - Минимум 2 билета на КР, 3 на экзамен

## 6. Интерактивные графики (plot) — ОПЦИОНАЛЬНО

Поле `plot` — опциональное. Используй для геометрических задач.

```json
"plot": {
  "curves": [
    {"type": "function", "expr": "x*x", "xRange": [0, 3], "label": "y=x²"},
    {"type": "parametric", "x": "pow(cos(t),3)", "y": "pow(sin(t),3)", "tRange": [0, 6.2832], "label": "Астроида"}
  ],
  "fills": [{"between": [0, 1], "xRange": [0, 2]}],
  "points": [{"x": 1, "y": 0, "label": "(1,0)"}],
  "xRange": [-1.5, 1.5],
  "yRange": [-1.5, 1.5]
}
```

**Правила:**
- Выражения в **JS-синтаксисе**: `pow(x,3)`, `cos(t)`, `sin(t)`, НЕ `x^3`
- `tRange` покрывает ПОЛНУЮ кривую (кардиоида: `[0, 6.2832]`)
- `fills.between` — индексы кривых (0-based)
- Подписи ключевых точек ОБЯЗАТЕЛЬНЫ
- Диапазоны с запасом 10-20%

## 10. Типичные ошибки (из реального опыта)

### Ошибка 1: «Шаги-дубли»
```json
❌ steps: [
  {"title": "Анализ", "text": "Замечаем: d(x²+1)=2x dx → подведение"},
  {"title": "Подведение", "text": "Ключевое наблюдение: d(x²+1)=2x dx"}, // ДУБЛЬ!
  {"title": "Подведение", "text": "Применяем замену и интегрируем..."}    // ДВА ОДИНАКОВЫХ ЗАГОЛОВКА!
]
```
**Правильно:** Анализ → Замена → Интегрирование → Ответ (уникальные заголовки).

### Ошибка 2: «tldr = "Анализ"»
```json
❌ "tldr": "Анализ"        // бесполезен
❌ "tldr": "Шаг 1:"        // бесполезен
✅ "tldr": "Подведение: dx/x = d(ln x)"
```

### Ошибка 3: «Решение — заглушка»
```json
❌ "math": "$$\\text{Сводится к рациональной дроби}$$"
❌ "math": "$$\\text{Решение через замену Бернулли}$$"
✅ "math": "$$\\boxed{\\frac{1}{2}\\ln(x^2+1) + C}$$"
```

### Ошибка 4: «Нет boxed в финальном ответе»
```json
❌ "math": "$$= \\frac{4}{5}(5+\\ln x)^{5/4} + C$$"
✅ "math": "$$\\boxed{\\frac{4}{5}(5+\\ln x)^{5/4} + C}$$"
```

### Ошибка 5: «type без темы»
```json
❌ "type": "Задача"                         // нет темы → нет фильтра
❌ "type": "Задача · 1 балл"               // нет темы
✅ "type": "Задача · 1 балл · Подведение"  // тема есть
```

### Ошибка 6: «Билет без math»
```json
❌ steps: [{"title": "Задача 1", "text": "Решение...", "math": ""}]
✅ steps: [{"title": "Задача 1", "text": "...", "math": "$$\\boxed{...}$$"}]
```

### Ошибка 7: «Unicode в text»
```json
❌ "text": "ИМ: μ = e^{∫ p(x)dx}"
✅ "text": "ИМ: $\\mu = e^{\\int p(x)dx}$"
```

### Ошибка 8: «md() ломает LaTeX»
Функция md() защищает `$...$` и `$$...$$` от bold/list regex.
Но если LaTeX содержит `*` (не как умножение) — может сломаться.
Используй `\\cdot` вместо `*` для умножения в LaTeX.

## 11. Адаптация под разные предметы

### 11.1 Универсальный шаблон

| Секция | Что содержит | Примеры |
|--------|-------------|---------|
| 📋 Формулы | Справочные формулы, таблицы | Табл. интегралов, формулы кинематики |
| 📚 Методы | Алгоритмы решения + примеры | Метод подстановки, закон Ньютона |
| ✏️ Задачи | Задачи с пошаговыми решениями | Интегралы, задачи на ускорение |
| 🎯 Доп. задачи | Расширенный задачник | Дополнительная практика |
| 🎫 Билеты | Образцы вариантов | Полные варианты с решениями |

### 11.2 Математические предметы
- `formula` = финальный ответ в KaTeX
- `plot` для геометрических задач
- Каждая подстановка/замена — отдельный шаг
- Каждая ЗК — отдельный шаг с числом

### 11.3 Физика
- `formula` = число + единицы ($= 4{,}2 \\text{ м/с}$)
- Каждая подстановка значений — отдельный шаг
- Проверка размерности — отдельный шаг

### 11.4 Программирование
- Код в `<pre class="code-block"><code class="language-cpp">...</code></pre>`
- Пример ввода/вывода в каждом решении
- `formula` = текстовое описание результата
