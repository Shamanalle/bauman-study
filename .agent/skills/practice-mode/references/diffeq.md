# Интегралы и ДУ — Practice Mode Reference

## 1. Специфика предмета

ИнтДУ — самый **вычислительно-тяжёлый** предмет. Задачи — цепочки алгебраических
преобразований, где каждый шаг опирается на предыдущий. Ошибка на раннем шаге
каскадно ломает всё решение.

Ключевая проблема студента: **не может определить метод решения**.
Студент видит `∫ x·cos²x dx` и не знает — это подведение? По частям? Замена?

## 2. Адаптация UI для ИнтДУ

### 2.1 Тренировка

**Что критически важно:**
- **Подсказка метода** — для ИнтДУ это КЛЮЧЕВАЯ фича. Студент застрял = не знает
  какой метод. Hint должен быть ЧЁТКИМ: «Подведение: t = ..., dt = ...»
- **Пошаговое решение** часто длинное (5-7 шагов) — прогресс-бар в steps полезен
- **Формулы** — основной контент, почти в каждом шаге есть `math`
- **Справочник** перед тренировкой КРИТИЧЕН — формулы и методы нужны под рукой

**Организация по темам:**
Поле `type` содержит метод после последнего `·`:
- `Подведение`, `По частям`, `Рац. дроби`, `Тригонометрия`
- `Площадь (декартовы)`, `Площадь (полярные)`, `Объём (Ox)`, `Длина дуги`
- `НИ 1-го рода`, `НИ 2-го рода`
- `Составление ЛОДУ`, `Задача Коши`, `Вариация постоянных`, `Подбор частного`

Это идеальная структура для **фокусированных сессий**: «сегодня тренирую подведение».

### 2.2 Контрольная

Контрольные ИнтДУ:
- КР-1: 8 задач, 60 минут (неопределённые + определённые интегралы)
- КР-2: 4-5 задач, 45 минут (ОДУ)
- Экзамен: 6 задач, 120 минут (всё)

Билеты содержат задачи с указанием баллов и типа. Используй section-04 для генерации.

## 4. Проверка качества для ИнтДУ

При ревизии обрати внимание:
- **Цепочка замен** — каждый шаг корректно ссылается на предыдущий?
- **Обратная замена** — не забыл вернуться к исходной переменной?
- **Пределы интегрирования** — при определённом интеграле пересчитаны для новой переменной?
- **Знак** — ошибки в знаках при интегрировании по частям крайне часты
- **+C** — в неопределённом интеграле ответ содержит `+ C`?
- **\boxed** — последний шаг содержит `\boxed{}`?
- **Длинные решения** — не деградировало ли качество к 5-7 шагу?

## 5. Примечания по реализации

- Решения ИнтДУ САМЫЕ ДЛИННЫЕ из всех предметов (5-7 шагов)
- Подсказка метода = ключевая фича, важнее чем для других предметов
- Справочник формул и алгоритмов КРИТИЧЕН — студент без шпаргалки не решит
- Графики (plot) есть для задач на площадь и объём — renderPlots() нужен
- Типы задач идеально мапятся на темы — лучшая структура для фильтрации
