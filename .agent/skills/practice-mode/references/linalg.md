# Линейная Алгебра и ФНП — Practice Mode Reference

## 1. Специфика предмета

ЛинАлг — это **два совершенно разных блока** в одном предмете:

1. **РК-1 (Линейная алгебра)**: матрицы, базисы, квадратичные формы,
   собственные числа, линейные операторы — **алгебраические** вычисления
2. **РК-2 + КР-1 (ФНП)**: частные производные, градиент, экстремумы,
   условный экстремум — **аналитические** вычисления (ближе к ИнтДУ)

Эти два блока требуют **разного подхода** к тренировке.

## 2. Адаптация UI для ЛинАлг

### 2.1 РК-1 (Линейная алгебра)

**Что важно:**
- **Матрицы** — `\begin{pmatrix}...\end{pmatrix}` должны рендериться корректно.
  Большие матрицы (4×4) могут не влезать на мобильном — нужен overflow-x scroll
- **Собственные числа** — решения часто содержат характеристическое уравнение
  3-й степени. Шаги: уравнение → корни → собственные векторы для каждого корня
- **Квадратичные формы** — два метода (ортогональное преобразование vs Лагранж).
  Hint должен указывать КАКОЙ метод

**Подсказка:**
- Для собственных чисел: `"$\\det(A - \\lambda E) = 0$, раскрой определитель 3×3 по 1-й строке"`
- Для квадр. форм: `"Ортогональное: найди собственные числа → каноническая форма"`

### 2.2 РК-2 + КР-1 (ФНП)

**Что важно:**
- **Частные производные** — цепное правило, неявные функции. Steps короче чем ЛА
- **Экстремум** — алгоритм: grad = 0 → критические точки → достаточное условие (Δ)
- **Условный экстремум** — метод Лагранжа: система уравнений + проверка

**Подсказка:**
- Для экстремума: `"Найди $f'_x = 0, f'_y = 0$. Проверь $\\Delta = AC - B^2$"`
- Для условного: `"Лагранжиан: $L = f - \\lambda g$. Система: $L'_x = L'_y = g = 0$"`

### 2.3 Контрольная

- РК-1: 3-4 задачи, 90 минут, 8 баллов за каждую (итого 24-32)
- РК-2: 3-4 задачи, 90 минут, 8 баллов за каждую
- КР-1: 5 задач, 90 минут, 3 балла за каждую (15 баллов)

## 4. Проверка качества для ЛинАлг

При ревизии обрати внимание:
- **Матрицы** — корректно рендерятся? `\begin{pmatrix}` не сломан?
- **Размер матриц** — 3×3, 4×4 не обрезаются на мобильном?
- **Собственные числа** — характеристическое уравнение решено верно?
  Корни подставлены обратно? Собственные векторы найдены для КАЖДОГО λ?
- **Крит. Сильвестра** — знаки миноров проверены?
- **ФНП: частные производные** — правильно ли применено цепное правило?
- **Условный экстремум** — система Лагранжа корректна? Множитель λ найден?

## 5. Примечания по реализации

- ЛинАлг = 2 разных предмета в одном. Подумай о разделении на суб-темы
- Матрицы — основная визуальная проблема. Тестируй рендеринг `pmatrix` обязательно
- Решения средней длины (3-5 шагов), но содержат тяжёлый KaTeX
- 11 задач в midterm-1-practice и 14 в midterm-2-practice имеют `type: undefined` — 
  это задачи без типа, их нужно обрабатывать gracefully
- kr-1-practice: смесь ФНП-задач с баллами (3 б.) + дополнительных + варианты КР
