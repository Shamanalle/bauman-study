# Физика — Practice Mode Reference

## 1. Специфика предмета

Физика — это **формулы + размерности + графики**. Задачи требуют:
- Определить какой закон/формулу применить (кинематика? энергия? импульс?)
- Подставить числа с ЕДИНИЦАМИ измерения
- Получить ответ с правильной размерностью

### Типы задач по бандлам

| Бандл | Кол-во задач | Ключевые типы |
|-------|-------------|---------------|
| midterm-1-practice | 99 | Механика: кинематика, динамика, энергия, импульс, вращение |
| midterm-2-practice | 97 | Термодинамика, МКТ, волны, СТО |
| exam-practice | 100 | Всё вместе (объединение РК1 + РК2) |

### Особенности данных

```json
{
  "type": "Задача · Термодинамика",     // тема фильтра
  "type": "Билет · СТО",                // задача из билета
  "formalText": "**Дано:**\n$m = 2$ кг\n$v_0 = 5$ м/с\n...\n\n**Найти:** $a$, $F$",
  "hint": "2-й закон Ньютона: $F = ma$. Найди ускорение из кинематики.",
  "steps": [...],
  "formula": "a = 2.5 \\text{ м/с}^2"    // ← единицы в ответе!
}
```

## 2. Адаптация UI для физики

### 2.1 Тренировка

**Что важно:**
- **formalText** часто содержит секцию «Дано» + «Найти» — она должна быть чётко видна
- Формулы с единицами (`\text{ м/с}`, `\text{ Дж}`) — убедись что KaTeX рендерит `\text{}`
- **Графики** (plot) могут быть в задачах на волны, колебания — renderPlots() нужен

**Подсказка (hint):**
- Для физики hint = какой ЗАКОН применить + ключевая формула
- Пример: `"2-й закон Ньютона: $F = ma$. Ускорение найди из $v^2 = v_0^2 + 2as$"`

### 2.2 Контрольная

Физические контрольные обычно:
- РК: 10-15 задач, 90 минут, разные темы
- Экзамен: 5-6 задач, 120 минут, all topics

Билеты содержат задачи типа `Билет · Термодинамика` — используй их для генерации.

## 4. Проверка качества для физики

При ревизии обрати внимание:
- **Единицы измерения** — в ответе (`\boxed{}`) есть единицы?
- **Размерность** — промежуточные формулы размерно согласованы?
- **Числовые значения** — подстановка чисел корректна? Арифметика верна?
- **Графики** — если задача геометрическая (волна, колебание), нет ли plot?

## 5. Примечания по реализации

- Физические задачи часто КОРОЧЕ математических (меньше шагов замен)
- Но требуют АНАЛИЗ условия (выбор закона) — hint очень важен
- Единицы в `\text{}` — проверь что KaTeX не ломается
- Билеты физики разделены по темам (`Билет · СТО`) — используй для фильтрации
