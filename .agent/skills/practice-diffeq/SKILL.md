# Practice Mode: Интегралы и ДУ

Предметный скилл для реализации тренировочного и экзаменационного режимов
решения задач по «Интегралам и дифференциальным уравнениям».

> ### 🎯 Почему ИнтДУ — самый важный предмет для тренажёра
>
> ИнтДУ — единственный предмет, где студент **полностью зависит от навыка**.
> Нельзя «угадать» интеграл. Нельзя «вспомнить» решение ОДУ.
> Нужно **уметь решать**: видеть метод, делать замену, не терять знаки, доводить до ответа.
>
> Это самый **вычислительно-тяжёлый** предмет: решения — цепочки из 5-7 алгебраических
> шагов, где ошибка на 2-м шаге каскадно ломает всё. И основная проблема студента —
> **он не может определить метод**. Видит `∫ x·cos²x dx` и не знает: подведение?
> По частям? Тригонометрия? Тренажёр должен решить именно эту проблему.
>
> **Нет лимита на итерации.** Качество — единственная метрика. Итеративно доводи
> до состояния, когда студент скажет «блин, удобно, хочу ещё».

1. **Прочитай мастер-скилл** `practice-mode/SKILL.md` — общая архитектура и цикл качества
2. **Прочитай кодовую базу** — файлы из §2 мастер-скилла
3. **Изучи данные ИнтДУ** — прочитай хотя бы один JSON из каждого бандла:

```
src/data/differential-equations/midterm-1-practice/  ← КР-1: интегралы
src/data/differential-equations/midterm-2-practice/  ← КР-2: ОДУ
src/data/differential-equations/exam-practice/       ← экзамен: всё
```

Обрати внимание на:
- Поле `type` — метод решения после `·` (`Подведение`, `Бернулли`, `Вариация`)
- Поле `hint` — подсказка метода с KaTeX
- Поле `steps` — пошаговые решения (5-7 шагов для сложных задач)
- Поле `formula` — финальный ответ
- Поле `plot` — графики для геометрических задач

## 2. Специфика ИнтДУ

### 2.1 Типы задач

ИнтДУ — это ДВА совершенно разных блока:

**КР-1 / РК-1 (Интегралы):**
| Тема | Суть | Что студент должен уметь |
|------|------|--------------------------|
| Подведение | `∫ f(g(x))·g'(x) dx` | Заметить что числитель ≈ производная знаменателя |
| По частям | `∫ u dv = uv - ∫ v du` | Правильно выбрать u и dv |
| Рац. дроби | Разложение + интегрирование | Разложить на простейшие, проинтегрировать дроби |
| Тригонометрия | sin²x, cos²x, tg³x... | Понижение степени, замена |
| Площадь | `S = ∫ |f(x) - g(x)| dx` | Найти пределы, правильная разность |
| Объём | Диски, оболочки, кольца | Выбрать метод, записать формулу |
| Длина дуги | `L = ∫ √(1 + y'²) dx` | Вычислить производную, проинтегрировать |
| НИ | Сходимость + вычисление | Признаки сравнения, предельный |

**КР-2 / РК-2 (ОДУ):**
| Тема | Суть | Что студент должен уметь |
|------|------|--------------------------|
| Разделяющиеся | `f(x)g(y)dx + h(x)p(y)dy = 0` | Разделить переменные, проинтегрировать |
| Однородные | `y' = φ(y/x)` | Подстановка t = y/x |
| Бернулли | `y' + P(x)y = Q(x)·yⁿ` | Замена z = y^(1-n) → линейное |
| ЛОДУ | `a·y'' + b·y' + c·y = f(x)` | Характ. уравнение → определить структуру частного |
| Вариация | Метод вариации постоянных | Система для C₁'(x), C₂'(x) |

### 2.2 Что делает тренажёр ИнтДУ особенным

1. **Подсказка метода — ключевая фича.** Для ИнтДУ это КРИТИЧНО. Студент застрял = не знает метод.
   Hint должен быть максимально конкретным:
   - ✅ `"Подведение: $t = 5 + \ln x$, $dt = \frac{dx}{x}$"`
   - ✅ `"Бернулли ($n=2$): замена $z = y^{-1}$ → линейное для $z$"`
   - ❌ `"Используй подходящий метод"` — бесполезно

2. **Справочник перед тренировкой — КРИТИЧЕН.** Студент не решит интеграл без формул.
   Формулы и алгоритмы (section-00, section-01) должны быть доступны одним кликом.

3. **Решения длинные** (5-7 шагов). UI должен не пугать длиной, а помогать: прогресс-бар
   внутри steps? Плавное раскрытие? Подумай, как показать 7 формул не перегрузив экран.

4. **Графики (plot)** есть для задач на площадь/объём — нужен renderPlots().

## 3. Как думать (творческая свобода для ИнтДУ)

### Про определение метода

Это **ключевая педагогическая проблема** для ИнтДУ. Варианты, как тренажёр может помочь:

- **Вариант A**: показать тип задачи до раскрытия (badge «Подведение»). Студент знает метод,
  тренирует технику.
- **Вариант B**: скрыть тип задачи. Кнопка «Какой метод?» → показать тип.
  Студент сначала сам думает «что за метод», потом проверяет.
- **Вариант C**: quiz-элемент «Определи метод:» → кнопки [Подведение] [По частям] [Замена] →
  правильно-неправильно → потом раскрытие.

Какой вариант лучше? Зависит от уровня студента. Может, все три — это разные «уровни
сложности» тренировки? **Подумай и реши сам.**

### Про пошаговое раскрытие

Для ИнтДУ раскрытие всего решения сразу может быть overwhelming. Варианты:
- Всё сразу (как сейчас в practice-browser)
- Шаг за шагом (по клику «следующий шаг»)
- Первые 2 шага сразу, остальные — по клику

Что лучше для обучения? **Подумай и реши сам.**

### Про группировку задач

ИнтДУ идеально ложится на тематические сессии:
- «Сегодня тренирую подведение» → 8 задач на подведение
- «Завтра — рациональные дроби» → 6 задач на дроби
- Перед контрольной: «Все вперемешку» → случайная выборка

Карта покрытия по темам здесь ОЧЕНЬ полезна — студент видит:
```
Подведение         ████████░░  80%
По частям          ██████░░░░  60%
Рац. дроби         ██░░░░░░░░  20%  ← слабое место!
ОДУ Бернулли       ░░░░░░░░░░  новое
```

## 4. Контрольная ИнтДУ — специфика

| КМ | Задачи | Время | Структура |
|----|--------|-------|-----------|
| КР-1 | 8 | 60 мин | 4 неопр. + 2 опред. + 1 НИ + 1 прил. |
| КР-2 | 4-5 | 45 мин | 2 ОДУ-1 + 2 ЛОДУ + 1 вариация |
| Экзамен | 6 | 120 мин | 2 интегр. + 2 прил. + 2 ОДУ |

Симулятор контрольной должен максимально точно воспроизводить эту структуру.
В section-04 (билеты) есть образцы — используй их для генерации.

## 5. Цикл качества (дополнение к мастер-скиллу)

Помимо 5 осей из мастер-скилла, для ИнтДУ дополнительно проверь:

### КОНТЕНТ — специфика ИнтДУ
- Формулы с `+C` в неопределённых интегралах отображаются?
- Пределы интегрирования в определённых — видны, не обрезаны?
- `\boxed{}` в последнем шаге — рендерится в рамку?
- Длинные цепочки замен (5-7 шагов) — не сливаются в кашу?
- Графики для задач на площадь — renderPlots() работает?

### ПЕДАГОГИКА — специфика ИнтДУ
- Подсказка метода — конкретная? Содержит замену и ключевую подстановку?
- Студент РЕАЛЬНО тренирует определение метода? Или просто жмёт «показать»?
- Справочник формул доступен? Открывается без закрытия текущей задачи?
- Для ОДУ: студент может отличить Бернулли от однородного? Тренажёр помогает?
- Для НИ: признаки сходимости в справочнике? Студент знает когда какой применить?

### ЛАКОНИЧНОСТЬ — специфика ИнтДУ
- 7-шаговое решение не превращается в стену текста?
- Прогресс внутри решения виден? Студент понимает «осталось 2 шага»?

## 6. Антипаттерны для ИнтДУ

- ❌ Показывать тип задачи (метод) прямо в условии — это спойлер
- ❌ Подсказка «Используй правильную формулу» — бесполезна
- ❌ Справочник в отдельном окне/вкладке — студент потеряет контекст
- ❌ Генерировать случайный билет без учёта структуры реальной КР
- ❌ Не проверять renderPlots() для геометрических задач
- ❌ Игнорировать что ОДУ (КР-2) и интегралы (КР-1) — разные навыки
