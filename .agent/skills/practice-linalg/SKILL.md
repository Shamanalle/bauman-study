# Practice Mode: Линейная Алгебра и ФНП

Предметный скилл для реализации тренировочного и экзаменационного режимов
решения задач по «Линейной алгебре и функциям нескольких переменных».

> ### 🎯 Почему ЛА+ФНП — это два предмета в одном
>
> ЛинАлг — уникальный случай: это **два абсолютно разных навыка** под одной вывеской:
>
> 1. **Линейная алгебра (РК-1)**: матрицы, базисы, квадратичные формы, собственные числа.
>    Абстрактная алгебра + вычисления с матрицами. Навык: **аккуратная работа с многоэтажными
>    конструкциями** (определитель 3×3, обратная матрица, ортогонализация).
>
> 2. **ФНП (РК-2, КР-1)**: частные производные, градиент, экстремумы, условный экстремум.
>    По сути это **продолжение матана**, но для функций от 2-3 переменных.
>    Навык: **дифференцирование + алгоритм поиска экстремума**.
>
> Тренажёр должен учитывать эту двойственность. Студент, готовящийся к РК-1 (матрицы),
> и студент, готовящийся к КР-1 (ФНП) — это разные студенты с разными потребностями.
>
> **Нет лимита на итерации.** Качество — единственная метрика.

- Некоторые задачи имеют `type: undefined` — gracefully handle

## 2. Специфика ЛА + ФНП

### 2.1 Типы задач

**РК-1 (Линейная алгебра):**
| Тема | Суть | Ключевой навык |
|------|------|---------------|
| Матрица перехода | Базис → базис | Построить матрицу T, проверить T·e' = e |
| Координаты вектора | Разложение по базису | Решить СЛАУ, проверить |
| Линейная оболочка | Линейно зависимые/независимые | Определитель, ранг |
| Собственные числа | det(A−λE) = 0 | Характ. уравнение 3-й степени |
| Собственные векторы | (A−λE)x = 0 | СЛАУ для каждого λ |
| Квадратичная форма | Каноническая форма | Ортогональное преобразование или Лагранж |
| Критерий Сильвестра | Знакоопределённость | Угловые миноры |
| Ортогонализация | Грам—Шмидт | Алгоритм: проекции + вычитание |

**РК-2 + КР-1 (ФНП):**
| Тема | Суть | Ключевой навык |
|------|------|---------------|
| Частные производные | f'x, f'y, f''xy | Цепное правило, неявная функция |
| Градиент | grad f = (f'x, f'y, f'z) | Вычислить компоненты, направление |
| Касательная плоскость | z - z₀ = f'x(Δx) + f'y(Δy) | Вычислить в точке |
| Экстремум | f'x = f'y = 0, Δ = AC - B² | Найти критич. точки, проверить |
| Условный экстремум | Лагранжиан L = f - λg | Система: L'x = L'y = g = 0 |
| Область определения | D(f) | Ограничения: корни, логарифмы |
| Предел ФНП | lim f(x,y) | По разным путям → не существует |

### 2.2 Что делает тренажёр ЛА особенным

1. **Матрицы — главный визуальный вызов.** `\begin{pmatrix}` рендерится в KaTeX,
   но на мобильном 4×4 матрица может обрезаться. **Обязательно** проверь overflow.
   Может понадобиться `overflow-x: auto` на контейнере с формулами.

2. **Два разных навыка = два разных UI?** Студент, тренирующий собственные числа,
   и студент, тренирующий экстремум ФНП — это разные сессии. Карта покрытия
   должна чётко разделять: «ЛА (РК-1)» vs «ФНП (РК-2)».

3. **Алгоритмические задачи.** Собственные числа, ортогонализация — это АЛГОРИТМЫ
   с фиксированными шагами. Подсказка = «Какой алгоритм?» + первый шаг.
   - ✅ `"Характ. ур-ие: $\det(A - \lambda E) = 0$. Раскрой определитель по 1-й строке"`
   - ✅ `"Критерий: $\Delta = AC - B^2$. Найди $A = f''_{xx}$, $B = f''_{xy}$, $C = f''_{yy}$"`

4. **Длинные матричные вычисления.** Определитель 3×3 — это 6 слагаемых.
   Обратная матрица — это N² миноров. Steps должны быть **чёткие и читаемые**,
   несмотря на объём формул.

## 3. Как думать (творческая свобода для ЛА)

### Про двойственность РК-1 / РК-2

Главный вопрос: это ОДИН тренажёр с разделением по темам или ДВА разных тренажёра?

- **Вариант A**: Один тренажёр. Setup-экран показывает все темы вместе.
  Студент выбирает «Собственные числа» или «Экстремум ФНП» из общего списка.
- **Вариант B**: Setup-экран имеет два блока: «ЛА (РК-1)» и «ФНП (РК-2/КР-1)».
  Разные прогресс-бары, разные сессии.
- **Вариант C**: Полное разделение: practice-browser показывает два отдельных
  бандла, и тренажёр запускается для каждого независимо (это уже так и есть —
  midterm-1-practice и midterm-2-practice — разные бандлы).

Вариант C — архитектурно самый простой (каждый бандл = отдельный тренажёр).
**Подумай, достаточно ли этого, или нужна доп. навигация.**

### Про матричный рендеринг

Матрицы в KaTeX:
```
$$\begin{pmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 9 \end{pmatrix}$$
```

На десктопе — красиво. На мобильном (320px) — может обрезаться.
Варианты:
- `overflow-x: auto` с горизонтальным скроллом
- Уменьшить размер шрифта для math-блоков с матрицами
- Ничего не делать (большинство студентов используют десктоп/ноутбук)

**Проверь на реальных данных и реши сам.**

### Про алгоритмические задачи

Собственные числа, ортогонализация, приведение к канонической форме —
это задачи с **фиксированным алгоритмом**. Студент должен: (1) знать алгоритм,
(2) аккуратно его выполнить.

Для таких задач справочник (section-01: алгоритмы) — КРИТИЧЕН.
Может, для ЛА стоит показывать алгоритм прямо рядом с задачей?
Или как pop-up по клику «📚 Алгоритм»? **Подумай и реши сам.**

### Про задачи ФНП

ФНП-задачи ближе к ИнтДУ:
- Вычислить частную производную
- Найти критические точки
- Проверить условие

Это скорее **вычислительные** задачи с чётким алгоритмом.
Подсказка здесь = алгоритм (шаги): «1. Найти f'x, f'y. 2. Решить систему. 3. Проверить Δ.»

## 5. Цикл качества (дополнение к мастер-скиллу)

### КОНТЕНТ — специфика ЛА
- `\begin{pmatrix}` — рендерится? Не обрезается на 320px?
- Определитель 3×3 — расписан по строке/по саррусу, видно?
- Характеристическое уравнение с λ — степени рендерятся?
- Системы уравнений — выравниваются красиво или разъезжаются?
- `\boxed{}` — рендерится в рамку?

### ПЕДАГОГИКА — специфика ЛА
- Студент тренирует АЛГОРИТМ, а не подстановку в формулу?
- Для собственных чисел: подсказка содержит «det(A-λE)=0, раскрой по строке»?
- Для ФНП: подсказка содержит «f'x = 0, f'y = 0 → критич. точки → Δ = AC - B²»?
- Справочник алгоритмов доступен? Студент может посмотреть алгоритм Грам—Шмидта
  не закрывая задачу?
- РК-1 и РК-2 чётко разделены в карте покрытия?

### ЛАКОНИЧНОСТЬ — специфика ЛА
- Матричные вычисления (определитель, обратная) — не перегружают экран?
- Может, для больших вычислений нужен compact/expanded toggle?
- Setup-экран не перегружен темами (ЛА имеет 8+ тем в РК-1)?

## 6. Антипаттерны для ЛА

- ❌ Не проверять рендеринг `\begin{pmatrix}` — матрицы сломаются
- ❌ Смешивать темы РК-1 (матрицы) и РК-2 (ФНП) в одной сессии без предупреждения
- ❌ Показывать алгоритм (метод) прямо в условии — спойлер
- ❌ Подсказка «Используй алгоритм» без указания КАКОЙ алгоритм
- ❌ Игнорировать что задачи РК-1 по 8 баллов (длинные) vs КР-1 по 3 балла (короткие)
- ❌ Не handle'ить `type: undefined` — некоторые задачи без типа
