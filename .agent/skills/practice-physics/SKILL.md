# Practice Mode: Физика

Предметный скилл для реализации тренировочного и экзаменационного режимов
решения физических задач.

> ### 🎯 Почему физика — особенный предмет для тренажёра
>
> Физика отличается от математики принципиально. В математике метод решения —
> это последовательность алгебраических операций. В физике **нет формулы для решения задачи**.
> Есть законы, а задача — понять КАКОЙ закон применить и КАК записать его для данной ситуации.
>
> Студент видит «Тело массой 2 кг скользит по наклонной плоскости...»
> и должен: (1) Нарисовать силы. (2) Выбрать систему координат. (3) Записать 2-й закон Ньютона
> в проекциях. (4) Подставить числа. (5) Проверить размерность.
>
> Тренажёр должен помочь студенту **думать как физик**: от ситуации к закону,
> от закона к уравнению, от уравнения к числу с единицей измерения.
>
> **Нет лимита на итерации.** Делай столько, сколько нужно для wow-результата.

## 1. Перед началом

1. **Прочитай мастер-скилл** `practice-mode/SKILL.md`
2. **Прочитай кодовую базу** — файлы из §2 мастер-скилла
3. **Изучи данные физики:**

```
src/data/physics/midterm-1-practice/    ← РК-1: механика, колебания
src/data/physics/midterm-2-practice/    ← РК-2: МКТ, термодинамика, волны, СТО
src/data/physics/exam-practice/         ← экзамен: всё
```

Обрати внимание на:
- Поле `formalText` — часто содержит «Дано: ... Найти: ...» — это КЛЮЧЕВОЙ формат
- Поле `hint` — подсказка: какой закон/формулу применить
- `formula` — ответ с единицами (`\text{ м/с}`, `\text{ Дж}`)
- Поле `type` — тема (`Термодинамика`, `СТО`, `Динамика`)

## 2. Специфика физики

### 2.1 Типы задач

**РК-1 (Механика + Колебания):**
| Тема | Суть | Ключевой навык |
|------|------|---------------|
| Кинематика МТ | Движение точки | Выбрать уравнение движения, найти ускорение/скорость |
| Динамика | Силы F=ma | Нарисовать силы, записать 2-й закон в проекциях |
| Работа и энергия | W = ΔKE, закон сохранения | Выбрать ЗСЭ vs ЗСИ, записать до и после |
| Импульс | p = mv, столкновения | Типы столкновений: упругое vs неупругое |
| Вращение | I, M, ε | Момент инерции + теорема Штейнера |
| Колебания | x = A·cos(ωt+φ₀) | Начальные условия → A, ω, φ₀ |

**РК-2 (Термодинамика + Волны + СТО):**
| Тема | Суть | Ключевой навык |
|------|------|---------------|
| МКТ | Уравнение состояния, газы | PV = νRT, изопроцессы |
| Термодинамика | Циклы, КПД, 1-е и 2-е начала | Расчёт по циклу, КПД |
| Волны | Стоячие, звук, интерференция | Узлы/пучности, условие интерференции |
| СТО | Лоренц, E=mc², сложение v | Формулы Лоренца, инвариант E²-p²c² |

### 2.2 Что делает тренажёр физики особенным

1. **Структура «Дано — Найти — Решение»** — это DNA физической задачи.
   Текущий `formalText` часто содержит «Дано: ...». UI тренажёра может
   визуально выделить эту структуру (или нет — решай сам).

2. **Подсказка = какой закон применить.** Не формула, а закон:
   - ✅ `"ЗСЭ: $K_1 + U_1 = K_2 + U_2$. Найди $v$ из закона сохранения"`
   - ✅ `"2-й Ньютон в проекции на ось $Ox$: $ma = F\cos\alpha - f_{тр}$"`
   - ❌ `"Подставь формулу"` — какую?

3. **Единицы измерения** — ответ без единиц = неправильный ответ.
   Проверь что `\text{}` в KaTeX рендерится корректно.

4. **SVG/графики** — физические задачи часто требуют рисунков (силы, схемы).
   Если в данных есть `plot` — renderPlots() нужен.

## 3. Как думать (творческая свобода для физики)

### Про «Дано — Найти»

Физическая задача начинается с выписывания «Дано» и «Найти». Варианты:
- **A**: Показывать formalText как есть (уже содержит «Дано: ... Найти: ...»)
- **B**: Парсить formalText и визуально разделить — карточка «Дано» слева, «Найти» справа
- **C**: Показать только текст задачи, без «Дано/Найти» — пусть студент сам выпишет

Вариант C — самый педагогически ценный (навык выписывания «Дано» = навык решения),
но может быть frustrating. **Подумай, что лучше для студента за день до РК.**

### Про выбор закона

Физика = выбор правильного закона. Как тренажёр может помочь:
- Показать тему задачи (badge «Динамика») — студент знает область, ищет закон
- Скрыть тему — студент вообще не знает с чего начать
- Quiz: «Какой закон?» → [ЗСЭ] [2-й Ньютон] [ЗСИ] → feedback

**Подумай: для физики quiz по выбору закона может быть более полезен,
чем для ИнтДУ, потому что физических законов меньше, чем математических методов.**

### Про справочник

Физический справочник — это формулы + ЕДИНИЦЫ + ОБОЗНАЧЕНИЯ.
Студент часто забывает: что такое `ε` в контексте колебаний? А в контексте термодинамики?
Справочник по физике должен быть структурирован по темам, не по алфавиту.

### Про числовые результаты

В физике ответ — число с единицей: `v = 3.5 м/с`. Студент может:
1. Получить правильный ответ
2. Получить правильное число с неправильной единицей
3. Получить неправильное число

Как самооценка может это учитывать? Может, показать ответ ДО полного решения
(чтобы студент сравнил число), а потом — полное решение для понимания?
**Подумай и реши сам.**

## 4. Контрольная по физике — специфика

| КМ | Задачи | Время | Структура |
|----|--------|-------|-----------|
| РК-1 | 10-15 | 90 мин | Все темы механики + колебания |
| РК-2 | 10-15 | 90 мин | МКТ + термодинамика + волны + СТО |
| Экзамен | 5-6 | 120 мин | Все темы |

Физические контрольные обычно содержат БОЛЬШЕ задач, чем математические,
но каждая задача КОРОЧЕ (2-4 шага вместо 5-7).

## 5. Цикл качества (дополнение к мастер-скиллу)

### КОНТЕНТ — специфика физики
- `\text{ м/с}`, `\text{ Дж}`, `\text{ Н}` — рендерится в KaTeX?
- «Дано: ... Найти: ...» — читаемо? Не выглядит как каша текста?
- Формулы с греческими буквами — α, β, ω, φ — рендерятся?
- Ответ содержит единицу? `\boxed{v = 3.5 \text{ м/с}}`

### ПЕДАГОГИКА — специфика физики
- Студент тренирует ВЫБОР ЗАКОНА, а не подстановку чисел?
- Подсказка — это закон с формулой, а не «подумай»?
- Справочник — структурирован по темам (механика, термо...)?
- Для СТО: формулы Лоренца доступны в справочнике?

### ЛАКОНИЧНОСТЬ — специфика физики
- Задачи короткие (2-4 шага) — не слишком ли много пустого пространства?
- Может, для коротких решений подойдёт другой layout?

## 6. Антипаттерны для физики

- ❌ Показывать ответ (число) в подсказке — это спойлер
- ❌ Справочник без единиц — студент не знает что такое «Дж» vs «Н»
- ❌ Игнорировать `\text{}` в формулах — единицы не отображаются
- ❌ Одна контрольная на все темы — РК-1 и РК-2 РАЗНЫЕ блоки
- ❌ Не различать механику и термодинамику в карте покрытия
